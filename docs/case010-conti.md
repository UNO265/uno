# CASE #010 최종 콘티 — 「コンビニ、なぜ値引きせず捨てる？」

[06 DIRECTION](guide/06_DIRECTION.md) · 양식 [conti-v4](templates/conti-v4.md). 1차 콘티 → 시청지속률 검수 → 이탈 위험 탐지 → 자동 수정 → 재검수를 마친 **최종 콘티**다(06-32). 컷 연출은 AI가 결정했다(06-4·51). **#010까지 실사 없음(C5)** → REAL은 2D 재현.

- 대본(확정): [script.txt](../cases/case010/script.txt) **4,190자** / 최종 음성 **13:30.8** / 나레이션 컷 46개(E33을 45초 기준으로 E33·E33B로 분할) → **화면 CUT 43개**
- **경제적 핵심 구조(06-28)**: 本部の取り分 = 売れた分の利益 × 率 / 捨てた原価 = 店85%・本部15% → 棚を埋めるほど本部は減らず店が重くなる → 値引きは店に大きく得・本部に小さく損 → 負担が本部へ動く(2019 → 2024 → 2027 50%)と損得の向きが変わる. 06-29 상식 ≠ 실제: **"버리면 본부가 번다"가 아니라, 본부의 차이는 6円·가게의 차이는 106円**.
- **Micro Question(06-24)**: なぜ売り切らない？ → 6円なら、なぜ広がらなかった？ → 店は値引きできるようになった？ → なぜ今動いた？ → この先どうなる？
