  | 질감 | 임시 목표 | 실제 |
  |---|---|---|
  | FLAT 2D | 35~40% | 25.5% (215초) |
  | OBJECT · DOCUMENT · BLUEPRINT · VELVET | 25~30% | 29.4% (249초) |
  | EVIDENCE | (DOCUMENT에 포함) | 12.3% (104초) |
  | DATA · MONEY FLOW | 20% | 12.1% (102초) |
