# カネナゾ / KANENAZO 영상 제작 마스터 지침

> 모든 롱폼 영상(CASE #001 이후 전부)에 적용한다. 기준 스타일은 CASE #001의 1분 샘플(`video/` C001–C011).
> 핵심: 샘플의 디자인을 유지하고, 15~20분 장기 시청의 단조로움만 실제 자료·숫자·그래프·패턴 브레이크로 보완한다.
> 과도한 애니메이션, 화려한 전환, 불필요한 효과는 추가하지 않는다.

## 1. 영상 정체성
「身近なお金の謎を解く。」 — 경제 미스터리 다큐멘터리.
흐름: 의문 제시 → 단서 발견 → 구조 분석 → 예상 밖의 사실 → 새로운 의문 → 반전/비교 → 수수께끼의 답.

## 2. 유지할 기본 디자인
- 따뜻한 베이지/아이보리 배경, 심플한 플랫 일러스트, 구조를 보여주는 아이콘
- 빨간 100円 가격표 같은 핵심 오브젝트 강조, 필요 시 어두운 배경으로 분위기 전환
- 핵심 숫자는 큰 타이포그래피, 돈/상품의 흐름은 화살표와 선
- 화려하지 않은 모션, 일본 시청자가 한눈에 이해하는 화면
- 디자인을 영상마다 새로 만들지 않는다 (CASE #001의 디자인 언어를 계속 사용)

## 3. 화면 구성 비율
- 약 60~70%: 카네나조 플랫 모션그래픽(아이콘·숫자·도식·타이포)
- 약 30~40%: 실제 사진·영상·공식자료·통계·지도·그래프·기사자료
- [그래픽] → [실제 자료] → [숫자] → [그래프] → … 로 화면 질감을 계속 바꾼다

## 4. 실제 자료 삽입
- 실제 자료도 카네나조 디자인 안에 넣는다 (베이지 배경 + 사진 프레임 + 스크랩 느낌 + 강조선·화살표·숫자·짧은 일본어 설명)
- 'CASE FILE의 증거자료'처럼 보여주는 방식 우선. 현장감이 중요한 장면만 풀스크린 허용

## 5. 실제 자료 우선 원칙
- 실존 기업·매장·상품·인물·사건은 가능한 한 실제 자료 우선 (공식자료, 실제 매장, 공식 역사자료, 실제 통계로 직접 그린 그래프)
- 공장·물류 같은 일반 개념은 플랫 애니메이션 또는 합법적으로 사용 가능한 B-roll
- 안전하게 쓸 수 없으면 카네나조 스타일 그래픽으로 대체
- '인터넷에 공개되어 있다'는 이유만으로 사용 가능하다고 판단하지 않는다. 정보 출처와 콘텐츠 사용권은 별도로 판단

## 6. 화면 변화 속도
- 약 3~7초마다 시각적 변화 (줌, 숫자 등장, 아이콘 추가, 화살표 이동, 그래프 상승, 텍스트 강조, 사진 변경, 배경 전환 등)
- 이해하기 전에 지나갈 정도로 빠르게 편집하지 않는다

## 7. 패턴 브레이크
- 약 1~2분 간격. 예: 밝은 베이지 → 갑작스러운 검은 화면 → 작은 동전 → 「それなのに——」
- 배경음 변화, 암전, 효과음, 큰 질문, 숫자, 잠깐의 정적. 남용 금지

## 8. 내레이션과 화면
- 내레이션 받아쓰기 금지. 화면은 내레이션을 증명하거나 이해시킨다
- 예: 「大量に仕入れることで…」 → 100個 → 10万個 → 100万個 / 大量発注 → 1個あたりのコスト↓

## 9. 핵심 숫자
- 1兆1100億円, 7710億円, 5891店舗, 5万8000種類, 毎月1600種類 등은 화면의 주인공
- 그래프·카운트업·확대·비교. 한 화면에 여러 숫자를 동시에 보여주지 않고 내레이션에 맞춰 하나씩

## 10. 그래프/도표
- 복잡한 구조는 반드시 시각화 (순환 구조, MONEY FLOW)
- MONEY FLOW(メーカー → 物流 → 100円ショップ → 消費者)는 반복 사용하는 핵심 시각 장치로 발전시킨다

## 11. CASE / CLUE 시스템
- 각 영상 = 하나의 사건. 예: 「KANENAZO CASE #001 100円ショップは、なぜ100円で儲かる？」
- 중간에 CLUE 01, CLUE 02 … 로 단서 정리. 너무 자주 쓰지 않는다 (게임처럼 보이지 않게)

## 12. 일본어 자막
- 하단 자막은 스마트폰에서 읽기 쉽게 (작은 글씨 금지)
- 일반 내레이션 → 하단 자막 / 핵심 문장 → 중앙 대형 타이포 / 숫자 → 화면 중심 / 질문 → 독립된 화면

## 13. 첫 30초
- 첫 5~10초 안에 질문을 이해시킨다. 예: 100円 × 1 → × 3 → × 7 → × 12 → 「なぜ、これで儲かる？」
- 긴 채널 소개 금지

## 14. 비교 장면
- 좌우 분할로 한눈에. 예: DAISO 200円/300円/500円 → 価格帯を広げる VS Seria 100円 → 100円を守る

## 15. 마지막
- 처음 질문을 반드시 회수 → 단서들이 하나의 구조로 합쳐짐
- 핵심 문장을 강하게: 「100円は、ただの値段ではない。ビジネスのルールだった。」
- 종료: KANENAZO / 「身近なお金の謎を解く。」 / 「では、次の謎で。」

## 16. 가장 중요한 원칙
- 목표는 예쁜 영상이 아니라 '아, 그래서 그런 거구나'를 화면만 보고도 이해하게 하는 것
- 모든 화면의 역할: ① 지금 말하는 것을 보여준다 ② 근거를 보여준다 ③ 다음 이야기를 궁금하게 만든다. 역할 없는 장면은 제거

## 17. 제작 방식
- 대본을 받으면 바로 영상부터 만들지 않는다. 먼저 의미 단위로 장면을 분할한다
- 장면마다 결정: 내레이션 / 화면 목적 / 플랫 그래픽인지 실제 자료인지 / 필요한 사진·영상 / 숫자 / 그래프·도식 / 화면 일본어 텍스트 / 모션 / 길이 / 다음 장면과의 연결
- 설계 완료 후 제작. '움직이는 PowerPoint'처럼 보이면 안 된다

## 18. 기준 샘플
- CASE #001 1분 샘플이 스타일 기준. 초반 훅 강화, 실제 자료 추가, 숫자 시각화 강화, 그래프/도표 추가, 패턴 브레이크, 스마트폰 자막 가독성 개선을 적용해 롱폼으로 확장
