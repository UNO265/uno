## 5. 장면 설계

**화면 타입**: A 플랫 / B EVIDENCE·문서 / C 숫자 / D 그래프·구조·MONEY FLOW / E 실사 / F 질문·패턴 브레이크 / G 핵심 문장 / H 시간축·지도
**목적**: ① 이해시킨다 ② 근거를 보여준다 ③ 다음이 궁금해지게 한다
**BGM 표기**: ▶ 흐름(곡 이름) / ↓ 낮춤 / ■ 정지·무음
**자막**: 화면 중앙에 같은 문장이 있으면 하단 자막을 생략합니다. 9자 이하의 짧은 말은 박스 없이 표시합니다.
