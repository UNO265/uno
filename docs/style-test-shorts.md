# 스타일 비교 쇼츠 실험 (CASE #010 소재)

목적: 일본 시청자가 어떤 화면 스타일에 더 오래 머무는지 **숫자로** 정한다. 04 SHORTS의 「실험」 칸(한 번에 한 요소만 바꾼다)에 해당한다.

## 같은 것 / 다른 것

| 같음 | 다름 |
|---|---|
| 내레이션(VOICEVOX 雀松朱司, 1.3배), 자막, 길이(22.3초), BGM(#010 e_calc), 반복 재생 끝, 출처·계산 표시 | **화면 스타일만** |

| 파일 | 스타일 |
|---|---|
| `video/out/style_frames/ShortA.mp4` | A 지금 방식(평면 벡터, 남색) |
| `video/out/style_frames/ShortB.mp4` | B 종이 질감 + 수사 보드 |
| `video/out/style_frames/ShortD.mp4` | D 따뜻한 3D 미니어처 + 탐정 캐릭터 + 테롭 |

- 대본: `cases/case010_shorts/style_test/cuts.json`(확정 대본 #010 E14~E16의 문장을 쇼츠용으로 줄임). 코드: `video/src/style/shorts/`.
- 길이가 SH5 기준(25~40초)보다 짧다(22.3초). 세 편이 같으므로 비교에는 영향이 없다.

## 올리는 방법

1. **본편 #010을 먼저 공개**한다(関連動画 지정 때문).
2. 세 편을 **같은 요일·같은 시간대에 하루 간격**으로 올린다(예: 월 A → 화 B → 수 D, 18시). 순서 효과가 걱정되면 다음 실험에서 순서를 바꾼다.
3. 제목은 세 편 모두 같은 문장: `値引きで、本部の損は6円だけ？ #Shorts`. 설명란·해시태그·関連動画도 같게.

## 볼 숫자 (공개 7일 뒤, YouTube 스튜디오)

| 지표 | 의미 |
|---|---|
| **스와이프하지 않고 본 비율**(視聴した / スワイプして離れた) | 첫 1초. 스타일이 눈을 붙잡았는가 |
| **평균 시청 지속률**(100% 넘으면 반복 재생) | 끝까지 보고 다시 봤는가 |
| 조회수 | 위 두 숫자의 결과 |
| 関連動画 클릭 | 본편으로 보냈는가 |

- 판정: 스와이프하지 않은 비율과 평균 시청 지속률이 **둘 다** 다른 스타일보다 높으면 채택한다. 차이가 작으면(5%p 안쪽) 제작 비용이 낮은 쪽을 고른다.
- 결과는 `docs/performance-log.md`의 Shorts 표에 적는다.
