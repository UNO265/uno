# CASE #004 입구 쇼츠 1편 (코인 세탁소)

[쇼츠 지침 v1](KANENAZO_SHORTS_v1.md)을 처음 적용한 편입니다. 다만 끝은 사용자 요청으로 지침 2번(반복 재생 없음) 대신 **반복 재생형**으로 만들었습니다. 지침 3번에 따라 **CASE마다 입구 0~1편**만 만들고, 이번 CASE는 ① 입구 1편입니다.
본편 「コインランドリー、人がいないのになぜ儲かる？」(12:28)에서 확인된 사실만 썼고, 새 수치는 넣지 않았습니다.

| 항목 | 내용 |
|---|---|
| 0프레임 질문 | 「コインランドリー、人がいないのに、なぜ儲かる？」(본편 제목과 같은 문장, 글자 + 첫 음성) |
| 작은 답(본편 REWARD 1) | 人件費は半分だけ正しい → 高価な機械に働いてもらう店(본편 N10~N12) |
| 본편으로 넘기는 질문 | 家に洗濯機があるのに市場は1155億円 → 「何を買ってる？」(본편 썸네일 질문. 본편 N27에서 묻고 N30·N31에서 답함) |
| 말하지 않은 것 | 본편의 MID REVEAL(クリーニング店の縮小)과 FINAL ANSWER(機械で時間を売る店) |
| 끝 | 본편 썸네일과 같은 그림(드럼 창 + 「1155億円」 + 「何を買ってる？」)을 약 0.8초 보여 준 뒤, 마지막 0.5초에 첫 화면(W01)으로 바뀜 → **반복 재생**. 마지막 프레임과 0프레임은 드럼 위치·회전 각도까지 같다. 광고 문구 없음 |
| 길이 | 29.4초 |

- **형식**: 1080×1920 / 30fps
- **음량**: -14.3 LUFS, 최대 피크 -1.2 dBFS, 0.8초 이상 무음 없음
- **음성**: VOICEVOX 雀松朱司, 본편보다 1.3배 빠르게(`--rate 1.3`)
- **BGM**: 새로 작곡(본편 CASE #004의 곡 분위기 mechanism, FluidR3_GM)
- **실사**: 쓰지 않았습니다(CASE #010까지 방침).
- 대본: `cases/case004_shorts/short1/cuts.json`, 화면: `video/src/shorts004/short1.tsx`

## 올리는 순서(지침 6번)

1. **본편을 먼저 공개**합니다.
2. 쇼츠는 본편 공개 당일~다음 날에 올리고, Studio에서 **「関連動画」에 본편을 지정**합니다.
3. 1~2주 뒤 関連動画 클릭 수를 [성과 기록](performance-log.md)의 J 줄에 적습니다. #003 쇼츠와 같은 반복 재생형이므로, 비교되는 차이는 "마지막 질문이 본편 썸네일 질문과 같은 말인가"와 "끝에 썸네일 그림이 나오는가"입니다.

# CASE #004 쇼츠 2·3편 (2026-09-27 추가, 쇼츠 지침 3번 개정: 롱폼과 병행)

두 편 모두 본편에서 확인된 사실만 썼고, 본편의 중간 반전(클리닝 가게 축소)과 최종 답(機械で時間を売る店)은 말하지 않았습니다. 끝은 1편과 같은 반복 재생형(마지막 프레임 = 0프레임)입니다.

| 편 | 역할 | 0프레임 질문 → 작은 답 | 끝의 질문 | 길이 | 음량 |
|---|---|---|---|---|---|
| 2 | ② 의외의 숫자 | 「コインランドリー、店の数は何倍？」 → 1996년 약 1만 점 → 2013년 1만 6693점(약 1.6배, 厚労省) → 10년간 약 4할 증가(日経 2024) → 시장 1155억 엔(矢野 2025) | 「客はいったい、何を買ってる？」(본편 썸네일 질문) | 28.4초 | -14.1 LUFS / -1.2 dBFS |
| 3 | ③ 돈의 흐름 | 「コインランドリーに入れたお金、どこへ消える？」 → 1회마다(수도·전기/가스·세제) → 와도 안 와도(임대료·청소·점검/수리) → 설비 → 무인이라 거의 이익, 은 아니다 | 「人がいないのに、なぜ儲かる？」(본편 제목) | 30.5초 | -14.4 LUFS / -1.0 dBFS |

- 3편은 금액을 쓰지 않았습니다(가게마다 다름). 본편 N15~N18과 같은 설명입니다.
- 대본: `cases/case004_shorts/short2|3/cuts.json`, 화면: `video/src/shorts004/short2|3.tsx`, BGM: 본편 분위기 market(2편)·contrast(3편)로 새로 작곡.
- 올리는 순서: 1편(본편 공개 당일) → 2편(2~3일 뒤) → 3편(다시 2~3일 뒤). 모두 「関連動画」에 본편 지정.
