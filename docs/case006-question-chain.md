[CORE v4](archive/KANENAZO_CORE_v4.md)(최상위) + 시청지속 v2.0·v2.1·32~34 + 성과 지침 3-1·4-3·7-1. 근거 번호(G1~G12)는 [사전 조사](case006-research.md). 목표 분량 **3,500~4,200자(약 9~11분)**. 채우지 않는다.

## 0. ANSWER CARD

| 항목 | 내용 |
|---|---|
| 제목 질문 | ガチャガチャ、なぜ500円に？ |
| 답의 형식 | 이유 |
| 공개 자료로 말할 수 있는 답 | **買う人が変わったから.** おこづかいで1回だけ回す子どもの商品から, 大人が選んで何回も回す商品になった. 主流の価格帯が200〜300円から400〜500円に上がっても, 市場は1年で39%増えて1,960億円(G1·G2·G4·G5) |

| 상식 점검 | 「大人向けで高くなった」는 알려짐 → **중간 보상(2분대)**. 최종 결론은 "값이 올라도 무너지지 않는 구조"(수주 생산·재고를 누가 지나·장소로 버는 오퍼레이터) |

## 4. 썸네일 (7-1)

- 캡슐 하나 + `500円` + 「なぜ売れる？」
- 답(大人が何回も回す)은 2:00~2:40, 최종 구조(受注生産・在庫・場所)는 숨김. 썸네일만으로 결론을 맞힐 수 없음 ✅

## 5. PROMISE AUDIT(예정)

1. 제목의 기대(왜 500円?) → 2:00~2:40에 답 ✅
2. 최종 답 첫 문장 = 이유 ✅
3. 공개되지 않는 숫자(1회 이익·설치 몫) → 타이틀 직후에 말함 ✅
4. 여기서만 아는 사실: G1(3년 1.7배), G4(20〜30대 1,200〜1,400円), G9(ハピネット 654億円·52億円·+71%), G11(3か月前に数量, 在庫はオペレーター) ✅

## 6. 주의
- ハピネット는 반다이 계열 오퍼레이터의 **한 예**다. 업계 전체의 이익률로 말하지 않는다.
