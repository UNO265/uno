## 4. 썸네일 설계안 (사용자 제작, P5)

- **A(추천)**: 투명 쓰레기봉투 속 멀쩡한 도시락·주먹밥 + `1店 年468万円`(「1店 年」 작게, 「468万円」 크게) + 「誰が払う？」(누가 내나?)
  - 쓰레기봉투 그림이 있어야 468万円이 "버린 돈"으로 읽힌다. 숫자만 있으면 가격·매출·연봉과 헷갈림.
  - 제목=왜 / 썸네일=누가 → 각도가 다름.
- B: 같은 그림 + `年468万円` + 「ゴミに？」 → 제목과 같은 말 반복이라 약함. C: 「なぜ？」 → 제목과 같은 질문.
- 답(가게 85%·새 계약 50%·「本部」)은 쓰지 않는다. 「誰が払う？」의 답은 REWARD 1(1:50, 가게)과 REWARD 5(10:00~, 본부로 이동).
- 점검: 가로 160px에서 "쓰레기봉투 속 음식 / 468万円 / 誰が払う？"가 즉시 보이는가.
