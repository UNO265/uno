# CASE #002 쇼츠 3편 (라면)

본편 「ラーメン一杯1000円。店には、いくら残る？」(13:16)에서 확인된 사실만 썼습니다. 새 수치는 넣지 않았습니다.

세 편 모두 [성과 지침](KANENAZO_PERFORMANCE_v1.md) 24~27번과 24-1을 따랐습니다(CASE #001 쇼츠 3편 v2와 같은 방식).
- 시작 구조: 0초 가격 → 1초 질문 → 3초 의외의 답 → 설명
- 쇼츠 안에서 답을 끝까지 줍니다.
- 본편으로는 **다른 질문 한 줄**로 잇습니다.
- 「CASE #002」 머리말과 「続きは本編で」 엔드카드는 없습니다. 왼쪽 위에 작은 로고만 둡니다.

| 편 | 질문 → 답 | 본편으로 잇는 한 줄(본편에서 답하는 부분) | 길이 | 대본 |
|---|---|---|---|---|
| 1 | 「その原価は、5年でどれだけ上がった？」 → 원가 지수 100 → 141. **「1000円は変わらなくても、1000円の中身は変わる。」** | 「値段を上げれば、いいのでは？」 → 본편의 「1000円の壁」 | 35.5초 | `cases/case002_shorts/short1/cuts.json` |
| 2 | 「市場は過去最高。なら、儲かっている？」 → 순손익 합계 356억 → 171억 엔. **「売れている。でも、残らない。」** | 「利益を残せる店は、何が違うのか。」 → 본편의 「店の仕組み」 | 38.9초 | `cases/case002_shorts/short2/cuts.json` |
| 3 | 「ラーメンは、なぜ簡単に値上げできない？」 → 「安くて、うまい大衆食」 이미지. **「客単価」를 올린다** | 「その1000円、最後に店に残るのは、いくら？」 → 본편의 답 | 29.4초 | `cases/case002_shorts/short3/cuts.json` |

- **형식**: 1080×1920 / 30fps
- **음량**: -14.2~-14.4 LUFS, 최대 피크 -1.1 dBFS(클리핑 0), 0.8초 이상 무음 없음
- **음성**: VOICEVOX 雀松朱司, 본편보다 **1.3배 빠르게**(`--rate 1.3`). 읽기 보정: 味玉→あじたま
- **BGM**: 각 편 전용으로 새로 작곡(본편 CASE #002의 곡 분위기 pressure·paradox·wall, FluidR3_GM)
- **반복 재생**: 마지막 컷이 첫 화면의 배경색으로 바뀌며 끝납니다.
- **화면 질감**: 베이지 / 흰 DATA / 남색 DARK / 문서 / 빨간 면이 교차합니다. 실사는 쓰지 않았습니다(CASE #010까지 방침).

## 실험 설계(성과 지침 28번: 한 번에 한 요소만)

세 편의 구조는 CASE #001 쇼츠 3(v2)와 같게 고정하고, **첫 프레임만** 다르게 했습니다. 결과는 [성과 기록](performance-log.md)의 D·E·F 줄에 적어 주세요.

| 편 | 첫 프레임 |
|---|---|
| 1 | 라면 그릇 + 가격 「1000円」 |
| 2 | 라면 그릇 + 큰 숫자 「8855億円」 |
| 3 | 벽돌 벽 + 라면 그릇 + 말 「1000円の壁」(숫자 없음) |

## 사실 확인(본편과 같은 출처)

| 쇼츠 속 수치 | 출처 |
|---|---|
| 라면 원가 지수 2020=100 → 2025=141(도쿄도 구부·돈코츠 베이스, 원재료 비용) | 帝国データバンク「『ラーメン店』の倒産動向（2025年）」2026-01 |
| 시장 2025년도 8855억 엔(전망, 과거 최고), 2015년도 5418억 엔, +63.4% | 帝国データバンク「全国『ラーメン店』市場動向調査（2025年度）」2026-07 |
| 주요 체인 점포 수 6305곳(과거 최다) | 같은 조사 |
| 순손익 합계 356억 → 171억 엔(손익을 확인할 수 있었던 기업) | 같은 조사 |

- 1편 「すべての店が、41％上がったわけではない」: 지수를 모든 가게의 원가 상승률로 오해하지 않도록 넣었습니다.
- 1편의 1000엔 막대(비용 / 남는 돈)는 실제 비율이 아니어서 화면에 「※ 割合はイメージ」를 표시했습니다.

## 만드는 방법

```bash
cd video
python3 scripts/narration.py --case case002_shorts/short1 --rate 1.3   # 2, 3도 같음
python3 scripts/music.py --case case002_shorts/short1
npx remotion render Short002-1 out/shorts002/render_1.mp4
scripts/master.sh out/shorts002/render_1.mp4 out/shorts002/KANENAZO_CASE002_short1.mp4
CASE=002 node scripts/shorts_sheet.mjs 1    # 확인용 시트 → out/shorts_sheet_002_1.jpg
```
