# 세종 쇼츠 1 「87세까지 퇴사 못 한 황희」

본편 「세종대왕 밑에서 일하면 생기는 일」(15:47) 3장(C305~C309)에서 확인된 사실만 썼다. 새 사실·수치는 넣지 않았다.

- **길이·형식**: 36.9초 / 1080×1920 / 30fps
- **음량**: -14.0 LUFS, 최대 -1.5 dBFS, 0.2초보다 긴 무음 없음
- **구성**: 0초 [사직서 + 반려 도장 + 큰 숫자 87세 + 질문 「퇴사가 안 된다고?」] → 70세 사직 불허 → 또 반려 → 한 달 두 번 조회(재택근무) → 답: 1449년 87세에 물러남, 3년 뒤 90세에 세상을 떠남
- **본편으로 잇는 한 줄**: 「그런데 세종이 가장 혹독하게 부린 사람은, 따로 있었습니다.」 → 본편 에필로그의 답(세종 자신)
- **반복 재생**: 마지막 컷이 첫 화면의 한지 바탕으로 돌아가며 끝난다.
- **적용한 지침**(`next-video-guide.md`): 큰 그림·큰 글자(자막 74px), 정교한 실루엣(사모·단령·흉배, 흰 수염 / 곤룡포 용보·익선관 뒷모습), 문장 단위 내레이션, 음성인식 단어 시간에 맞춘 자막(문장부호 없음, 한 줄 우선·길면 두 줄, 핵심어 주황 강조), 강조 장면에만 효과음 4개(불허 도장·반려 도장·1449년 숫자 멈춤·마지막 질문 종), BGM 두 곡 전환(사직서 반려까지 경쾌 → 87세 답부터 무겁게)
- **목소리**: Supertonic 3 M2, 본편보다 약 15% 빠르게(쉼 제외 초당 7.8음절)

## 사실 확인

| 쇼츠 속 내용 | 본편 근거 |
|---|---|
| 1432년, 일흔 살 무렵 늙었다는 이유로 물러나기를 청함 → 세종이 허락하지 않음 | C306 |
| 몸이 더 약해져 다시 사직을 청했으나 또 받아주지 않음, 한 달에 두 번만 조회·나머지는 집에서 | C308 |
| 1449년 영의정에서 물러남(87세), 3년 뒤 90세로 세상을 떠남 | C309 |
| 황희 1363–1452, 영의정 | C305 |

※ 본편 검토 문서(`sejong-script-review.md` 5번)가 실록 원문 대조를 권한 항목 중 「한 달 두 번 조회」 명령의 연도는 쇼츠에서 연도를 쓰지 않았다.

## 만드는 방법

```bash
cd video
python3 scripts/sejong_short.py sejong_short1        # 음성(문장 단위)·자막 카드·BGM·효과음 → public/sejong_short1/
npx remotion render src/sejong_short/index.ts SejongShort1 out/sejong_short1_render.mp4 --crf=18
python3 scripts/sejong_short.py sejong_short1 --master out/sejong_short1_render.mp4 out/SEJONG_short1.mp4
```

썸네일: `npx remotion still src/sejong_short/index.ts SejongShort1Thumb out/SEJONG_short1_thumb.png` (1080×1920, [반려된 사직서 + 87세 + 「퇴사가 안 된다고?」]. YouTube 모바일 앱에서 쇼츠 업로드 때 「썸네일 → 사진 업로드」로 올린다)

대본은 `video/data/sejong_short1/script.json`(`[ ]` = 자막 강조어), 화면은 `video/src/sejong_short/Short.tsx`.
