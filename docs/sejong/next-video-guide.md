# 한국사 다큐 · 다음 영상 제작 지침 (세종 편 회고)

세종 편(`SEJONG.mp4`, 15:47)을 다 보고 정리한 개선점. 다음 한국사 영상부터 적용한다.
세종 편의 톤(한지 + 먹선 + 촛불 한 점, 얼굴 없는 실루엣, 실록 인용)은 그대로 계승하고, 아래 항목만 바꾼다.

## 1. 화면

- **크게.** 그림과 화면 글자를 키운다. 휴대폰 화면에서 읽히는 크기가 기준이다.
  - 화면 속 설명 글자(출처·주석 포함)는 1080p 기준 최소 32px. 세종 편의 20px대 캡션은 폰에서 읽히지 않았다.
  - 핵심 그림(물체·인물)은 화면 높이의 절반 이상을 차지하게 한다. 작은 그림을 가운데 하나만 두지 않는다.
- **전환을 더 자주.** 한 화면이 오래 머물지 않게 한다.
  - 한 컷 안에서도 그림이 바뀌거나 움직이게 한다(물체 추가, 확대, 카메라 이동, 강조 표시).
  - 글자만 있는 카드(장 제목 제외)를 연달아 두지 않는다. 가설·삼년상·기복 같은 개념 카드는 물체 장면으로 바꾼다(예: 기복 → 상복 위로 내려오는 왕명 문서).
- **깊이감.** 편전·집현전 같은 실내 장면은 기둥·인물·배경을 층으로 나눠 카메라 이동 때 층마다 다르게 움직이게 하고, 벽에 흔들리는 촛불 그림자와 먼지를 더한다.
- **수묵 연출.** 먹 번짐 전환, 붓 획 순서로 그려지는 제목, 쾅 찍히는 실록 도장.
- **지도.** 한반도 윤곽은 손으로 그리지 말고 공개 지도 데이터(Natural Earth, 퍼블릭 도메인)로 그린다.

## 2. 인물

- 얼굴 없는 실루엣은 유지하되 **정교하게** 그린다.
  - 왕: 익선관(뒤로 솟은 두 날개 모양, 둥근 귀처럼 보이지 않게)·곤룡포.
  - 신하: 사모(양옆 날개)·단령 관복. 엎드린 자세는 머리·등·소매가 구분되게(검은 덩어리 금지).
- 작은 동작을 넣는다: 숨 쉬는 듯한 미세한 움직임, 고개 숙이기, 책장 넘기기, 붓 들기.

## 3. 자막

- 반투명 회색 상자 + 흰 글씨는 유지한다.
- **핵심어만 색으로 강조**한다(숫자·인물 이름·핵심 개념). 한 줄에 하나 정도. 색은 촛불 주황 또는 도장 빨강.
- **마침표(.)와 쉼표(,)는 쓰지 않는다.** 물음표(?)와 따옴표(인용)는 남긴다.
- **가능하면 한 줄**, 내레이션이 길 때만 두 줄. 한 줄 최대 글자 수는 폰트 크기에 맞춰 정한다(대략 22자 안팎).
- 자막은 **내레이션 발화 시간에 맞춰** 나눈다(아래 4번). 대본 줄바꿈에 맞추지 않는다.
- 자막 상자가 화면 아래쪽 글씨·그림(출처 표기, 받침 등)을 가리지 않게 화면 설계 단계에서 자막 영역(아래 약 20%)을 비워 둔다.

## 4. 내레이션

- 목소리: Supertonic 3 **M2**, 말 속도는 세종 편과 같게(쉼 제외 초당 약 6.8음절).
- **문장 단위로 합성한다.** 세종 편은 자막 줄 단위로 합성해서, 한 문장이 두 줄에 걸친 44줄(20%)에서 문장 중간 억양이 끝난 것처럼 떨어졌다가 다시 시작해 "끊기는 느낌"이 났다.
  - 순서: 문장 단위 합성 → 음성인식(Whisper)으로 단어별 시간 추출 → 그 시간으로 자막을 한 줄/두 줄로 나누고 컷 타이밍을 정한다.
  - 짧은 문장이 빨라지는 문제는 문장 단위 속도 맞춤(`sejong_voice.py`의 `speech_rate` 방식)을 그대로 쓴다.
- 합성용 문장과 자막 문장을 분리한다. 합성용에는 쉼표를 호흡이 필요한 곳에만 남기고, 숫자는 한글 한자어로 풀어 쓴다(1439년 → 천사백삼십구년). 잘못 읽는 말은 `READ` 표로 고친다.
- 대본을 쓸 때부터 쉼표를 줄인다. 쉼표마다 0.3~0.4초 쉼이 생긴다.

## 5. 소리

- **효과음은 강조 장면에만** 확실하게 넣는다. 모든 장면에 깔지 않는다.
  - 예: 실록 도장 찍힘, 사직서 반려, 연도·숫자 등장, 반전 공개(초수리), 장 제목, 에필로그 영수증.
  - 한 장(章)에 3~5개 안팎. 효과음이 내레이션 단어와 겹치지 않게 문장 사이에 둔다.
- **BGM은 대본 흐름에 따라 바꾼다.** 한 곡을 길게 깔지 않는다.
  - 장면 성격별로 곡을 나눈다: 오프닝 긴장 / 기록·사실 전달(담담) / 인물의 고통(무겁게) / 반전(정적 → 전환) / 에필로그(여운).
  - 전환은 문장이 끝난 쉼에서 1~2초 크로스페이드. 반전 직전에는 BGM을 잠깐 비워 정적을 만든다.

## 6. 끝 화면

- **마지막 20초는 YouTube 최종 화면용으로 비운다.** 다음 영상 카드·구독 버튼이 들어갈 자리이므로 화면 중앙~오른쪽에 중요한 글자·그림을 두지 않는다.
- 내레이션("댓글로 들려주세요…시청해 주셔서 감사합니다")은 이 20초가 시작되기 전이나 시작 직후에 끝낸다. 배경은 어두운 한지 + 촛불 정도로 단순하게, BGM은 여운으로 이어 간다.

## 7. 제작·전달

- 최종본은 원본 화질로 렌더링한 뒤 `python3 video/scripts/sejong_split.py`로 25MB 이하 조각 + `join_windows.bat`으로 나눠 전달한다(재압축 없음, 합치면 원본과 같음).
- 업로드용 제목·설명은 실제 챕터 시각으로 만든다(`docs/sejong/sejong-upload.md` 형식).
