# CASE #005 QUESTION CHAIN 설계 — 「送料無料、本当に無料？」

[시청지속 지침 v2.0·v2.1](KANENAZO_RETENTION_v2.md) 21번 양식 + v2.1(26~31) + 32~34번. 근거 번호(F1~F14)는 [사전 조사](case005-research.md). 시각은 약 5.55자/초로 잡은 **예상치**다. 목표 분량: 공백 제외 약 4,300~4,800자(약 13~14분). 반복으로 채우지 않는다.

- 제목(확정, 사용자): **送料無料、本当に無料？**(11자. 검색어 「送料無料」 맨 앞, 후킹 = 의문·역설). 설계 확정 뒤 사용자가 「送料は誰が払ってる？」에서 바꿨다.
- 썸네일(안): 「送料無料」 스티커가 붙은 골판지 상자 + 큰 숫자 `0円` + 질문 **「誰が払う？」** — 제목(무료인가)과 다른 두 번째 궁금증(누가). 제목이 바뀌어 「本当はいくら？」는 제목과 겹치므로 바꿨다. MID REVEAL(운반하는 사람의 시간)과 최종 답(客と店、そして運ぶ人)에서 회수
- 성과 지침 32번: #005는 VALIDATION 편. #001·#002·#004의 「なぜ儲かる／いくら残る」와 달리 **숨은 구조형 후킹**을 쓴다.

| FINAL ANSWER(답 먼저) | 送料は消えていない。商品の値段、まとめ買い、会費として客が払い、店が費用として負担し、足りない分は運ぶ人の時間が支えてきた。「送料無料」とは、送料が無い状態ではなく、送料が見えなくなった状態だ。 | 11:40 | — |

## 대본 작성 때 지킬 것

- 가게가 送料를 상품값에 "얹었다"고 단정하지 않는다(消費者庁도 확인 못 함). 「〜という方法がある」.
- 楽天·Amazon의 의도를 단정하지 않는다. 구조로 설명한다.
- 711엔은 "법인 할인 포함 평균, 2025年3月期"라고 화면에 표기한다.
- 6만 명 시산은 "재배달률 약 10%일 때"라고 말한다(현재 8.3%에 붙이지 않음).
- 운전기사를 피해자로만 그리거나 소비자를 비난하는 톤을 쓰지 않는다. 구조를 보여 준다.
- REWARD 뒤 부연 두 문장까지(33번), 마지막 20%에 요약 표현·목록 재나열 없음(34번).

## 쇼츠(쇼츠 지침 3번)

입구 1편 후보: 「送料無料、本当は0円？」 → 답: 0엔이 아니다(711엔 평균, 「送料当社負担」) → 끝: 본편 썸네일(상자 + 0円 + 本当はいくら？)이 아니라 **본편 제목 질문 「送料は誰が払ってる？」** 로 넘긴다. 대본 확정 후 결정.
