## 쓰지 않는 것 / 주의

- **운임 내역 비율(집하·간선·분류·배달 몇 %)**: 공개 1차 자료를 찾지 못했다. 과정만 그림으로 보여 주고 비율은 쓰지 않는다.
- **특정 가게가 送料를 상품값에 얼마 얹었는지**: 확인 불가. 「商品価格に含める方法がある」처럼 방법으로만 말한다. 消費者庁도 「配送コストが送料に転嫁されていないことまで確認できなかった」고 했다(F7) — 즉 **전가됐다고도, 안 됐다고도 단정하지 않는다.**
- **기업 의도**: 楽天·Amazon이 "무엇을 노렸다"고 단정하지 않는다. 「仕組みとして〜という働きがある」로 쓴다.
- F2 711円은 **대형 법인 할인 포함 평균**이다. 개인이 창구에서 내는 요금과 다르다는 점을 화면에 적는다. 2026年3月期 통기 수치가 공표되어 있으나 원문을 열지 못했다 → ★확인 후 최신치로 바꿀 수 있다.
- F4의 「약 10% → 6만 명」은 재배달률이 10%일 때의 시산이다. 현재 8.3%에 그대로 붙이지 않는다.
