# CASE #009 QUESTION CHAIN 설계 — 「ドラッグストア、なぜ食品が安い？」

[02 SCRIPT](guide/02_SCRIPT.md) S2·S4·S10 + [00 CORE](guide/00_CORE.md) C2·C3 + [01 PLANNING](guide/01_PLANNING.md) P3. 근거 번호(R1~R18)는 [사전 조사](case009-research.md). 분량 **4,000~5,000자**. 화면은 대본 확정 뒤 [06 DIRECTION](guide/06_DIRECTION.md) 콘티로.

## 0. ANSWER CARD

| 항목 | 내용 |
|---|---|
| 제목 질문(확정) | ドラッグストア、なぜ食品が安い？ |
| 답의 형식 | 이유 |
| 공개 자료로 말할 수 있는 답 | **食品は、儲けるためではなく、客を何度も来させるための値段だから.** 食品の粗利は15%前後、薬は40%台(R5, 옛 자료). 客が何度も来れば、薬・化粧品、そして公的保険から払われる調剤で回収できる(R2·R3·R13) |
| 출처(1차) | JACDS 実態調査(R1·R2) / 経済産業省 商業動態統計(R14) / 各社 決算(R7·R8·R9) / 帝国データバンク(R11) |
| 공개되지 않는 것(첫 1분) | 「食品だけの利益」「商品ごとの原価」はどの会社も公表していない. だから業界統計と決算で"どこで稼いでいるか"を追う |
| 처음 답하는 시각 | **약 2:00**(영상의 1/3 안) |
| 약속과 답의 형식 | 제목=이유 / 최종 답 첫 문장=「答えは――食品は、客を何度も来させるための値段だからだ」 ✅ |
| 상식 점검 | 「薬・化粧品で稼いで食品で客を呼ぶ」는 검색 1위 → **EXPECTED ANSWER(0:50)와 REWARD 1의 반쪽**. 최종 발견은 **"세 번째 지갑(조제·공적 보험)"과 "싼 식품 → 내점 → 조제 → 규모 → 더 싼 식품"의 순환**(06-29 상식 ≠ 실제: 식품을 싸게 팔수록 오히려 이익이 늘었다 R7·R8) |
| ONLY-HERE FACTS | 10兆0,307億円·2万3,723店 / 食品 +13.2%(가장 빠름) / 調剤 1兆5,205億円 +8.4% vs 전국 +1.6% / 粗利 15.1% vs 42.3% / アオキ 食品 51.3%·전 점포 생선식품 / コスモス 販管費 15% vs 21.2% / 비축미 2万トン / 도산 358건 → 8개 ✅ |

**주의(숫자)**: 粗利 15.1%·42.3%는 2019년 보도 → 「2019年の報道では」로만. 調剤 1兆5,205億円은 2차 인용 → 원문 확인 전까지 「と報じられている」. 「スーパーより安い」는 **일반화하지 않는다**(전국 가격 비교 통계가 없음). 「安いと感じる」「安い店を求めて」(R15)로만.

## 4. 썸네일 설계안 (사용자 제작, P5)

- 卵·牛乳가 든 장바구니 + `10兆円` + 「何で稼ぐ？」
- 답(내점·조제)은 쓰지 않는다. 「何で稼ぐ？」의 답은 REWARD 1(약·화장품, 2:00)과 MID REVEAL(조제·보험, 5:30~7:30).
