# CASE #004 QUESTION CHAIN 설계 — 「コインランドリー、人がいないのになぜ儲かる？」

[시청지속 지침 v2.0](KANENAZO_RETENTION_v2.md) 21번 양식. 대본: [cases/case004/script.txt](../cases/case004/script.txt)(사용자 원문: `script_v0_user.txt`). 시각은 CASE #003의 말하기 속도(약 5.55자/초)로 잡은 **예상치**입니다.

- 썸네일 질문(안): 대형 건조기 하나 + 「1155億円」 + 「何を買ってる？」 → Q3에서 회수(17번)

| 항목 | 내용 | 예상 시각 |
|---|---|---|
| CORE MYSTERY | コインランドリーは、人がいないのに、なぜ儲かるのか？ | 0:00 |
| EXPECTED ANSWER | 人件費が少ないから | — |
| QUESTION 1 | 人がいない店は、何で儲けているのか（まず一番分かりやすい答えから） | 0:25 |
| REWARD 1 (SMALL REVEAL) | 人件費は半分正しい。でも実は「高価な設備に働いてもらう店」 | 1:10~1:45 |
| QUESTION 2 | 人の代わりに働く機械は、どうやってお金を生むのか／お金はどこへ | 1:45 |
| REWARD 2 (SMALL REVEAL) | MONEY FLOW ①②③（使うたびの費用 → 固定費 → 設備）。重要なのは機械が「回るか」 | 2:50~4:20 |
| QUESTION 3 | 家に洗濯機があるのに、なぜ回す人がいる？ 1155億円で何を買っている？ | 4:25~4:55 |
| REWARD 3 | 大容量・乾燥・時間（経産省: 家事負担を減らしたい需要） | 5:30~6:40 |
| MID REVEAL | 手間を減らしたいならクリーニング店が伸びそうなのに、店頭型は1540億円で縮小。違いは「客が作業の一部をし、機械がサービスの中心」 | 7:00~8:10 |
| FINAL REVEAL | 「人がいない店」→「機械で時間を売る店」 | 10:10 |
| FINAL ANSWER | 人件費が少ないから、だけではない。客の時間と手間を減らす機械を、何度も回し続けられるからだ。（답을 먼저 말하고 이유） | 9:25 |

## MONEY FLOW 단계 공개

| 단계 | 공개하는 흐름 | 예상 시각 |
|---|---|---|
| 1 | 料金 → 水道・電気/ガス・洗剤（一回動くたび） | 2:05 |
| 2 | ＋ 家賃・清掃・点検・修理・防犯/決済（来ても来なくても） | 2:25 |
| 3 | ＋ 洗濯機・乾燥機そのもの → 残るお金 | 2:50 |
| 완성 | 客（大容量・乾燥・時間を買う）→ 料金 → 費用・設備 → 次の客でもう一度 | 9:10 |
