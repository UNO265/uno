# 육영수 편 쇼츠

영상: `YUK_SHORT.mp4` (47.9초, 1080×1920). 만들기: `python3 video/scripts/yuk_short.py` → `--sound` → `npx remotion render src/yuk/short-index.ts YukShort ... --gl=angle`.

## 설계
- 첫 프레임(0초부터): 큰 탄두 + 큰 숫자 「5발」 + 질문 「그 1발은 어디로?」 + 작은 이름표 「1974 · 육영수 저격 사건」.
- 흐름: 판결의 다섯 발(①②③⑤ → ④만 빨강) → 관통(증언) → 식장 어딘가(점선 고리) → 수거·보관·대조(공개 기록 없음) → 답: 판결은 문세광, 뒤집는 기록 없음, 빈칸 하나 → 본편 안내.
- 본편보다 빠르게 읽는다(1.0배, 문장 사이 0.3초). 자막은 아래에서 560px 위(쇼츠 버튼 영역을 피해서).

## 제목
**육영수를 맞힌 4번째 총알, 기록이 없다** (추천)
- 후보: 판결은 5발, 그 1발은 어디로? / 육영수 사건, 공개되지 않은 한 가지

## 설명
```
판결문에 적힌 총알은 다섯 발.
육영수 여사를 맞힌 네 번째 탄두를 누가 보관했는지, 범인의 총과 대조했는지는 지금도 공개된 기록이 없습니다.
판결은 문세광. 이 결론을 뒤집는 기록도 없습니다. 다만 확인해 줄 기록 하나가 비어 있을 뿐입니다.

▶ 전체 기록: 「육영수를 맞힌 총알은 어디로 갔나」 (본편 링크)
```
