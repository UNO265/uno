## 계산 (대본에서는 「計算」「イメージ」 표시, C4)

**おにぎり 예시(단순화: 원가 80円·가격 100円·10개 입고·チャージ 50%·폐기 원가 본부 15%)**

| | 2개를 버린다 | 2개를 50円으로 판다 |
|---|---|---|
| 매출 | 800円 | 900円 |
| 판 것의 원가 | 640円 | 800円 |
| 売上総利益 | 160円 | 100円 |
| 본부 몫(50%) | 80円 − 폐기 부담 24円 = **56円** | **50円** |
| 가게 몫 | 80円 − 폐기 원가 160円 + 24円 = **−56円** | **50円** |

- 버리는 쪽 → 값을 깎는 쪽: 가게 **−56円 → +50円(차이 106円)**, 본부 **56円 → 50円(차이 −6円)**.
- 결론: 값을 깎으면 가게는 크게 좋아지고 본부는 조금 줄어든다. 본부에게는 깎을 이유가 약하다. 새 계약(50%)이면 버렸을 때 본부 몫은 80 − 80 = **0円** → 본부도 버리는 쪽이 손해가 된다.
- 더 많이 발주할 때(12개 입고, 9개 판매·3개 폐기): 売上総利益 900 − 720 = 180 → 본부 90 − 36 = 54円 / 가게 90 − 240 + 36 = −114円. → 선반을 채우면 본부 몫은 크게 줄지 않고 가게 부담이 커진다.
- 실제 원가율·チャージ율은 가게·계약마다 다르다 → 반드시 「イメージ」.

## 상식 점검 (P3)

- 「コンビニ 値引きしない なぜ」 검색 상위 답: **コンビニ会計(버리면 가게 부담, 깎으면 본부 몫도 줄어든다)**(井出留美 기사 등). → 알려진 답 → **REWARD 1(중간 보상)**.
- 한 층 더(최종 답 후보):
  1. 문제는 "버리는 게 이득"이 아니라 **"누가 버린 값을 내느냐"**. 버린 값은 가게(85%), 깎은 값은 가게와 본부가 함께 → 본부에게는 선반을 채우는 쪽(機会ロス 방지)이 유리한 비대칭(N4·N5·N16).
  2. 그 비대칭이 2009년 명령(N5)·2020년 조사(N2)에도 남았다 → 70%가 깎지 않음.
  3. 지금 바뀌는 이유: 가맹점이 모이지 않고(N11 목적·N15), 인건비·쌀값이 오르고(N15·N17), 식품 로스 목표(N14). 그래서 **본부가 버린 값을 더 내기 시작했다**(2019 포인트 → 2024 エコだ値 원자 → 2027 50%).
  4. 최종: **누가 버린 값을 내느냐가 바뀌면, 버리는 양이 바뀐다.**
