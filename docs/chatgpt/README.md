# ChatGPT에서 이어서 작업하기

세종 편을 만들며 정한 모든 지침을 ChatGPT용으로 정리한 묶음이다.

| 파일 | 넣는 곳 | 내용 |
|---|---|---|
| `01_instructions.md` | 프로젝트(또는 GPT) **지침** 칸에 전문 붙여 넣기 | 역할·사실 원칙·작업 순서·대본 틀·출력 형식 (약 2,200자) |
| `02_knowledge_guide.md` | **파일**로 업로드 | 전체 기준: 구조, 훅, 팩트 원칙, 화면, 자막, 내레이션, 소리, 컷 표, 업로드 |
| `../sejong/sejong-final-script.md` | **파일**로 업로드 (파일명: sejong-final-script) | 완성 대본 예시 |
| `03_prompts.md` | 작업할 때 단계별로 복사 | 주제 → 조사 → 구성 → 대본 → 팩트체크 → 최종 → 컷 표 → 자막·TTS → 업로드 → 회고 |

## 설정 방법

1. ChatGPT에서 **프로젝트**를 새로 만든다(예: "한국사 다큐").
   - 맞춤형 GPT를 만들어도 된다. 그때는 GPT 편집의 "지침"과 "지식"에 넣는다.
2. 프로젝트 설정의 **지침**에 `01_instructions.md` 내용을 그대로 붙여 넣는다.
3. 프로젝트 **파일**에 `02_knowledge_guide.md`와 `sejong-final-script.md`를 올린다.
4. 사실 확인을 위해 대화에서 **웹 검색**을 켠다.
5. 새 대화에서 `03_prompts.md`의 1번 프롬프트부터 시작한다.

## 역할 나누기

- **ChatGPT:** 주제 선정, 사료 조사, 대본, 팩트체크, 컷 표, 자막·TTS 텍스트, 업로드 문구.
- **영상 만들기(이 저장소):** ChatGPT가 만든 **최종 대본 + 컷 표 + TTS용 텍스트**를 가져오면 영상으로 렌더링한다.
  - 렌더링: Remotion, `video/src/sejong/` 참고
  - 음성: Supertonic 3 M2
  - BGM: 자체 합성
- ChatGPT의 답은 사실 오류가 섞일 수 있다. 실록 인용과 숫자는 조선왕조실록 사이트(sillok.history.go.kr)에서 한 번 더 대조한다.
