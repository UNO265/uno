# 단계별 프롬프트 (복사해서 ChatGPT에 붙여 넣기)

`{ }` 안만 바꿔서 쓴다. 한 단계씩 진행하고, 결과를 확인한 뒤 다음 단계로 넘어간다.

---

## 1. 주제 고르기
```
지식 파일 1장의 주제 조건 5가지로 {주제 후보 또는 "새 후보 5개를 찾아줘"}를 평가해줘.
주제마다 ① 훅이 될 1차 사료 한 줄 ② 반전 증거 ③ 현대 공감 프레임 ④ 영상 전체를 꿰는 물건 하나와 화면 효과 하나 ⑤ 사실 확인이 필요한 위험 요소를 표로 정리하고, 추천 순위를 매겨줘.
확인할 수 없는 사실은 "확인 필요"로 표시해.
```

## 2. 사료 조사·팩트 표
```
주제는 {주제}야. 대본에 쓸 사실을 조사해서 팩트 표로 정리해줘.
형식: # | 사실 | 연도·출처(실록 몇 년 몇 월 등) | 확실성(✅/⚠️/❓) | 대본에서 쓸 방법
특히 ① 인물 본인이 남긴 인용 3~5개 ② 숫자 카운터로 쓸 숫자 ③ 반전 증거 ④ 흔히 알려졌지만 틀린 속설을 꼭 찾아줘.
웹 검색이 되면 출처 링크를 달고, 안 되면 "원문 대조 필요" 목록을 따로 만들어줘.
```

## 3. 구성안(질문 사다리)
```
위 팩트 표로 지식 파일 2장의 대본 틀(훅·프롤로그·1~5장·에필로그)에 맞춘 구성안을 만들어줘.
파트마다 ① 제목 ② 이 파트가 답하는 질문 ③ 다음 파트로 넘기는 질문 ④ 쓸 사실(팩트 표 번호) ⑤ 현대 번역 문장 한두 개 ⑥ 감정을 적어줘.
훅은 25초 안에 끝나게 초 단위로 설계해줘.
```

## 4. 대본 초안
```
구성안대로 한국어 내레이션 대본 초안을 써줘. 약 4,300음절, 15~16분 분량.
규칙: 짧은 문장, 쉼표 최소화, 연도는 한자어·나이는 고유어로 읽히게, 과장 표현 금지, 병명·속마음 단정 금지.
기록에 없는 대사는 【재구성】, 후대 일화는 【야사】, 학설은 【가설】, 해석은 【해석】으로 표시해.
마지막 20초(최종 화면)에는 내레이션이 없게 끝내줘.
```

## 5. 팩트체크·수정
```
방금 대본을 팩트체크해줘. 지식 파일 3장의 형식(원문 서술 | 판정 | 확인된 내용·수정 방향 | 출처)으로 표를 만들고,
❌·❓ 항목은 고친 문장을 제안해줘. 주제·결론·구조는 바꾸지 말고 사실 수정·표현 개선·중복 제거만 해줘.
```

## 6. 최종 대본
```
수정 사항을 반영한 최종 대본을 줘. 파트 제목 [ ]과 내레이션만, 읽는 그대로 코드 블록 하나로.
끝에 전체 음절 수와 예상 길이(쉼 포함 초당 약 5음절 기준)를 한 줄로 알려줘.
```

## 7. 장면 설계(컷 표)
```
최종 대본으로 지식 파일 8장 형식의 컷 표를 만들어줘.
- 내레이션 줄은 대본 문장을 그대로 옮기고, 한 컷에 1~4줄, 한 컷 15초 이내.
- 장면 타입은 8장 목록에서 고르고, 없으면 new로 적어서 물체·배치·움직임을 구체적으로 써줘.
- 글자만 있는 카드가 연달아 나오지 않게, 개념은 물건 하나로 보여줘.
- 효과음은 한 장에 3~5개, 강조 장면에만.
- 영상 전체를 꿰는 화면 효과(예: 흐림 0~1 값)의 흐름도 컷마다 적어줘.
```

## 8. 자막·TTS용 텍스트
```
최종 대본을 두 가지로 바꿔줘.
① 자막용: 마침표·쉼표 없이, 한 줄 약 22자(최대 두 줄), 문장 흐름대로 줄바꿈(" / "로 표시). 핵심어 하나를 **굵게** 표시.
② TTS용: 문장 단위, 숫자는 한글로 풀어 쓰기(1439년 → 천사백삼십구년), 쉼표는 호흡이 필요한 곳에만, 발음이 헷갈리는 말은 소리 나는 대로.
두 개를 표로 나란히 보여줘.
```

## 9. 제목·설명·썸네일·쇼츠
```
지식 파일 9장 기준으로 업로드 정보를 만들어줘.
① 제목 후보 3개(공감형/숫자·대립형/사료형)와 추천 하나 ② 설명란 전문(챕터는 {실제 챕터 시각} 사용) ③ 태그
④ 썸네일 안 2개(실루엣 + 큰 글자 하나 + 짧은 한 줄) ⑤ 쇼츠 4편(한 편에 사실 하나, 첫 문장·마지막 문장 포함).
```

## 10. 회고
```
공개한 영상의 데이터야: {클릭률, 평균 시청 지속 시간, 30초 유지율, 이탈이 큰 구간, 대표 댓글}.
지식 파일 10장 기준으로 원인을 분석하고, 다음 영상에서 바꿀 규칙을 지식 파일 장 번호별로 정리해줘.
```
