# 한국사 다큐 채널 제작 가이드 (ChatGPT 지식 파일)

세종 편(「고기 없인 못 살던 왕과 꺼지지 않는 편전의 불빛」, 15:47)을 만들며 정한 기준과 회고를 한 문서로 모았다. 새 영상은 이 문서를 기준으로 기획·대본·장면 설계·업로드 정보까지 만든다.

---

## 1. 채널의 틀: "위인의 이면 · 사료 탐사형"

모두가 아는 인물(교과서·지폐·드라마)의 알려지지 않은 이면을, 그 인물이 직접 남긴 기록으로 따라간다. 해설자가 주장하는 영상이 아니라 **기록이 말하게 하는** 영상이다.

### 1-1. 주제 조건 (5개 중 4개 이상)
1. 누구나 아는 인물·물건
2. 본인이 남긴 생생한 1차 사료 (실록 속 발언, 편지, 일기)
3. 현대 공감 프레임 (직장, 건강, 가족, 돈, 시험 중 하나)
4. 반전 증거 (이미지와 반대되는 기록, 또는 적·반대편이 남긴 증언)
5. 오늘과의 연결 (지금 우리가 쓰는 것·사는 방식과 이어지는 고리)

"1차 사료 한 줄(훅)"과 "반전 증거"가 없으면 주제를 바꾼다.

### 1-2. 다음 주제 후보 (세종 편 이후)
| 순위 | 주제 | 핵심 사료·반전 | 주의 |
|---|---|---|---|
| ★1 | 정조의 비밀편지 297통 | 1796~1800년 정적 심환지에게 보낸 사신(『정조어찰첩』, 2009 공개). "나는 태양증이 있어 부딪치면 바로 폭발한다", 공식 석상과 반대로 미리 짜 맞춘 상소 | 거친 표현은 번역 원문 확인. 독살설은 가설로만 |
| ★2 | 황희의 두 얼굴 | 세종실록 속 뇌물·청탁 의혹 기사와 사관 논평('황금 대사헌', 1428). 실록 편찬 때 삭제 논쟁 → "사초는 고치지 않는다"는 원칙으로 남김 | 의혹과 사실 구분. 사관 개인 원한이라는 당대 반론도 소개 |

| 4 | 조선 왕들의 진료기록 | 평균 사망 나이 약 46세, 가장 흔한 병은 종기(문종·성종·효종·정조·순조) | 통계 출처를 화면에 명시. 인물 3명으로 좁히기 |

## 2. 대본 구조

### 2-1. 파트와 비율 (15~16분, 약 4,300음절)
| 파트 | 비율 | 할 일 | 감정 |
|---|---|---|---|
| 훅 | 5% | 1차 사료 한 줄 → 의외의 사실 2~3개 → 인물 공개 → 반전 예고 (25초 이내) | 궁금증 |
| 프롤로그 | 5% | 재구성 장면 하나 + 핵심 질문 | 긴장 |
| 1장 | 15% | 가벼운 이면 (식성·습관·취미) | 호기심·유머 |
| 2장 | 17% | 무거운 이면 (병·고통·실패), 본인의 말로 증명 | 연민 |
| 3장 | 20% | 주변 인물 2~3명으로 확장, 숫자 카운터 | 블랙코미디 |
| 4장 | 8% | 핵심 질문에 대한 해석 (짧게) | 숙고 |
| 5장 | 17% | 결과·업적 + 반전 증거 | 경외 |
| 에필로그 | 10% | 오늘과 연결 + 양면 결론 + 양자택일 질문 | 성찰 |

### 2-2. 질문 사다리 (세종 편 예)
이 온화한 왕이 왜 최악의 상사였나 → 고기 집착은 식탐이었나 → 그 생활이 몸에 무엇을 남겼나 → 그 몸으로 일했다면 신하들은 → 그들은 왜 떠나지 않았나 → 무엇이 남았고 누가 증명하나 → 나라면 어떻게 할까.
장마다 마지막 문장이 다음 장의 질문을 만든다.

### 2-3. 효과가 확인된 장치 7가지
1. **1차 사료 콜드 오픈:** 첫 문장을 인물의 실제 말로 연다.
2. **위인 vs 인간 대비:** 지폐 속 온화한 얼굴 ↔ 당뇨·안질·지팡이.
3. **현대 직장 번역:** 퇴사 불가, 재택근무, 종합병원, 에너지 드링크.
4. **본인의 말로 증명:** 해설 대신 인물의 고백(세종이 직접 말한 병 목록).
5. **숫자 카운터:** 황희 70 → 87 → 90세.
6. **적의 증언(반전):** 한글을 반대한 최만리 상소가 오히려 한글 작업을 증명.
7. **양면 결론 + 양자택일 질문:** "가혹한 상사이자 가장 혹독했던 자신" / "응답하겠는가, 도망치겠는가".

### 2-4. 훅 설계 (세종 편 실제 예)
| 시간 | 내용 |
|---|---|
| 0~5초 | "한 걸음 앞에 사람이 있는 건 알겠는데, 그게 누구인지는 모르겠다." (세종실록 1439) |
| 5~15초 | 병 목록 3개 (당뇨, 등 통증, 지팡이) |
| 15~25초 | 일흔 살 재상의 사직서 반려 + 재택근무 명령 |
| 25~35초 | "지금 여러분이 읽고 있는 글자를 만들었다" → 세종 공개 |
| 35~45초 | "그 사실을 증명한 건 한글을 반대한 신하들이었다" (5장에서 회수) |

- 인물은 숨기지 않는다(제목·썸네일에 이미 보인다). 숨길 것은 이유와 반전이다.
- 훅의 모든 문장은 확인된 사실만 쓴다. 첫 30초의 오류는 댓글에서 바로 무너진다.
- 다음 영상부터는 반전 예고까지 25초 안에 끝낸다(세종 편은 35초로 길었다).

### 2-5. 톤·균형
- 과로·희생을 감동으로만 포장하지 않는다. "숭고했다"와 "가혹했다"를 둘 다 사실로 남긴다.
- 해석 파트(4장)는 짧게, 증거가 있는 파트로 곧바로 넘어간다.
- 개념 설명(삼년상·기복 같은 용어)은 글자 카드가 아니라 "물건 하나"로 보여 줄 수 있게 쓴다.

## 3. 사실 확인 원칙

1. 숫자·연도·인용을 지어내지 않는다. 출처를 찾을 수 없으면 삭제하거나 "확인 필요".
2. 표시 규칙: 기록에 없는 대사 【재구성】, 후대 일화 【야사】, 학설 【가설】, 제작진 해석 【해석】. 이 표시는 영상 화면 구석에도 작게 넣는다.
3. 병명·동기·속마음 단정 금지. 확신의 강도는 기록의 강도에 맞춘다.
4. 우선 출처: 조선왕조실록(sillok.history.go.kr), 한국민족문화대백과사전(encykorea.aks.ac.kr), 우리역사넷(contents.history.go.kr), 승정원일기.
5. 팩트 표 형식: `# | 원문 서술 | 판정(✅확인 / ⚠️부분·과장 / ❌틀림 / ❓출처 없음) | 확인된 내용·수정 방향 | 출처`

### 세종 편에서 실제로 틀렸던 것 (같은 실수 방지)
| 원래 서술 | 사실 |
|---|---|
| 실록 '고기' 언급 432회 vs 165회 | 출처 없음 → 삭제 |
| 관절 때문에 지팡이 | 기록상 눈 때문("어두운 곳은 지팡이가 아니면 걷기 어렵다") |
| 말년에 1미터 앞도 못 봄 | 1439년, 마흔 초반의 기록 |
| 세자에게 정사를 넘기지 않았다 | 1442 첨사원 설치, 1445부터 서무를 세자가 결재 |
| 황희 89세 은퇴 | 1449년 87세 은퇴, 1452년 90세 사망 |
| 특급 가마를 내렸다 | 궤장(안석과 지팡이) 제도 |
| 신숙주에게 곤룡포 | 후대 야사, 담비 갖옷 |
| 앙부일구를 광화문에 | 혜정교와 종묘 앞 |
| 500년 전 | 1418년 즉위 = 약 600년 전 |
| 포계는 세종을 위해 개발한 치킨 | 『산가요록』 수록, 기름에 지지는 요리 |
| 강직성 척추염과 완벽히 일치 | 일부 전문의의 가설 |
| "나는 두 눈이 멀어도…" 같은 명대사 | 기록에 없는 창작 → 삭제 |

## 4. 화면(애니메이션) 스타일

### 4-1. 기본
- 바탕: 한지(밝은 미색)와 먹(어두운) 두 가지.
- 그림: 먹선 실루엣. 얼굴·표정은 그리지 않는다. 뒷모습·옆모습·손·물건 위주.
- 색: 먹색·미색·옅은 회색 + 촛불 주황 하나(강조·도장은 빨강).
- 움직임: 천천히 확대·이동, 촛불 흔들림, 먹 번짐으로 글자 등장, 2~3겹 레이어 시차.
- 영상 전체를 꿰는 물건 하나 + 화면 효과 하나(세종 편: 촛불 = 수명, 시야 흐림 → 훈민정음에서 선명).

### 4-2. 회고에서 정한 개선점
- **크게:** 화면 속 설명 글자는 1080p 기준 최소 32px. 핵심 그림은 화면 높이의 절반 이상.
- **자주 바꾸기:** 한 컷 안에서도 물체 추가·확대·카메라 이동·강조 표시로 변화를 준다. 글자만 있는 카드를 연달아 두지 않는다.
- **깊이감:** 실내 장면은 기둥·인물·배경을 층으로 나누고, 벽에 흔들리는 촛불 그림자와 먼지를 넣는다.
- **수묵 연출:** 먹 번짐 전환, 붓 획 순서로 그려지는 제목, 쾅 찍히는 실록 도장.
- **지도:** 손으로 그리지 말고 공개 지도 데이터(Natural Earth, 퍼블릭 도메인)를 쓴다.
- **인물 실루엣:** 왕은 익선관(뒤로 솟은 두 날개)·곤룡포, 신하는 사모(양옆 날개)·단령. 엎드린 자세는 머리·등·소매가 구분되게. 숨쉬기·고개 숙이기·책장 넘기기 같은 작은 동작을 넣는다.
- **자막 영역:** 화면 아래 약 20%는 자막 자리로 비워 둔다.

### 4-3. 저작권
- 왕의 표준영정(저작권 존속 가능)과 지폐 도안(한국은행 이용 기준)을 그대로 쓰지 않는다. 자체 실루엣·일러스트로 대체한다.
- 실제 사진·영상은 사용권이 확인된 것만 쓴다. 공개되어 있다는 이유만으로 쓰지 않는다.
- 음악은 자체 제작 또는 저작권이 정리된 음원만 쓴다.

## 5. 자막 규칙
- 반투명 어두운 상자 + 흰 글씨. 글꼴은 부드러운 계열(고운돋움/고운바탕).
- **마침표·쉼표는 쓰지 않는다.** 물음표와 인용 따옴표는 남긴다.
- **가능하면 한 줄(약 22자 안팎), 길 때만 두 줄.** 세 줄은 쓰지 않는다.
- 줄바꿈은 문장 흐름대로: 쉼표 자리 → 절 경계 → 어절 사이 순서로 끊는다. 보조 용언 앞("읽고 / 있는"), 꾸미는 말 뒤("한 / 왕")에서는 끊지 않는다.
- 핵심어(숫자·이름·핵심 개념)만 한 줄에 하나 정도 색으로 강조(주황 또는 빨강).
- 자막은 내레이션 발화 시간에 맞춰 나눈다.

## 6. 내레이션
- 목소리: 차분한 남성 중저음 다큐 톤. 세종 편은 Supertonic 3 **M2**(상업 이용 가능, OpenRAIL-M). 채널 목소리는 계속 같은 것을 쓴다.
- 속도: 쉼 제외 초당 약 6.8음절(세종 편 기준). 인용문은 반 박자 쉬고 조금 낮고 느리게, 사극 연기 금지.
- **문장 단위로 합성**한다(자막 줄 단위로 합성하면 문장 중간에서 억양이 끊긴다).
- 합성용 텍스트는 자막 텍스트와 따로 만든다: 숫자는 한글로 풀고(1439년 → 천사백삼십구년, 87세 → 여든일곱 살), 쉼표는 호흡이 필요한 곳에만, 잘못 읽는 말은 발음대로 고쳐 쓴다(예: 소갈증[소갈쯩]).
- 대본을 쓸 때부터 쉼표를 줄인다.

## 7. 소리
- 효과음은 강조 장면에만, 한 장에 3~5개: 실록 도장, 사직서 반려, 연도·숫자 등장, 반전 공개, 장 제목, 에필로그 영수증. 내레이션 단어와 겹치지 않게 문장 사이에 둔다.
- BGM은 흐름에 따라 바꾼다: 오프닝 긴장 / 기록 전달(담담) / 고통(무겁게) / 반전(정적 → 전환) / 에필로그(여운). 전환은 문장 끝 쉼에서 1~2초 크로스페이드. 반전 직전엔 잠깐 비운다.
- 악기 방향: 가야금풍 뜯는 현, 낮은 드론, 대금풍 긴 소리.
- **마지막 20초는 YouTube 최종 화면용으로 비운다.** 인사말은 그 전에 끝내고, 화면은 어두운 한지 + 촛불 정도로 단순하게.

## 8. 장면 설계(컷 표) 형식

대본이 확정되면 아래 표로 장면을 설계한다. 영상 제작 도구(Remotion)로 옮길 때 이 표를 그대로 쓴다.

| 컷ID | 파트 | 장면 타입 | 화면 내용(구체적으로) | 내레이션 줄(대본 그대로) | 표시(재구성·야사·가설·해석) | 흐림 0~1 | 효과음 |
|---|---|---|---|---|---|---|---|

- 컷ID 규칙: 훅 H01~, 프롤로그 P01~, 장 C100·C101… (C100 = 1장 제목), 에필로그 E00~.
- 한 컷에 내레이션 1~4줄. 한 컷이 15초를 넘지 않게 한다.

### 장면 타입 (이미 만들어져 바로 쓸 수 있는 것)
| 타입 | 화면 |
|---|---|
| quote | 어두운 바탕 + 큰 인용문 + 출처 |
| word | 핵심 단어 하나(+ 한자, 한 줄 설명) |
| list | 제목 + 체크 목록(줄마다 하나씩 등장) |
| flip | A가 지워지고 B가 나타남(+ 셋째 단어) |

| counter | 큰 숫자 카운터(나이·개수) |

## 9. 업로드 정보

### 9-1. 제목
- 검색어(인물 이름)를 앞에, 30자 안팎. 의문·대립·역설·의외의 숫자 중 하나를 넣는다.
- 후보 3개를 성격과 함께 제시한다: 공감형(클릭 안정) / 숫자·대립형(차별화) / 사료형(신뢰).
- 세종 편 예: 「세종대왕 밑에서 일하면 생기는 일」, 「87세까지 퇴사 못 한 황희, 세종의 신하들」, 「세종대왕이 직접 털어놓은 병, 실록에 남은 왕의 몸」.

### 9-2. 썸네일
- 인물 실루엣(뒷모습·촛불 역광) + 큰 글자 하나 + 짧은 한 줄. 예: 「87세 퇴사 불가」, 「사직서 반려」 + 도장.

### 9-3. 설명란 틀
```
(두 줄 요약: 의외의 사실 + 인물)

(영상 소개 2~3줄)

▶ 챕터
00:00 (훅 제목)
…

▶ 참고 자료
· (실록·원전 이름과 출처)
※ '재구성 장면' 표시가 있는 장면은 기록을 바탕으로 재구성한 것입니다.
※ (가설·해석에 대한 주의 문구)

▶ 제작
· 내레이션: AI 음성 합성 (목소리 이름)
· 음악·효과음: 자체 제작

(댓글 질문 한 줄)

#인물 #키워드 #조선왕조실록 #한국사
```
- 챕터 시각은 완성된 영상의 실제 시각으로 적는다. 카테고리는 교육.

### 9-4. 쇼츠 (롱폼 축약이 아니라 한 편에 사실 하나)
세종 편 예: 태종의 유언 "고기를 먹여라" / 황희 87세까지 사표 반려 / 세종이 털어놓은 병 목록 / 한글 반대 상소가 증명한 것.

### 9-5. 정책 주의
- AI 음성·이미지를 쓰더라도 원문 사료 제시, 채널 고유의 해석, 영상마다 다른 연출이 있어야 "진정성 없는 콘텐츠"로 분류되지 않는다.
- 실제 인물을 사실처럼 보이게 만든 실사 합성 영상이 없으면 AI 공개 표시는 필수가 아니지만, 설명란에 AI 음성 사용을 적는다.
