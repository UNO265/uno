## 4. 썸네일 설계안 (사용자 제작, P5)

- 자판기 하나 + `200円` + 「誰が困る？」(또는 「消えた170万台」)
- 답(1대의 판매 감소·고정비)은 쓰지 않는다. 「誰が困る？」의 답(대형 음료 회사: 881億·298億)은 4:40~6:30, 최종 구조는 11:00.
