## 2. 대본의 사실 사용 원칙

- 팝콘 원가는 숫자 대신 「値段の、ほんの一部」로 표현한다. 원료가 싸다는 것은 일반적 사실이고, 미국의 이익률 80%는 출처를 밝혀 「アメリカの大手チェーン」으로 한정한다.
- 일본 영화관의 매점 비율은 확인된 수치가 없으므로 「重要な収入源」 + TOHO 결산의 「飲食収入も寄与」까지만 말한다.
- 「平均1454円のおよそ半分」은 계산된 목안이다. 화면에는 「目安」 표시를 붙이고, EVIDENCE 라벨은 1454엔(映連)에만 붙인다.
