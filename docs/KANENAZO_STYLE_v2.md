> 브랜드는 같게, 장면은 새롭게, 정보는 더 실제적으로, 오디오는 더 자연스럽게.
> 기본 지침 [KANENAZO_GUIDE.md](KANENAZO_GUIDE.md)(v1)는 그대로 유효하며, 이 문서가 충돌 시 우선한다.

## 0. 유지하는 브랜드 자산 (변경 금지)
KANENAZO / カネナゾ · 「身近なお金の謎を解く。」 · CASE #00X · 경제 미스터리 다큐 구조 · CLUE · EVIDENCE · MONEY FLOW · 핵심 숫자 시각화 · 단계적으로 깊어지는 질문 · 아이보리/베이지 + 네이비 + 포인트 컬러 · 절제된 플랫 그래픽 · 실제 근거자료 기반 설명 · 마지막에 처음 질문 회수 · KANENAZO 고정 엔딩.
목표는 "다른 영상"이 아니라 **"CASE #001보다 한 단계 더 실제 다큐멘터리"**.

## 1. CASE #001의 핵심 개선점
15~16분 동안 "아이보리 배경 + 플랫 일러스트 + 하단 네이비 자막" 질감이 오래 유지됐다. 배경색 변경이나 애니메이션 추가가 아니라 **서로 다른 종류의 화면을 교차**시켜 해결한다.

## 2. 화면 타입 (최소 6종 운영)
| 타입 | 내용 |
|---|---|
| A | KANENAZO 기본 플랫 모션그래픽 |
| B | 실제 EVIDENCE / 공식자료 / 문서 |
| C | 숫자 중심 화면 |
| D | 그래프 / 비교표 / MONEY FLOW / 구조도 |
| E | 사진 또는 실제 영상 / B-roll |
| F | 미스터리 질문 / 암전 / 패턴 브레이크 |
| G | 타이포그래피 중심 핵심 문장 |
| H | 지도 / 시간축 / 역사 흐름 |

한 타입이 지나치게 오래 이어지지 않게 한다(예: A→A→C→B→A→F→E→D→A→G→B→A). 기계적 반복 순서는 금지.

## 3. 베이지 = '홈 베이스'
베이지는 설명·CLUE·구조도·MONEY FLOW·숫자 등 KANENAZO 기본 화면의 공간. 실제 자료는 자료 자체의 색감을 살리고, 중요 질문은 어두운 배경, 핵심 숫자는 화이트/단색 배경도 허용.

## 4. 실제 자료 먼저 조사
순서: **조사 → 실제 자료 발견 → 스토리 설계 → 대본 → 장면 설계**.
실제 자료 우선 대상: 실제 기업·매장·제품, 역사적 인물, 과거 광고, 공식 통계, 기업 결산, 정부자료, 공식 역사자료, 실제 가격·점포·패키지 변화.
인터넷에 있다는 이유만으로 사용 가능하다고 판단하지 않는다. **정보 출처와 사용권은 별도 확인.**

## 5. 실제 자료 목표
전체의 약 **25~40%** 에서 실제 자료 또는 실제 자료 기반 화면. 비율을 억지로 맞추지 않되 "계속 일러스트만 본다"는 느낌을 주지 않는다. 자료 확보가 어려운 주제는 공식 통계·문서 기반 EVIDENCE 비중을 높인다.

## 6. EVIDENCE = 주장의 근거
EVIDENCE가 나오면 반드시 지금 주장을 뒷받침하는 근거가 있어야 한다.
```
EVIDENCE #03
기업 공식 결산자료
売上 ○○億円 / 前年比 +○○%
SOURCE: ○○株式会社 決算資料
```
문서 전체가 아니라 **핵심 부분을 확대**하고 형광펜·밑줄·화살표로 강조.

## 7. EVIDENCE와 일반 그래픽 구분
실제 사진·공식 문서가 없는 개념 일러스트에는 **EVIDENCE 라벨을 붙이지 않는다.** EVIDENCE = 실제 근거가 존재하는 장면.

## 8. placeholder 금지
빈 사진 프레임 + 실루엣처럼 "아직 사진이 안 들어간 자리"로 보이는 화면을 만들지 않는다. 사진이 없으면 처음부터 완성된 정보 그래픽(실루엣 + 이름 + 연도 + 핵심 사건 등)으로 설계.

## 9. 첫 30초
| 시간 | 내용 |
|---|---|
| 0~5초 | 이상하거나 흥미로운 현상 |
| 5~8초 | 첫 질문 |
| 8~20초 | 왜 이상한지 보여주는 증거 |
| 20~30초 | 질문을 한 단계 깊게 |
| 30초 전후 | KANENAZO CASE #00X (흐름을 억지로 끊지 않음) |

## 10. 질문은 반복하지 않고 발전
예: 「なぜ、こんなに安い？」→「それでも、なぜ利益が残る？」→「では、誰が儲けている？」→「そのお金は、どこから来る？」. 표현만 바꾼 반복 금지. 질문은 스토리를 움직이는 장치.

## 11. 60~90초마다 시각적 리셋
베이지 그래픽 → 실제 자료 → 암전 → 질문 → 실제 영상 → 그래프처럼 질감을 크게 바꾼다. 암전이 필수는 아니다. 목적은 "새 챕터에 들어왔다"는 감각.

## 12. 패턴 브레이크 다양화
갑작스러운 무음, 실제 사진 전환, 화면 전체 숫자, 그래프 급변, 한 문장만 남기기, 자료 속으로 들어가는 카메라, 지도, 시간축, MONEY FLOW 전환, 좌우 비교, 모든 요소 제거 후 질문 하나. **패턴 브레이크 자체가 반복 패턴이 되지 않게.**

## 13. 하단 자막 사용량 감소
화면이 이미 같은 내용을 명확히 보여주면(예: 중앙 「年間売上 1兆円」) 하단에 반복하지 않는다. 일반 설명 장면에서는 사용. 목표: "항상 자막이 있는 영상"이 아니라 "필요할 때 자막이 나타나는 영상".

## 14. 자막 박스 존재감 감소
배경 투명도 조절, 박스 높이 최소화, 짧은 문장은 박스 없이, 중요 단어만 강조, 중앙 타이포 장면은 하단 자막 제거. 스마트폰 가독성은 유지.

## 15. 한 장면 = 한 메시지
숫자·화살표·텍스트·아이콘을 한꺼번에 몰아넣지 않는다. 복잡한 구조는 순차 등장.

## 16. 숫자는 하나의 장면
「1兆円」만 중앙에 크게 → 「10年前の1.5倍」 추가 → 그래프. **숫자 → 의미 → 비교** 순.

## 17. 그래프는 움직인다
처음부터 전체를 보여주지 않는다. 선이 그려지고 막대가 오르고 특정 연도가 강조된다. 내레이션 「しかし、2022年から——」와 동시에 2022년 지점 강조(**내레이션과 동기화**).

## 18. MONEY FLOW = 핵심 자산
상품/서비스 → 한 방향, 돈 ← 반대 방향. 매번 같은 도식이 아니라 주제에 맞게 변형(예: 消費者↓店舗↓本社↓供給業者 / 広告主→Platform→Creator).

## 19. CLUE 개수는 내용이 결정
3개면 3개, 5개면 5개. 억지로 쪼개지 않는다. 중요한 발견이 있을 때만 등장.

## 20. CLUE 번호와 내레이션 충돌 방지
대본 단계에서 CLUE 번호와 내레이션을 **동시에 검증**. 「一つ目/二つ目」보다 「まず」「もう一つ」「さらに重要なのが」 같은 연결어 우선.

## 21. 실사/B-roll은 장식 금지
실사는 ① 실제 장소 ② 실제 제품 ③ 실제 과정·행동 ④ 주장의 현실감 ⑤ 시대·장소의 분위기 중 하나를 해야 한다. 아니면 KANENAZO 그래픽이 낫다.

## 22. 일본어 내레이션 우선 설계
**최종 대본 → 최종 일본어 음성 → 실제 발화 길이 → 장면 길이 → 자막 → 모션 → BGM/SFX.** 임시 TTS로 길이를 먼저 확정하지 않는다.

## 23. 일본어 음성 품질
자연스러움·차분함·지적·신뢰감·경제 다큐 적합·광고/애니 톤 배제·AI 기계음 최소·장시간 피로 없음. 질문과 결론에서 속도와 여백 활용. 문장마다 같은 억양 반복 금지.

## 24. BGM은 배경
BGM이 계속 귀에 인식되지 않게. 전자 노이즈·지지직·글리치·고주파 texture 금지. 미니멀·절제된 긴장·부드러운 저역·자연스러운 리듬·은은한 피아노/퍼커션. 같은 루프 반복 금지.

## 25. 효과음 사용량 감소
모든 움직임에 넣지 않는다. whoosh·click·beep·coin·glitch 반복 금지. 목표는 "효과음을 인식"이 아니라 "화면 변화가 자연스럽게 느껴짐".

## 26. 무음 활용
중요 질문 직전·예상 밖의 숫자·결론 직전에는 BGM을 줄이거나 잠시 제거. 오디오 오류처럼 느껴질 만큼 길게 비우지 않는다.

## 27. 오디오 노이즈 금지 (렌더링 전 확인)
static noise · 지지직 · clipping · distortion · 불필요한 고주파 · 전자 글리치 · 부자연스러운 ducking · 장면 사이 오디오 단절 · 반복 BGM · 반복 SFX.

## 28. 길이를 먼저 정하지 않는다
권장 약 12~20분이지만 기계적으로 맞추지 않는다. 시청시간을 늘리기 위한 반복 설명 금지.

## 29. 챕터마다 새로운 질문
답이 다음 질문을 만든다. 예: 왜 싸지? → 대량 구매 → 그것만으로 가능한가? → 상품 구성의 비밀 → 그렇다면 누가 비용을 부담하는가?

## 30. 비교는 한눈에
좌우 분할·숫자·가격·화살표·전략 키워드로 **2~3초 안에** 차이를 이해하게.

## 31. 엔딩은 '요약'이 아니라 '해결'
「つまり——」 → 핵심 구조(CLUE 합체, MONEY FLOW 또는 핵심 도식 완성) → 최종 문장 → KANENAZO 엔딩.

## 32. KANENAZO 고정 엔딩
KANENAZO / カネナゾ → 「身近なお金の謎を解く。」 → 「では、次の謎で。」. 길게 만들지 않는다.

## 33. 제작 전 대본 분석
대본을 받으면 즉시 영상 생성 금지. 먼저 HOOK · QUESTION · CLUE · EVIDENCE · MONEY FLOW · 실제 자료 · 숫자 · 그래프 · 비교 · 패턴 브레이크 · 결론을 표시한 뒤 장면 설계.

## 34. 장면 설계 기록 항목

## 36. CASE #002의 목표
애니메이션·효과음·화려함을 늘리는 것이 아니다. **더 실제적이고, 더 신뢰감 있고, 더 다양한 화면 질감, 더 자연스러운 일본어와 오디오, 더 강한 스토리텔링.** "AI가 만든 경제 설명 영상"이 아니라 "KANENAZO라는 제작팀이 만든 일본 경제 미스터리 다큐멘터리"처럼 보여야 한다.

## 37. 기본 스토리 구조 (CASE #001에서 계승)
현상 → 질문 → 증거 → CLUE → 구조 → 새로운 질문 → EVIDENCE → MONEY FLOW → 비교/반전 → 모든 CLUE 회수 → 답

## 38. 최우선 원칙
"이 화면은 왜 존재하는가?" 답은 반드시 ① 지금 말하는 내용을 이해시킨다 ② 근거를 보여준다 ③ 다음 이야기가 궁금해지게 만든다 중 하나. 아니면 삭제하거나 다시 설계.
