|---|---|
| 제목 질문 | **タクシー1000円、運転手に残るのは？**(사용자 확정 2026-10-09) |
| 답의 형식 | 숫자 |
| 공개 자료로 말할 수 있는 답 | 東京23区では、1000円のうち運転手の人件費は約700円（社会保険など込み、給料としては約6割）。会社に残る利益は約26円（関東運輸局の原価、計算） |
| 출처 | ①関東運輸局 2026-03 運賃改定の原価(T1~T3) ②東京ハイタク協会 輸送実績(T11) ③全タク連/厚労省 賃金統計(T12) ④国交省 運賃の決め方(T6·T14) |
| 비공개와 처리 | 「会社ごとの歩合率（運転手の取り分）は公表されていない。でも運賃を上げるとき、国に出す原価は公表される」(0:30대) |
| 처음 답하는 시각 | 약 1:50(15%) |

- 주제: タクシー(도쿄 23구 기준, 오사카·나라 비교)
- 제목: タクシー1000円、運転手に残るのは？
- 썸네일 질문(안): 택시 + `1000円` + 「会社は？」(회사에 얼마 남나) → 답 1:50(26円). 최종 답(빈 차 시간)은 쓰지 않는다

## 설계

| 항목 | 내용 | 예정 시각 | 근거 |
|---|---|---|---|
| CORE MYSTERY | 도쿄 택시는 4년에 두 번 올랐다(2022 +14%, 2026 +10%). 그런데 운전사는 7년에 3할 줄었다. 값을 올려도 운전사가 안 온다 | 0:00~0:30 | T1·T13 |
| EXPECTED ANSWER | 「회사(또는 앱)가 많이 떼 간다」 | — | |
| QUESTION 1 | 1,000円 내면, 운전사에게 얼마 남나? | ~0:30 | |
| REWARD 1 | 국가에 내는 원가로 1,000円 분해: 운전사 인건비 약 708円 / 연료 37 / 차 26 / 관리 등 약 200 / **회사 이윤 26円**. 예상과 반대로 회사는 거의 남지 않는다. 급여로는 약 6할(계산) | 1:00~2:30 | T2·T14 |
| QUESTION 2 | 그럼 운전사는 잘 버나? 왜 모자라나? | 2:30 | |
| REWARD 2 | 연수입 450만円 vs 전 산업 546만円, 월 192시간, 평균 56.8세. 오르긴 했다(+8.7%) | 2:30~4:00 | T12 |
| QUESTION 3 | 값을 올리면 그 돈은 어디로 가나? 왜 운전사 수입이 따라잡지 못하나? | 4:00 | |
| MID REVEAL | **요금은 국가가 「든 비용 + 적정 이윤」으로 정하고, 운전사 몫의 비율을 지키도록 사정한다** → 인상분의 약 7할은 운전사에게. 하지만 운전사 수입 = 단가 × **하루에 몇 번 태우나**. 도쿄 1대 하루 61,753円(5년 +20%)인데 **달린 거리의 절반 이상은 빈 차**(실차율 47.5%), **차의 3할은 운전사가 없어 차고에** 있다(실동률 68.6%) | 4:30~8:00 | T5·T6·T11 |
| 세 시점 S10 | ① 타는 사람: 1회 평균 약 2,440円, 비싸도 타는 때(비·막차·병원), 앱 배차·迎車料金 ② 회사: 앱으로 빈 차를 줄임, 신졸·여성 채용, 격일 근무, 日本版ライドシェア(제도 찬반 없이 사실만) ③ 시청자: 흘러가는 택시 vs 앱, 정액 운임 등 선택지 | 8:00~11:00 | T11·백서 |
| FINAL REVEAL | 처음: 「회사가 가져간다」처럼 보였다 → 실제: **운임의 7할은 운전사에게 가는 구조. 수입을 정하는 건 손님 없이 달리는 절반의 시간** | 11:00~12:30 | T2·T11 |
| FINAL ANSWER | 「答えは――1000円のうち、運転手の人件費は約700円。会社に残るのは26円。でも、運転手の年収を決めているのは1000円の中身ではなく、お客さんを乗せずに走る、半分の時間だ」 | 마지막 | |

## 깊이 점검

| 항목 | 내용 |
|---|---|
| 검색 1위 답(예상) | 「歩合給は売上の50〜60%」(구인 사이트) |
| 같은가? | 비슷 → REWARD 1에서 국가 원가로 정확히(708円·회사 26円), 최종 답은 빈 차 시간 |
| ONLY-HERE ① | 관동운수국 원가로 본 1,000円 분해(회사 이윤 26円) |
| ONLY-HERE ② | 「운전사 몫 비율을 지키도록」 요금을 정하는 사정 방식 |
| ONLY-HERE ③ | 도쿄 실차율 47.5%·실동률 68.6% → 차 3할이 서 있다 |
| 비공개 처리 | 회사별 보합률·앱 수수료 비공개 → 30사 평균 원가로 범위 |
| "이미 알고 있었다"? | 「운전사가 절반쯤 받는다」는 알지만, 「회사 26円·인상분 7할이 운전사·차 3할이 서 있음」은 대부분 모름 |
