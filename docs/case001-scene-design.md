## 패턴 브레이크 간격

0:05 (암전 질문, BGM 정지) → 0:50 (암전 + 동전 스포트라이트) → 1:54 (세피아) → 3:29 (암전 질문) → 4:21 (챕터) → 6:52 (숫자 강조, BGM 정지) → 8:35 (しかし: 순환 급정지) → 9:24 (챕터) → 12:24 (지우개 정지, BGM 정지) → 13:23 (암전 질문) → 14:05 (배경음 변화) → 14:16 (챕터)

연출이 같은 패턴 브레이크가 연달아 나오지 않도록 암전·세피아·숫자·정지·챕터를 번갈아 배치했습니다.

## 반영한 대본 수정

- C067: 「そして三つ目は、仕入れの条件だ。」 → 「そして、もう一つ重要なのが、仕入れの条件だ。」
- C127: 「そこに書かれた たった三文字。「100円」。」 → 「そこに書かれた、たった一つの価格。「100円」。」
- C010: 「たった100円で、本当に利益が出るのだろうか？」 → 「では、利益はどこから生まれるのか？」(질문이 5초 「なぜ、これで儲かる？」 → 23초 「たった100円で、本当に利益が出るのか？」 → 53초로 점점 깊어짐)
