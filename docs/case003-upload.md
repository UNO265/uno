# CASE #003 업로드 문구

성과 지침 4-1(SEO · 짧게 · 후킹) 기준. 챕터 시각은 최종 완성본(13:48) 기준(도입부 재배치 후).

## 제목

| 순위 | 제목 | 글자 수 | SEO | 후킹 |
|---|---|---|---|---|
| **추천** | 映画館のポップコーン、なぜ高い？ | 16 | 映画館・ポップコーン(맨 앞) | 의문 |
| 후보 | 映画館はポップコーンで儲かる？ | 15 | 映画館・ポップコーン | 의문 + 숨은 구조 |
| 후보 | 映画館ポップコーンが高い本当の理由 | 17 | 映画館・ポップコーン | 숨은 구조 |

- 「原価は？」 제목은 쓰지 않는다. 영상에서 원가 숫자를 말하지 않으므로(확인된 수치 없음) 제목이 약속을 지키지 못한다.
- A/B 테스트(「テストと比較」)를 쓸 수 있으면 추천안과 두 번째 후보를 비교한다.

## 썸네일(물체 하나 + 숫자 하나 + 짧은 질문)

- 물체: 빨간 줄무늬 팝콘 컵(영상 M01·M04·M46의 OBJECT 그림), 검은 배경
- 숫자: `2200円`(티켓. 팝콘 가격은 확인되지 않아 쓰지 않음)
- 질문: `本命は売店？`
- 제목과 같은 문장(なぜ高い)을 반복하지 않는다.
