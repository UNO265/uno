# CASE #004 업로드 문구

성과 지침 4-1(SEO · 짧게 · 후킹) 기준. 챕터 시각은 최종 완성본(12:28) 기준.

## 제목

| 순위 | 제목 | 글자 수 | SEO | 후킹 |
|---|---|---|---|---|
| **추천** | コインランドリー、人がいないのになぜ儲かる？ | 22 | コインランドリー(맨 앞) | 의문 + 역설(무인인데 돈을 번다) |
| 후보 | コインランドリーは、なぜ儲かる？ | 16 | コインランドリー | 의문(짧음) |
| 후보 | 無人のコインランドリー、儲けの正体 | 17 | コインランドリー | 숨은 구조 |

- 추천안은 영상 0초의 질문·타이틀과 같은 문장이다(시청지속 지침 11-1·16번).
- A/B 테스트(「テストと比較」)를 쓸 수 있으면 추천안과 두 번째 후보를 비교한다.
- vidIQ 추천(성과 지침 4-2)에서 가져온 검색어 버전도 후보로 둔다: `コインランドリー、無人で儲かる仕組みとは？`(21자, 「無人」「仕組み」). A/B 테스트는 A = 추천안(질문형), B = 이 검색어 버전으로 해서 "질문형 vs 검색어형" 한 가지만 비교한다.

## 썸네일(물체 하나 + 숫자 하나 + 짧은 질문)

- 물체: 업소용 드럼 세탁기의 둥근 창(영상 N01의 OBJECT 그림), 어두운 배경
- 숫자: `1155億円`
- 질문: `何を買ってる？` — 제목과 다른 두 번째 궁금증. 영상 5:40(N27)에서 묻고 6:30~6:40(N30·N31)에서 회수한다(시청지속 지침 17번).
