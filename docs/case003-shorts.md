# CASE #003 쇼츠 3편 (영화관 팝콘)

본편 「映画館のポップコーン、なぜ高い？」(13:48)에서 확인된 사실만 썼습니다. 새 수치는 넣지 않았습니다.

세 편 모두 [성과 지침](KANENAZO_PERFORMANCE_v1.md) 24-1(1질문 1답 + 다리 한 줄)과 **25-1(첫 1초 규칙)** 을 처음으로 적용했습니다.
- 0프레임에 질문이 **글자로** 떠 있고(페이드인 없음), 첫 음성도 질문으로 시작합니다.
- 0프레임부터 큰 움직임이 진행 중입니다(미끄러져 들어오는 티켓 / 터지는 팝콘 / 올라가는 두 화살표).
- 핵심 글자는 화면 가운데 영역에 두고, 아래쪽 UI 자리는 비웠습니다.
- 「CASE #003」 머리말과 엔드카드는 없고, 왼쪽 위에 작은 로고만 둡니다.
- 마지막 컷이 첫 화면의 배경색으로 바뀌며 끝납니다(반복 재생).

| 편 | 0프레임(질문) → 답 | 본편으로 잇는 한 줄(본편에서 답하는 부분) | 길이 | 대본 |
|---|---|---|---|---|
| 1 | 「映画のチケット、平均はいくら？」 → **1454円**(映連 2025년 평균 입장 요금). 학생·어린이·시니어·할인일·레이트쇼. 「定価と、実際に払う金額は、ずいぶん違う。」 | 「その1454円のうち、映画館に残るのは？」 → 본편의 「およそ半分(目安)」 | 29.2초 | `cases/case003_shorts/short1/cuts.json` |
| 2 | 「映画館は、なぜポップコーンを売る？」 → **팔 수 있는 좌석 수에 한계**(200석=최대 200장, 상영 중 교체 불가) → 매점은 **객단가**를 올린다 | 「なぜポップコーンは、あんなに高いのか？」 → 본편 제목의 질문 | 27.2초 | `cases/case003_shorts/short2/cuts.json` |
| 3 | 「映画は過去最高のヒット。なのに、値上げ？」 → 흥행 수입 **2744억 엔**(과거 최고) / TOHO 2023년 2000엔, 2026년 도심 일부 2200엔 / 이유 4가지 / 티켓값은 나눠 갖는 돈 → 「ヒットしても、コストは待ってくれない。」 | 「チケットだけで、映画館は支えられるのか？」 → 본편의 「売店＝もう一本の柱」 | 36.5초 | `cases/case003_shorts/short3/cuts.json` |

- **형식**: 1080×1920 / 30fps
- **음량**: -14.2~-14.3 LUFS, 최대 피크 -1.3 dBFS(클리핑 0), 0.8초 이상 무음 없음
- **음성**: VOICEVOX 雀松朱司, 본편보다 1.3배 빠르게(`--rate 1.3`)
- **BGM**: 각 편 전용으로 새로 작곡(본편 CASE #003의 곡 분위기 ledger·seats·pressure, FluidR3_GM)
- **실사**: 쓰지 않았습니다(CASE #010까지 방침).

세 편 모두 25-1을 같은 방식으로 적용하고, **질문의 종류만** 다르게 했습니다. 결과는 [성과 기록](performance-log.md)의 G·H·I 줄에 적어 주세요. CASE #002 쇼츠(D·E·F, 25-1 적용 전)와 비교하면 25-1의 효과도 볼 수 있습니다.

## 사실 확인(본편과 같은 출처)

| 쇼츠 속 수치·사실 | 출처 |
|---|---|
| 2025년 평균 입장 요금 1454엔 | 日本映画製作者連盟「2025年 全国映画概況」 |
| 2025년 흥행 수입 2744억 엔, 과거 최고(2000년 이후 집계) | 같은 자료 |
| TOHO 2023년 6월 일반 2000엔(에너지 가격, 엔저 매입 비용, 인건비, 설비 투자), 2026년 7월 극장별 요금, 도심 일부 2200엔 | TOHOシネマズ 요금 개정 공지 |
| 200석 스크린 = 1회 상영 최대 200장 | 본편 M27과 같은 예시(산수) |

- 1편에서 할인 요금의 **금액**은 쓰지 않았습니다(극장마다 다름).
- 3편에서 티켓값 배분 **비율**은 쓰지 않았습니다(작품·계약마다 다름. 본편에서 「目安」으로 다룸).
- 1편 막대의 높이는 실제 금액 비율(2200 : 1454)입니다.
