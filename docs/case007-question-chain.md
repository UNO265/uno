## 4. 썸네일 (7-1)

- 카드키(또는 호텔 방 문) 하나 + `15,000円` + 「誰が決めた？」
- 답(高くても埋まる / 今夜の値段)은 쓰지 않는다. 「誰が決めた？」의 답(부족한 빈 방이 정한다 = 예약 상황에 따라 호텔이 매일 바꾼다)은 **2:00**, 반대 전략(東横イン)은 5:00, 최종 구조는 10:00.
