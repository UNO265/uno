# 06 DIRECTION — 영상 제작·애니메이션·AI 자율 연출 통합 지침 (VERSION 1.0)

> 사용자가 준 원본(「KANENAZO 영상 제작 · 애니메이션 · AI 자율 연출 통합 지침서 VERSION 1.0 — MASTER PRODUCTION GUIDE」, 35쪽, 2026-09-29)을 **내용 그대로** 옮겼다. 번호(1~57)는 원본과 같다. **CASE #008 재제작부터 적용.**
> 장면 설계(콘티) 양식: [conti-v4](../templates/conti-v4.md). 기존 지침과 부딪히는 곳은 맨 아래 [기존 지침과의 관계](#기존-지침과의-관계)에서 정리했다.

## 0. 목적

KANENAZO는 일본 시청자를 대상으로 하는 경제·비즈니스 **비주얼 다큐멘터리** 채널이다. 목표는 경제 정보를 많이 전달하는 것이 아니다. 시청자가 하나의 경제 현상을 따라가며 「なぜ？」라고 궁금해하고, 증거와 숫자를 확인하고, 돈과 상품이 움직이는 구조를 이해한 뒤, 마지막에 「なるほど、だからこうなるのか。」라고 느끼게 만드는 것. → **정보 나열형 경제 해설이 아니라 경제 미스터리를 추적하는 비주얼 다큐멘터리.**

## PART 1. 핵심 제작 철학

1. **가장 중요한 원칙: 자료를 움직이지 말고, 경제가 움직이는 모습을 보여준다.** 텍스트·숫자·그래프·아이콘 등장을 반복하는 것은 애니메이션이 아니다. 돈·상품·사람·기업·가격·비용·시장이 서로 영향을 주고받는 모습이 보여야 한다.
2. **기본 스타일**: 지금의 깔끔하고 미니멀한 2D 인포그래픽을 유지한다(전면 변경 금지). 다만 실제 데이터 / Evidence Card / 2D Infographic / Object Animation / Graph Animation / Money Flow / Visual Simulation / Story Reconstruction / Real Footage·Photo / Impact Scene으로 **확장**해 경제 다큐멘터리 수준으로 발전시킨다.
3. **피할 것**: 과도한 3D, 귀여운 캐릭터 중심, AI 이미지 슬라이드쇼, 의미 없는 줌, 텍스트가 계속 나오는 영상, PPT처럼 자료만 넘기는 영상, 화려한 전환 중심 편집, 내용과 무관한 B-roll 남용, 모든 장면을 지나치게 역동적으로, 쇼츠식 과도한 자극. 경쟁력은 화려함이 아니라 **복잡한 경제 구조를 쉽고 흥미롭게 이해시키는 것**.

## PART 2. AI의 역할

4. **사용자에게 컷 연출을 묻지 않는다**("MONEY FLOW로 할까요?", "그래프로 할까요?", "실제 영상으로?", "STORY로?"). 경제 콘텐츠 편집자·다큐멘터리 연출자·모션그래픽 디렉터의 관점에서 AI가 직접 판단한다.
5. **판단 순서**: 형식을 먼저 정하지 않는다. 내용 → 이 문장의 의미 → 시청자가 이해해야 할 핵심 → 경제적 인과관계 → 가장 효과적인 시각화. **내용이 형식을 결정한다.**

## PART 3. 화면 유형 자동 판단

6. **[EVIDENCE] 근거** — 공식 통계·기업 자료·시장 데이터·조사·기사·정부 자료·실적·공식 발표·가격 자료. 깔끔한 카드 디자인 유지. **자료 전체가 아니라 그 장면에 필요한 핵심 숫자·문장만** 강조. 역할은 "사실이라는 증거"이며 **Evidence가 주인공이 되면 안 된다.**
7. **[GRAPH] 변화** — 가격 상승·판매 감소·시장 증가·점포 감소·비용 증가·실적 변화·원가 상승. 완성된 그래프를 바로 보여 주지 않고 시간의 흐름에 따라 변화가 나타나게. **그래프를 읽게 하지 말고, 그래프가 결론을 보여주게 한다.**
8. **[MONEY FLOW] 돈의 흐름** — 가장 중요한 시각화 중 하나. 수익 구조·가격·원가·유통·마진·수수료·물류비·인건비·임대료·광고비·소비자 지출·공급망·기업 간 거래·세금·손익 구조가 나오면 적극 검토. 예: 소비자 → 결제 → 자판기 → 상품 원가 → 물류비 → 보충 인건비 → 전기료 → 설치 장소 수수료 → 기업 이익. **정적인 화살표로 끝내지 않고, 돈이 실제로 이동하고 나뉘는 애니메이션으로.**
9. **방향**: 상품·서비스 → 소비자, 돈 → 기업·공급망.
10. **[STORY / VISUAL SIMULATION]** — 숫자가 현실에서 어떤 행동을 만드는지 보여 줄 때. 예: 가격 상승 → 소비자가 가격 확인 → 망설임 → 다른 구매처로 → 판매량 감소 → 재고 증가 → 기업 대응. **숫자 → 사람의 행동 → 기업 결과**를 연결. 캐릭터는 주인공이 아니라 최소한의 시각 요소.
11. **[REAL FOOTAGE / PHOTO]** — 실제 모습이 애니메이션보다 효과적이면 실제 자료 우선(일본 거리·자판기·편의점·슈퍼·상품·기업·공장·점포·사용 모습). 실제 자료는 신뢰와 현실감, 애니메이션은 이해를 담당. 흐름: 실제 현상 → Evidence → 애니메이션 구조 설명 → 경제적 의미. *(CASE #010까지는 아래 "기존 지침과의 관계" ①)*
12. **[IMPACT] 핵심 결론·반전** — 정보를 오히려 줄인다. **1 OBJECT + 1 NUMBER + 1 MESSAGE**, 잠시 정지 → 다음 질문으로 연결(예: 자판기 한 대 → 1일 약 660円 → 「これで、本当に儲かるのか？」).
13. **[2D INFOGRAPHIC / OBJECT ANIMATION]** — 다른 유형이 필요 없는 일반 설명. 억지로 모든 장면에 MONEY FLOW·STORY를 넣지 않는다. **가장 이해하기 쉬운 표현이 가장 좋은 표현.**

## PART 4. 장면 강도 (LEVEL)

14. 모든 장면을 화려하게 만들지 않는다.
   - **LEVEL 1 SUPPORTING**: 설명 보조. 간단한 아이콘·숫자·자료.
   - **LEVEL 2 EXPLANATION**: 경제 구조 이해. 그래프·구조도·MONEY FLOW.
   - **LEVEL 3 KEY INSIGHT**: 중요한 통찰. 애니메이션·카메라 움직임 적극 사용.
   - **LEVEL 4 HERO MOMENT**: 가장 중요한 반전·결론. **화면을 오히려 단순화하고 강하게.**
   - 모든 장면을 LEVEL 3~4로 만들지 않는다. 강약이 있어야 중요한 장면이 중요하게 느껴진다.

## PART 5. 숫자 표현

15. **숫자를 표시하지 말고 해석한다.** "그대로 보여 주면 의미를 체감하는가?" 아니면 비교·환산·시각화(예: 年24万円 → 月約2万円 → 1日約660円). **숫자 → 비교 → 의미**까지가 한 설명.
16. **큰 숫자는 규모를 시각화한다**(예: 65万台 → 일본 지도·자판기 아이콘·지역 분포·다른 규모와 비교).

## PART 6. 나레이션과 화면

17. **화면은 나레이션을 복사하지 않는다.** 「自販機の数は減っています」라고 말할 때 같은 글자를 쓰지 않고, 자판기 아이콘과 숫자의 변화처럼 **증명하거나 확장하는 정보**를 보여 준다.
18. **역할 분담**: 나레이션 = 이야기와 해석, 화면 = 증거와 이해.

## PART 7. 컷 분할

19. **한 문장 = 한 컷으로 만들지 않는다.** 기준은 정보 변화·논리 변화·시각적 변화·감정적 변화·질문 변화. 여러 문장이 하나의 현상을 설명하면 **하나의 연속 애니메이션**으로, 한 문장 안에 현상 → 원인 → 결과가 있으면 여러 장면으로 나눌 수 있다.
20. **핵심 질문: "지금 시청자의 머릿속 질문이 바뀌었는가?"** YES면 새로운 시각 구조로 전환을 우선 검토.

## PART 8. 기본 내러티브

21. 정보 → 정보 → 통계 → 또 통계를 피한다. 지향: **현상 → 질문 → EVIDENCE → 숫자 → 경제적 의미 → MONEY FLOW/STORY/GRAPH → 예상과 다른 결과 → 새로운 질문.**
22. 시청자는 정보를 받는 사람이 아니라 **경제 현상을 추적하는 사람**. 구조: 질문 → 단서 1 → 단서 2 → 예상 → 반전 → 경제적 원인 → 결론.

## PART 9. Open Loop & Micro Question

23. **답을 너무 빨리 공개하지 않는다**(질문 → Evidence → 판매량 변화 → 비용 구조 → MONEY FLOW → 결론). 과정을 통해 답을 발견하게. 단, 사실을 의도적으로 숨기거나 낚시성 연출을 하지 않는다. *(제목 질문의 첫 답은 C2가 우선 — 아래 ②)*
24. **Micro Question**: 큰 질문 하나로 15분을 끌지 않는다. 예: 왜 가격이 올랐을까? → 그런데 왜 판매량이 줄었을까? → 줄었는데 왜 계속 운영할까? → 실제로 한 대에서 얼마나 남을까? → 그렇다면 왜 철거할까? → 결국 사라질까? **억지로 만들지 않고 대본의 인과관계에서 발견한다.**

## PART 10. 정보 밀도

25. 자료를 3단계로: **MUST KNOW**(결론 이해에 필수 → 포함) / **GOOD TO KNOW**(없어도 논리 성립 → 흐름을 방해하지 않으면 사용) / **RESEARCH ONLY**(사실 확인용 → 영상에서 제거).
26. **조사는 깊게, 영상은 명확하게.** 조사를 많이 했다는 것을 보여 주려고 자료를 넣지 않는다.
27. **중복 Evidence 압축**: 같은 결론을 증명하는 자료가 여럿이면 가장 강력하고 신뢰도 높은 것을 중심으로, 나머지는 필요할 때 보조.

## PART 11. 경제 인과관계 시각화

28. **사실보다 연결 관계.** 원가↑ → 가격 인상 → 구매↓ → 판매량↓ → 1대당 매출↓ → 고정비 부담↑ → 수익성 악화 → 철거를 각각의 자료가 아니라 **하나의 움직이는 경제 시스템**으로.
29. **상식 ≠ 실제 결과**는 Key Insight 후보(예: 가격↑ → 예상 매출↑ / 실제 판매량↓ → 매출 정체 → 비용 부담↑ → 수익성 악화). LEVEL 3~4 연출을 적극 검토.

## PART 12. 카메라

30. **2D에서도 카메라가 있다**: Slow Zoom In/Out, Pan, Tracking, Top View, Close-up, Extreme Close-up, Wide Shot. 중요 숫자 = Zoom In, 시장 전체 구조 = Zoom Out, 돈 이동 = Tracking, 새로운 발견 = Close-up. **카메라는 장식이 아니라 시선 유도.**

## PART 13. Pattern Interrupt

31. 통계 → 통계 → 그래프 → 숫자가 계속되면 필요성을 판단(예: 정적인 통계 → 일본 거리 → 자판기 Close-up → 160円 → 동전 투입 → MONEY FLOW). 단순한 자극이 아니라 **정보 성격이 바뀌는 순간 화면 문법도 바꾸는 것.**

## PART 14. 시청지속률 검수 시스템

32. 콘티 완성 후 바로 제작하지 않는다: **1차 콘티 → 시청지속률 검수 → 이탈 위험 구간 탐지 → 콘티 자동 수정 → 재검수 → 최종 콘티 → 영상 프롬프트(제작).** 사용자에게 일일이 수정 여부를 묻지 않고 AI가 먼저 스스로 개선한다.
33. 핵심 질문: **"일본의 경제·비즈니스 콘텐츠 시청자가 지금 이 지점에서 계속 볼 이유가 있는가?"** 정확하다는 이유만으로 장면을 유지하지 않는다.

## PART 15. 시간대별 검수

34. **0:00~0:30 HOOK**(가장 엄격): 첫 5~10초에 흥미로운 현상·숫자·모순·질문? 핵심 미스터리가 빠르게? 제목·썸네일 내용을 반복만 하지 않나? 배경 설명이 너무 길지 않나? 결론을 너무 빨리 공개하지 않나? 30초 뒤에도 확인하고 싶은 것이 남는가? 배경 설명보다 궁금증 형성 우선.
35. **0:30~3:00 PROMISE**: "이 영상을 보면 무엇을 알게 되는가"를 자연스럽게. 목차 읽기 금지. 첫 중요한 단서 또는 예상 밖 숫자 등장.
36. **3:00~7:00 DEVELOPMENT**: 이탈 위험이 커지는 구간. **Evidence → 해석 → 새로운 질문**, 자료 나열 금지.
37. **7:00~11:00 MID-VIDEO RESET**: 예상과 다른 숫자·기존 설명을 뒤집는 사실·MONEY FLOW·새 이해관계자·기업의 예상 밖 선택·소비자 행동 변화·시장 구조 변화·강력한 비교·새 질문 중 적합한 것. "이제 다음 내용을 알아보겠습니다" 같은 인위적 전환 금지.
38. **11:00~END PAYOFF**: 새 자료를 계속 추가하기보다 앞의 단서를 연결해 「だから最初の現象が起きていたのか。」 결론은 요약이 아니라 **경제적 의미를 한 단계 확장**.

## PART 16. 이탈 위험 자동 탐지

39. **A 정보 연속**(통계 → 통계 → 기사 → 숫자) → 해석·MONEY FLOW·STORY·비교·질문이 필요한지.
40. **B 동일 화면 반복**(흰 배경 + 아이콘 → 숫자 → 그래프 → 텍스트) → 다른 시각 언어 검토.
41. **C 이미 답을 앎** → 공개 순서 재설계(왜곡·억지로 숨기기 금지).
42. **D 질문 없는 설명** → 다음 정보가 답하게 될 자연스러운 질문 탐색.
43. **E 화면과 나레이션 중복** → 다시 설계.
44. **F 중요도 평준화**(속도·크기·정보량·움직임이 비슷) → LEVEL 재조정.

## PART 17. 30~60초 리듬 검사

45. 약 30~60초마다 **새 질문·새 사실·의미 있는 숫자·비교·구조 변화·시각적 변화·예상 밖 결과·MONEY FLOW·STORY·IMPACT·새 이해관계자·다음을 궁금하게 하는 단서** 중 하나 이상. 없으면 위험 구간 → 먼저 대본 구조를 검토.

## PART 18. 화면 유형 반복 검사

46. EVIDENCE → EVIDENCE → EVIDENCE…가 계속되면 "정확하지만 단조로운가?"를 판단해 MONEY FLOW·STORY·GRAPH·REAL FOOTAGE·OBJECT·SIMULATION·IMPACT 중 적합한 방식으로. **다양성을 위한 다양성은 금지.**

## PART 19. 비율 (참고값)

47. 기본 인포그래픽/Evidence 약 40~45% · Money Flow 약 20~25% · Story 약 15~20% · Graph 약 10~15% · Impact 약 5~10%. **고정 비율을 강제하지 않는다. 주제가 비율을 결정한다**(수익 모델 → MONEY FLOW↑, 시장 변화 → GRAPH↑, 소비자 행동 → STORY↑, 실적 → EVIDENCE↑).

## PART 20. AI 최종 자체 검수

48. 최종 콘티를 처음부터 다시 본다: ① 같은 형식 반복 ② Evidence Card 과다 ③ 숫자 연속 ④ MONEY FLOW가 필요한데 정적으로 설명 ⑤ 현실 상황을 보여 주면 더 쉬운 곳 ⑥ 중요한 반전의 평범한 처리 ⑦ 중요하지 않은 장면의 과한 화려함 ⑧ 나레이션·화면 반복 ⑨ 30~60초 동안 변화 없음 ⑩ 다음을 궁금하게 하는 이유. **문제가 있으면 사용자에게 묻기 전에 스스로 수정.**
49. **최종 시청지속률 자체 평가**: HOOK(30초 뒤에도 볼 이유) · CURIOSITY(아직 풀리지 않은 자연스러운 질문) · CLARITY(전문 지식이 적은 일본 시청자도 이해) · VISUAL VARIETY · INSIGHT(검색 이상의 해석) · MONEY(돈이 어디서 나서 어디로 가는지) · PAYOFF(처음 질문의 회수). 하나라도 크게 부족하면 제작 전에 수정.

## PART 21. 확정된 내용 보호

50. 시청지속률 개선을 이유로 **CASE 주제·핵심 질문·검증된 사실·확정된 제목·핵심 경제 논리·승인된 방향·확정된 제작 콘셉트를 바꾸지 않는다.** 개선할 수 있는 것: 정보 공개 순서·컷 구성·시각화 방식·장면 강약·화면 반복·질문 배치·설명 압축·Pattern Interrupt·MONEY FLOW 표현. 개선은 CASE를 다른 콘텐츠로 바꾸는 것이 아니다. *(= C6)*

## PART 22. 최종 콘티 출력 규칙

51. 각 장면에 **유형과 중요도**를 표시한다(예: `CUT 034 — [MONEY FLOW / LEVEL 3]`). 사용자가 고르는 옵션이 아니라 **AI가 이미 결정한 결과**. 컷마다 필요에 따라: CUT 번호 · 유형 · LEVEL · 대응 나레이션 · 핵심 피사체 · 화면 구성 · 구체적 움직임 · 카메라 · 숫자·텍스트 · 시작 상태 · 종료 상태 · 다음 장면 연결.

## PART 23. 제작 조건

52. FACT CHECK → 대본 확정 → 경제적 핵심 구조 확인 → AI 자율 연출 분석 → 1차 콘티 → 화면 유형 자동 판단 → 시청지속률 검수 → 이탈 위험 탐지 → 정보 밀도 검수 → 반복 장면 검수 → 콘티 자동 수정 → 재검수 → 최종 콘티 → 제작.

## PART 24. MASTER WORKFLOW

53. 01 주제 선정 → 02 자료조사·FACT CHECK → 03 경제적 핵심 질문 → 04 대본 작성 → 05 대본 검수·확정 → 06 AI 자율 연출 분석 → 07 1차 콘티 → 08 EVIDENCE/GRAPH/MONEY FLOW/STORY/REAL/IMPACT/INFOGRAPHIC 자동 판단 → 09 LEVEL 판단 → 10 시청지속률 검수 → 11 이탈 위험 탐지 → 12 30~60초 리듬 → 13 정보 밀도·중복 Evidence → 14 동일 화면 반복 → 15 인과관계 시각화 → 16 콘티 자동 개선 → 17 전체 재검수 → 18 최종 콘티 확정 → 19 컷별 제작 지시 → 20 최종 영상 제작.

## PART 25. 작업 중 항상 기억할 질문

54. 장면: **"예쁘게 만들고 있는가, 경제를 이해시키고 있는가?"** 예쁘기만 하면 다시 설계.
55. 시청지속: **"이 장면 다음을 계속 보고 싶은 이유가 있는가?"**
56. 경제: 가격 → 소비자 행동 → 판매량 → 매출 → 비용 → 이익 → 기업 의사결정 → 시장 변화. 대본에 이 관계가 있으면 가능한 한 시각적으로.
57. 완성 후: **"시청자가 15분 동안 자료를 본 것인가, 하나의 경제 현상이 움직이는 과정을 경험한 것인가?"** 반드시 후자.

## PART 26. 최종 제작 철학

WHAT(무슨 일이) → WHY(왜) → MONEY(돈은 어디서 어디로) → CONSEQUENCE(그 결과 소비자와 기업은 어떻게 행동하나) → INSIGHT(우리가 보던 현상의 진짜 구조).

**FINAL RULE**
1. 자료를 움직이지 말고, 경제가 움직이는 모습을 보여준다.
2. 정보를 나열하지 말고, 시청자가 답을 발견하게 만든다.
3. 화려하게 만드는 것이 아니라, 계속 보고 싶고 이해하기 쉽게 만든다.

AI는 연출 방법을 사용자가 지정하기를 기다리지 않는다. 경제 콘텐츠 편집자 + 다큐멘터리 연출자 + 모션그래픽 디렉터로서 스스로 판단·검수·수정한 뒤 최종 제작안을 제시한다.
