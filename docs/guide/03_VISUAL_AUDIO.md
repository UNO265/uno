## V1. 원칙

- **다큐멘터리 안에서 필요한 순간에 Flat 2D를 쓴다**(Flat 2D 영상에 실사를 끼우는 것이 아니다).
- **모든 화면은 역할이 있다**: ① 현실 ② 설명 ③ 증명 ④ 비교 ⑤ 질문 ⑥ 반전. 어느 것도 아니면 삭제하거나 다시 설계한다. 화면은 내레이션을 받아쓰지 않고 **증명하거나 이해시킨다**.
- **CASE마다 디자인을 복제하지 않고 문법을 계승한다**: 주인공 물체·CLUE 카드 모양·장소 표현·MONEY FLOW 모양·BGM 악기를 CASE마다 새로 정한다(예: #005 송장, #006 台紙, #007 카드키 슬리브). 브랜드 자산(C1)은 유지.
- 목표는 "움직이는 PowerPoint"가 아니라 KANENAZO 제작팀이 만든 경제 미스터리 다큐.

## V2. 화면 타입과 질감 (CASE #010까지는 실사 없음)

| 타입 | 내용 |
|---|---|
| A OBJECT / TIMELINE / MAP | REAL 대신: 어두운·단색 배경에 **물체 하나만** 크게 / 연표 / 지도 |
| B EVIDENCE / DOCUMENT / BLUEPRINT | 공식 자료·결산 카드·영수증(종이 질감, 형광펜) / 남색 선화·단면도 |
| C DATA | 흰 화면에 숫자 하나 |
| D GRAPH | 내레이션과 함께 만들어지는 그래프 |
| E FLAT 2D | 보이지 않는 구조 설명(베이지 홈 베이스) |
| F MONEY FLOW | 돈의 이동 |
| G QUESTION / DARK / TITLE | 검은 화면·질문 한 줄·무음 |
| H KEY TYPOGRAPHY | 명조체 한 문장(하단 자막 없음) |
| I CLUE | 중간 결론 카드(CASE마다 모양을 새로) |
| J DOCUMENTARY RESET | 질감을 강제로 바꾸는 구간 |

- **질감 비율(시간 기준, 임시)**: FLAT 2D 35~40%(40% 이하) / OBJECT·DOCUMENT·BLUEPRINT 25~30% / DATA·GRAPH·MONEY FLOW 20% / DARK·TYPOGRAPHY 10%. 기계적으로 맞추지 않되 **한 질감이 영상을 지배하지 않게**. 숫자 화면이 많은 CASE는 그래프 옆에 물체를 크게 둔다.
- **같은 질감 60~90초 이상 → DOCUMENTARY RESET 검토.** 권장 흐름 예: OBJECT → QUESTION → 2D → DATA → EVIDENCE → OBJECT → MONEY FLOW → DARK → GRAPH → CLUE. 타입을 바꾸는 데엔 이유가 있어야 한다.
- **썸네일 크기 점검**: 장면 설계 뒤와 제작 뒤에 전체를 콘택트 시트로 펼쳐 「베이지 베이지 베이지」「Flat Flat Flat」로 보이면 실패. 시청자가 느끼는 **화면의 재질**이 달라야 한다.
- 실사 원칙(CASE #011부터 다시): 실사는 장식이 아니라 실제 장소·제품·과정·규모를 보여 줄 때만, REAL/B-roll 20~30%, 사용권 확인(C5).

## V3. 숫자·그래프·EVIDENCE

- **숫자는 하나의 장면**: 한 화면에 여러 숫자를 던지지 않는다. 숫자 → 의미 → 비교 순으로 하나씩, 카운트업·확대.
- **그래프는 내레이션과 동기화**: 처음부터 완성해 두지 않는다. 막대가 오르고 해당 연도가 강조되는 순간이 내레이션과 맞는다.
- **EVIDENCE 라벨은 실제 근거가 있는 장면에만**(공식 통계·정부 자료·IR·공식 가격·공식 발표). 개념 일러스트·재현 그래픽에는 붙이지 않는다. 핵심 부분만 확대하고 출처를 적는다. 공식 그래프는 숫자만 확인해 KANENAZO 그래프로 다시 그린다.
- **비교는 2~3초 안에**: 좌우 분할·숫자·화살표.
- **placeholder 금지**: 빈 사진 프레임처럼 보이는 화면을 만들지 않는다.

## V4. 움직임

- "많이 움직이는 영상"이 아니라 **"움직임의 순간"**. 정지 → 움직임 → 정지 → 숫자 → 여백. 예: 「1000円。」 정지 → 「でも――」 1000円이 갈라진다.
- 모든 애니메이션은 설명·비교·변화·강조·질문 중 하나를 한다. **금지 습관**: 계속 튀어나오는 아이콘, 모든 글자의 확대·축소, 의미 없는 화살표·동전·카메라 패닝·배경 움직임, 모든 장면의 페이드, 반복되는 카드 등장.
- 한 장면 = 한 메시지. 복잡한 구조는 순차 등장. 3~7초마다 의미 있는 시각 변화(이해하기 전에 지나갈 만큼 빠르게는 하지 않는다). 첫 30초는 3~5초마다.
- **패턴 브레이크**(60~90초마다 필요 여부 확인): 암전·무음·숫자 하나·흰 화면·문서·지도·타임라인·강한 한 문장·모든 요소 제거 후 질문 하나. **같은 브레이크를 연속으로 쓰지 않는다.**

## V5. MONEY FLOW와 CLUE 화면

- MONEY FLOW: 상품은 한 방향, 돈은 반대 방향. 주제마다 모양을 바꾼다(레인·평면도·배관 등). 파이 차트보다 **돈이 이동하는 느낌**. 단계적으로 쌓아 FINAL에서 완성(S6). FINAL MONEY FLOW 컷은 자막을 숨기고 화면으로 나열을 대신한다.
- CLUE 카드: CASE마다 새 모양. 문장이 카드 폭을 넘지 않게 글자 크기를 계산한다.

## V6. 자막과 화면 글자

- 모든 내레이션을 하단 박스로 반복하지 않는다. **생략하는 장면**: 숫자 화면, 질문 화면, CLUE, KEY TYPOGRAPHY, MONEY FLOW, FINAL CLUE, 타이틀.
- 박스는 옅게, 짧은 말은 박스 없이. 스마트폰 가독성 유지.
- **글자 크기**: 의미를 전하는 글자(라벨·숫자·칩)는 1080p 기준 **40px 이상**. 출처·「※イメージ」만 24~30px(시청자의 55%가 45세 이상, 대부분 휴대폰).
- **자막 안전 영역**: 하단 자막(2줄)은 화면 아래 약 y 884~1034를 차지한다. **도형·글자는 y 860 위에 둔다.**
- 화면이 빈 채 음성만 2초 넘게 흐르지 않게(특히 타이틀 직후).

## V8. BGM·효과음

- **CASE마다 새로 작곡**(`scripts/music.py --case case00X`, FluidR3_GM): 구간별 무드(MOODS)마다 **악기·패턴·타악기·템포를 바꾸고**, CASE 고유의 짧은 **주제 선율(motif)** 을 둔다. 이전 CASE와 같은 조합을 쓰지 않는다.
- **템포 점검**: 내레이션 약 7모라/초에 대해 선율 음은 초당 약 3음 이하. 빠른 분산화음은 옅은 음량으로.
- **BGM은 배경**: 계속 귀에 인식되지 않게. 내레이션 구간에서 자동으로 낮춘다(ducking). 무드별 음량(LEVEL)은 타악기·빠른 패턴일수록 낮게.
- **무음**: 첫 질문(0~3초), 제목의 답(먼저 답하는 순간), 중요한 CLUE, 최종 답 직전에 BGM을 끈다(MUTES). 오류처럼 느껴질 만큼 길게 비우지 않는다.
- **효과음 최소**: 중요한 숫자·CLUE·타이틀에만. whoosh·click·beep·glitch 반복 금지, 고주파·지지직 금지.
- 구간별 분위기 참고: HOOK 긴장 / 분석 차분 / EVIDENCE 낮춤 / QUESTION 거의 무음 / REVEAL 변화 / 엔딩 고정 징글.
