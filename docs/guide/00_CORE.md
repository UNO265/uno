## C1. 채널 정체성

- **채널**: KANENAZO｜カネナゾ / 슬로건 「身近なお金の謎を解く。」
- **정의**: 「カネナゾは、身近な『値段』の裏側にある、お金の流れとビジネスの仕組みを解く。」 投資 추천·경제 뉴스가 아니다.
- **포지션**: 身近なお金の謎を追う、ビジネス・ミステリードキュメンタリー. "플랫 2D 경제 설명 채널"이 아니라 **Documentary × Evidence × Motion Graphic**. Flat 2D는 보이지 않는 구조를 설명하는 도구다.
- **공식**: 身近なモノ × お金の謎 × MONEY FLOW × 今起きている変化
- **영상의 목표**: 가격을 따라갔더니 그 뒤의 **돈의 흐름·기업 구조·산업 구조·현재의 변화**가 보이고, 마지막에 **처음 보았던 가격의 의미가 바뀐다**. PRICE MYSTERY → BUSINESS MODEL DISCOVERY.
- **리듬**: "왜?" → "아, 그렇구나" → "그런데 그러면?" → "아, 그래서였구나" → "결국 이런 구조였구나". **답을 하나씩 얻을수록 더 큰 미스터리가 열리는 영상**(질문 하나를 15분 끄는 영상이 아니다).
- **브랜드 자산(변경 금지)**: CASE #00X, CLUE, EVIDENCE, MONEY FLOW, 단계적으로 깊어지는 질문, 고정 엔딩(C8).

## C2. 약속 원칙 (근거: #002 「結論がないなら最初からそう言えば？」, #003 「思ったよりも浅い」)

**제목·썸네일·첫 30초의 질문은 시청자와의 약속이다.** 같은 형식으로, **늦어도 영상의 1/3 지점까지 한 번** 갚고, 마지막에 더 정확한 형태로 다시 답한다(처음과 다른 답을 내놓지 않는다).

| 질문의 형식 | 갚는 방법 |
|---|---|
| いくら・何円・何%・何倍 | 숫자(정확한 값이 없으면 공식 자료로 만든 **범위·평균·실제 사례**) |
| なぜ | 핵심 이유 한 문장 |
| 本当に〜？ | 예·아니오 |
| 誰が | 누구인지 |

- 나머지 영상은 "그 답이 왜 그렇게 되는가"와 "그 뒤의 더 큰 구조"를 판다. FINAL REVEAL은 제목 질문의 답이 아니라 **비즈니스 구조의 발견**이다.
- **답할 수 있는 질문만 낸다**: 주제·제목 전에 ANSWER CARD를 채운다(P2). 못 채우면 제목을 바꾸거나 주제를 버린다.
- **모르는 것은 먼저 말한다**: 공개되지 않는 숫자는 첫 1분 안에 「公表されていない。だから○○で追う」라고 말하고, 범위를 좁히는 과정 자체를 조사 이야기로 만든다.
- **회피형 결론 금지**: 「店によって違う」「一概には言えない」「書かれていない」「ほんの一部だけ」로 답하지 않는다. 조건이 필요하면 **숫자·결론을 먼저, 조건은 뒤에**.

| 나쁜 결론 | 좋은 결론 |
|---|---|
| 「店によって違う」 | 「平均で約○%。上位と下位で○倍の差がある。その差を生むのは○○だ」 |
| 「メニューの値段には、書かれていない」 | 「公開データで言えるのは○○まで。そこから分かるのは○○だ」 |
| 「それだけではない」로 끝남 | 결론 한 문장 + 숫자 또는 구조 한 개 |

## C3. 시청자의 시간과 깊이

- **분량: 4,000자 이상, 5,000자 내외**(사용자 확정, CASE #007부터). 모자라면 **조사를 더 해서** 확인된 새 사실로 채운다. 같은 말을 바꿔 반복해 채우지 않는다.
- **1분 규칙**: 어느 1분을 잘라도 새로 알게 된 것(숫자·사실·구조)이 있어야 한다.
- **상식보다 한 층 더**: 제목 질문의 검색 1위 답이 우리 결론과 같으면 그 답은 중간 보상으로 내리고 결론을 더 깊게(P3). **여기서만 아는 사실 3개 이상**(결산·유가증권보고서·정부 통계·공적 조사).

## C4. 사실 규칙 (절대)

- **숫자를 만들지 않는다.** 「原価は○円」「利益率は○％」「業界平均は○％」「○円が店に残る」는 근거가 있을 때만. 인터넷에 반복되는 숫자도 1차 확인 전에는 쓰지 않는다.
- **売上 ≠ 粗利益 ≠ 営業利益 ≠ 純利益.** "매출이 늘었다"와 "벌었다"를 같은 뜻으로 쓰지 않는다.
- **과거 자료를 현재처럼 말하지 않는다**(「過去の○○の調査では〜」).
- **기업 의도를 단정하지 않는다**(「〜という効果が考えられる」「結果として〜につながる」). 공식 설명과 우리 분석을 구분한다.
- **과장 금지**: 「衝撃の事実」「絶対に儲かる」「ほぼ全部が利益」「企業は騙している」.
- **계산·이미지는 표시한다**: 우리가 계산한 값·예시 그림에는 「※計算」「※イメージ」, 보도는 「報じられている」, 업계 해설은 「と言われる」.
- **한 회사 숫자는 한 회사 숫자라고 말한다**(업계 평균처럼 쓰지 않는다).

## C5. 자료·사용권 (절대)

- **CASE #010까지는 실사를 쓰지 않는다**(유료 스톡·AI 생성 실사 모두). REAL 자리는 그래픽 질감(V2)으로 채운다. AI 실사용 자료(`docs/case003-ai-footage-prompts.md`, `video/scripts/gen_footage.py`)는 #011 이후를 위해 보관만 한다.
- 실제 사진·영상은 **사용권이 확인된 것만** 쓴다. "공개되어 있다"와 "재사용할 수 있다"는 다르다. 공식 그래프는 숫자만 확인해 KANENAZO 그래프로 다시 그린다. 실존 브랜드 로고·건물은 그리지 않는다(이름은 글자로만).

## C6. 사용자가 정한 것은 바꾸지 않는다

사용자가 확정한 **주제·제목·핵심 질문·스토리 방향·결론·구조**는 더 좋은 아이디어가 있어도 바꾸지 않는다. 확정된 방향 안에서는 사실 수정·일본어 표현 개선·중복 제거·논리 연결·근거 강화만 한다. 새 전략은 다음 CASE부터 제안한다.

## C7. 제작 순서 (단계마다 사용자 확정)

1. 조사 + **ANSWER CARD** + 제목 후보 → 사용자가 제목 선택 (01)
2. **질문 사슬 설계** → 사용자 확정 (02)
3. **대본**(4,000~5,000자) → 사용자 확정 (02)
4. **최종 음성** → `retention_check.py` → **장면 설계** → 사용자 확정 (03)
5. BGM·화면 제작 → 콘택트 시트 점검·수정 → **렌더링·마스터링·분할 전달** (03)
6. 업로드 문구 + **PROMISE AUDIT**(C9) → 업로드 → 성과 기록 (05)
7. 쇼츠 3편 (04)

- 대본을 받으면 영상부터 만들지 않는다. 최종 일본어 음성을 먼저 만들고, 실제 발화 길이에 장면·자막·BGM을 맞춘다(임시 TTS로 길이를 정하지 않는다).
- CASE #001~#003은 새 지침에 맞춰 다시 고치지 않는다(비교 데이터).

## C8. 고정 엔딩

```
身近なお金には、
まだまだ謎がある。

カネナゾ。
「身近なお金の謎を解く。」

では、
次の謎で。
```

- 채널 이름은 **음성에서 한 번만** 말한다(「カネナゾ。」). 화면에는 로고 `KANENAZO` + `カネナゾ`를 함께 보여 준다(CASE #008부터, 사용자 요청).

## C9. PROMISE AUDIT (업로드 전, 처음 보는 사람의 입장에서)

하나라도 "아니오"면 고친다.

1. 제목·썸네일만 보고 기대하는 것을 영상이 주는가? **몇 분에?**(영상의 1/3 안인가?)
2. 최종 답의 첫 문장이 제목 질문과 같은 형식인가?
3. 공개되지 않은 숫자가 있다면 첫 1분 안에 그렇게 말했는가?
4. "이미 알던 이야기"로 끝나지 않는가? 여기서만 아는 사실이 3개 이상인가?
5. 어느 1분을 잘라도 새로 알게 된 것이 있는가?

## C10. 비판 댓글

방어하지 않는다. 맞는 지적은 인정하고 보완한 내용으로 답한다. 영상을 고칠 수 없으면 설명란·고정 댓글로 보완한다. 비판은 성과 기록에 적고, 같은 원인이 반복되지 않게 지침을 고친다.
