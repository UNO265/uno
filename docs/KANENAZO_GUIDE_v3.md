# KANENAZO VIDEO PRODUCTION MASTER GUIDE v3.0

- **적용 범위**: CASE #003 이후 모든 KANENAZO 영상. v1([KANENAZO_GUIDE.md](KANENAZO_GUIDE.md))과 v2([KANENAZO_STYLE_v2.md](KANENAZO_STYLE_v2.md))는 계속 유효하며, 충돌하면 이 문서가 우선한다.
- **채널**: KANENAZO｜カネナゾ
- **브랜드 문구**: 「身近なお金の謎を解く。」
- **채널 포지션**: 身近なお金の謎を追う、ビジネス・ミステリードキュメンタリー。

## 1. 영상의 기본 철학

KANENAZO는 단순한 「図解アニメーションチャンネル」이 아니다. 목표는 **「Documentary × Evidence × Motion Graphic」** 형식의 비즈니스 미스터리 다큐멘터리다.

Flat 2D는 영상 전체의 형식이 아니다. 눈에 보이지 않는 돈의 흐름과 비즈니스 구조를 설명하기 위한 KANENAZO의 시각 언어로 사용한다.

| 요소 | 역할 |
|---|---|
| REAL | 현실 |
| EVIDENCE | 증거 |
| DATA | 숫자 |
| FLAT 2D | 구조 설명 |
| MONEY FLOW | 돈의 흐름 |
| DARK / SILENCE | 질문과 반전 |

영상 전체를 하나의 그래픽 스타일로 채우지 않는다.

## 2. CASE #001 → #002에서 얻은 교훈

**유지할 방향**: CASE #002에서 CASE #001보다 개선된 다음 요소들.
- 질문 구조, 숫자 시각화, CLUE 시스템, MONEY FLOW, 그래프
- 내레이션과 화면의 논리적 연결, 패턴 브레이크, 결론 회수

**새로 확인된 문제**
- 설계상 서로 다른 화면 타입(A / C / D / G 등)도 실제 영상에서는 모두 비슷하게 표현됐다.
  - 아이보리 배경 + 플랫 일러스트 + 타이포그래피
  - 같은 계열 색상 + 비슷한 모션
- 그래서 시청자에게는 「같은 종류의 화면」으로 느껴질 수 있다.

**CASE #003부터**: "정보의 다양성"뿐 아니라 **"화면 질감의 다양성"**을 설계한다.

## 3. 가장 중요한 변화

- **기존**: Flat 2D 영상 안에 실사를 넣는다.
- **변경**: **다큐멘터리 영상 안에서 필요한 순간에 Flat 2D를 사용한다.**

기본 흐름:

```
REAL → QUESTION → EVIDENCE → ANALYSIS → FLAT 2D → MONEY FLOW → REAL
→ DATA → QUESTION → CLUE → REAL → FINAL REVEAL
```

매번 똑같이 적용할 필요는 없지만, 한 가지 화면 질감이 오래 이어지지 않게 한다.

## 4. 화면 타입 v3.0

### [A] REAL / B-ROLL
- **보여 주는 것**: 실제 장소, 제품, 행동, 사람의 손, 거리, 매장, 음식, 기계, 생산 과정 등
- **목적**: "이 이야기는 현실에서 벌어지고 있다."
- **예**: 라멘, 영화관, 팝콘, 자판기, 호텔, 편의점, 택배, 주차장
- 가능하면 영상 초반에 REAL 화면을 먼저 쓴다.

### [B] EVIDENCE
- **실제 근거를 보여 주는 화면**: 정부 통계, 기업 IR, 공식 조사, 공공기관 자료, 가격표, 공식 홈페이지, 실제 메뉴, 공식 발표
- **중요**: EVIDENCE 라벨은 실제 근거가 있는 장면에만 붙인다. 일러스트나 재현 그래픽에는 EVIDENCE라고 표시하지 않는다.

### [C] DATA / NUMBER
- 숫자 자체를 주인공으로 만든다(예: 1000円 / 8855億円 / 141 / 63.4%).
- 숫자가 중요할 때는 주변 장식을 최소화한다.
- 한 화면에 여러 숫자를 동시에 던지지 않는다.
- 기본 구조: **숫자 → 숫자의 의미 → 비교**

### [D] GRAPH
- 숫자의 변화나 관계를 설명한다.
- 그래프가 내레이션보다 먼저 완성되어 있으면 안 된다. 내레이션이 진행되는 순간 그래프도 함께 만들어진다(예: 2020 100 → 2025 141).
- 시청자가 그래프를 "읽는 것"이 아니라, 그래프가 만들어지는 과정을 "보게" 한다.

### [E] FLAT 2D EXPLAINER
- 눈으로 직접 볼 수 없는 구조를 설명한다.
- **사용 대상**: 원가 구조, 수익 구조, 유통 구조, 플랫폼 수수료, 공급망, 비용 구조, 비즈니스 모델, 객단가, 회전율
- Flat 2D는 장식이 아니다. 실사로 설명하기 어려운 것을 설명할 때만 쓴다.

### [F] MONEY FLOW
- KANENAZO의 핵심 시그니처. 시청자가 지불한 돈이 어디로 이동하는지 보여 준다.
- 예: 1000円 → 食材 → 人件費 → 家賃 → 光熱費 → その他 → 利益
- 단순 파이 차트보다 **"돈이 이동한다"는 느낌**을 우선한다.
- CASE마다 형태는 바꿀 수 있지만, MONEY FLOW라는 개념은 유지한다.

### [G] QUESTION / DARK
- 미스터리를 만든다. 중요한 질문에서는 화면의 정보를 오히려 제거한다.
- 예: 검은 화면에 「なぜ？」「誰が払っている？」「利益は？」「原価はいくら？」
- 질문 장면에서는 과도한 애니메이션을 쓰지 않는다.

### [H] KEY TYPOGRAPHY
- 중요한 한 문장을 화면 전체에 쓴다(예: 「売れている。でも、残らない。」).
- 이때 하단 자막은 표시하지 않는다.

### [I] CLUE
- 중간 결론이다. 단순한 챕터 제목이 아니다.
- 앞에서 발견한 사실을 한 문장으로 압축한다(예: CLUE 04 「売上が増えることと、儲かることは、同じではない。」).
- CLUE 다음에는 새로운 질문이 생겨야 한다.

### [J] DOCUMENTARY RESET
- 영상의 질감을 강제로 바꾸는 구간이다.
- 예: 실사, 거리, 매장, 제품 클로즈업, 환경음, 사진, 신문, 문서, 지도, 타임라인
- 같은 화면 질감이 60~90초 이상 이어지면 Documentary Reset을 검토한다.

## 5. 화면 비율 가이드

정확한 할당량이 아니라, 영상 전체의 질감을 관리하기 위한 참고 기준이다.

| 질감 | 비율 |
|---|---|
| Flat 2D / Motion Graphic | 약 35~45% |
| REAL / B-roll | 약 20~30% |
| Evidence / Document | 약 10~15% |
| Graph / Number / Money Flow | 약 15~20% |
| Dark / Typography / Silence | 약 5~10% |

숫자를 기계적으로 맞추지 않는다. 핵심은 **"하나의 화면 질감이 영상 전체를 지배하지 않게 한다."**

## 6. 화면 전환 기본 문법

- **피할 구조**: 2D → 2D → 2D → 2D → CLUE → 2D → 2D → 그래프 → 2D
- **권장 구조**: REAL → QUESTION → REAL → 2D → DATA → EVIDENCE → REAL → MONEY FLOW → DARK → GRAPH → CLUE

화면 타입을 바꾸는 데에는 이유가 있어야 한다. 단순히 지루함을 피하려고 무작위로 바꾸지 않는다.

## 7. 움직임의 원칙

"많이 움직이는 영상 = 좋은 영상"이 아니다. KANENAZO는 움직임보다 **"움직임의 순간"**을 중요하게 생각한다.

- **기본 리듬**: 정지 → 움직임 → 정지 → 실사 → 숫자 → 움직임 → 정적
- **예**: 「1000円。」 화면 정지. 잠시 여백. 「でも――」 1000円이 갈라진다.
- 이 한 번의 움직임이 계속 움직이는 아이콘보다 강할 수 있다.

## 8. 금지할 애니메이션 습관

다음 연출을 반복해서 쓰지 않는다.
- 아이콘이 계속 튀어나오는 연출
- 모든 텍스트의 확대/축소
- 의미 없는 화살표 이동
- 계속 날아다니는 동전
- 반복되는 카드 등장
- 모든 숫자에 같은 줌
- 모든 장면의 페이드 인/아웃
- 이유 없는 카메라 패닝
- 의미 없는 배경 움직임

애니메이션은 반드시 다음 중 하나를 해야 한다: ① 설명한다 ② 비교한다 ③ 변화시킨다 ④ 강조한다 ⑤ 질문을 만든다. 어느 것에도 해당하지 않으면 움직이지 않아도 된다.

## 9. 실사 사용 원칙

실사는 장식용으로 쓰지 않는다. 다음을 보여 줄 때 쓴다.
- 제품, 장소, 사람의 행동
- 제조 과정, 구매 과정, 사용 과정
- 매장 환경, 현실의 규모

예:
- **라멘 영상**: 김이 올라오는 라멘, 면 삶기, 국물 붓기, 토핑, 식권기, 라멘 거리
- **팝콘 영상**: 영화관 입구, 팝콘 기계, 팝콘이 쏟아지는 장면, 컵에 담는 장면, 메뉴판, 관객이 들고 이동하는 장면

실사를 보여 주다가 구조 설명이 필요한 순간 Flat 2D로 전환한다.

## 10. 자료 사용 원칙

- 공식 자료는 영상의 신뢰도를 높이는 "증거"로 쓴다.
- 공식 보고서의 그래프나 표를 그대로 가져오지 않는다. 가능하면 **공식 숫자 확인 → 출처 표시 → KANENAZO 그래프로 재구성**한다.
- 공개되어 있다는 이유만으로 사진·영상·그래프를 다시 쓸 권리가 있다고 판단하지 않는다.

## 11. 자막 v3.0

모든 내레이션을 항상 하단 자막 박스에 표시하지 않는다. 하단 자막이 계속 유지되면 영상 전체가 하나의 템플릿처럼 보일 수 있다.

하단 자막을 생략할 수 있는 장면: 숫자 화면, 질문 화면, CLUE, 그래프, KEY TYPOGRAPHY, MONEY FLOW, FINAL CLUE.

예: 내레이션 「売れている。でも、残らない。」 → 화면에 「売れている。」「でも、残らない。」. 이 문장 자체가 자막 역할을 한다.

## 12. 첫 30초

첫 30초는 설명 시간이 아니라 **"미스터리 발생 시간"**이다.

| 시간 | 내용 |
|---|---|
| 0~5초 | 현실적인 대상 |
| 5~8초 | 첫 번째 질문 |
| 8~20초 | 상식과 현실의 충돌 |
| 20~30초 | 핵심 질문 / CASE TITLE |

예: REAL 영화관 팝콘 「700円」 → QUESTION 「原価は、いくら？」 → REAL 팝콘이 쏟아짐 → BUT 「でも――」 → CASE TITLE

## 13. 질문 사다리

질문은 반복하지 않고 깊어진다.

| 단계 | 질문의 성격 |
|---|---|
| Q1 | 상식적인 의문 |
| Q2 | 돈에 대한 의문 |
| Q3 | 첫 답에서 생긴 새로운 의문 |
| Q4 | 데이터가 보여 주는 모순 |
| Q5 | 구조적인 원인 |
| FINAL | 처음 질문으로 돌아간다 |

예: 왜 비싸지? → 원가는 얼마지? → 원가가 낮다면 왜 이렇게 비싸지? → 그 돈은 누가 가져가지? → 이 구조가 왜 필요한 거지? → 처음 가격의 의미가 완전히 달라진다.

## 14. CLUE 시스템

- CLUE는 보통 3~5개 정도 쓴다. 개수를 억지로 맞추지 않는다.
- 각 CLUE는 반드시 "지금까지 알아낸 것"이어야 한다.
- CLUE 뒤에는 다음 질문이 생겨야 한다. CLUE가 단순 요약으로 끝나면 안 된다.

## 15. 숫자 연출

숫자를 한꺼번에 보여 주지 않는다.

- **나쁜 예**: 市場 8855億 / 店舗 6305 / 利益 171億 / 前年比 XX% 를 한 화면에
- **좋은 예**: 8855億円 → 「市場は過去最大。」 → 6305店 → 「店舗も増えた。」 → 그런데 화면 정지 → 356億円 → 171億円 → 「売れている。でも、残らない。」

숫자 자체가 스토리가 되어야 한다.

## 16. MONEY FLOW 원칙

MONEY FLOW는 영상 후반에 갑자기 등장하는 요약 그래픽이 아니다. 영상 전체에서 추적하던 돈이 최종적으로 하나의 구조로 연결되는 순간이다.

| 구간 | 돈의 모습 |
|---|---|
| 초반 | 1000円 |
| 중반 | 1000円에서 돈이 빠져나간다 |
| 후반 | 1000円이 어디로 이동했는지 완성된다 |
| FINAL | 시청자가 처음 봤던 1000円의 의미가 완전히 달라진다 |

## 17. 패턴 브레이크

약 60~90초마다 시각적 리셋이 필요한지 확인한다.

사용할 수 있는 방식: 암전, 무음, 실사 전환, 숫자 하나, 흰 화면, 문서, 지도, 타임라인, 강한 한 문장, 환경음만 들려주는 장면, 이전 장면 재현.

같은 패턴 브레이크를 연속해서 반복하지 않는다.

## 18. 사운드

BGM은 영상 전체에 하나를 반복하지 않는다.

| 구간 | 사운드 |
|---|---|
| HOOK | 긴장 |
| ANALYSIS | 차분한 리듬 |
| EVIDENCE | 음악 낮춤 |
| QUESTION | 거의 무음 |
| REVEAL | 변화 |
| ENDING | KANENAZO 고정 사운드 |

- SFX는 최소화하고, 중요한 숫자나 CLUE 등에만 제한적으로 쓴다.
- **금지**: 반복적인 클릭음, 계속되는 whoosh, 고주파 효과, AI 영상에서 흔한 glitch, 의미 없는 digital beep

## 19. 편집자가 매 장면에 물어볼 질문

이 장면은 무엇을 하는가? ① 현실을 보여 주는가 ② 설명하는가 ③ 증명하는가 ④ 비교하는가 ⑤ 질문을 만드는가 ⑥ 반전을 만드는가. 어느 것에도 해당하지 않으면 장면을 다시 설계한다.

## 20. 가장 중요한 체크

장면 설계가 끝나면 전체 영상을 썸네일 크기로 펼쳐 본다. 화면들이 전부 「베이지 베이지 베이지 베이지」 또는 「Flat Flat Flat Flat」처럼 보이면 실패다.

내용이 다르다고 화면이 다른 것은 아니다. 시청자가 느끼는 **"화면의 재질"**이 달라야 한다.

## 21. KANENAZO가 지향하는 최종 영상 문법

1. 현실을 보여 준다.
2. 이상한 점을 발견한다.
3. 질문한다.
4. 돈을 따라간다.
5. 증거를 발견한다.
6. Flat 2D로 보이지 않는 구조를 설명한다.
7. 숫자가 상식을 뒤집는다.
8. 다시 현실로 돌아온다.
9. 새로운 질문이 생긴다.
10. MONEY FLOW가 완성된다.
11. 처음의 가격으로 돌아온다.
12. 시청자가 그 가격을 이전과 다르게 보게 만든다.

## 22. KANENAZO의 정의

KANENAZO는 "플랫 2D 경제 설명 채널"이 아니다. **「身近なお金の謎を追う、ビジネス・ミステリードキュメンタリー。」**이다.

Flat 2D는 정체성이지만 영상 전체의 형식은 아니다.
- REAL은 현실을 보여 준다.
- EVIDENCE는 사실을 증명한다.
- DATA는 상식을 흔든다.
- FLAT 2D는 구조를 설명한다.
- MONEY FLOW는 돈의 행방을 보여 준다.
- QUESTION은 다음 장면을 보게 만든다.
