## 상식 점검 (P3)

- 「ドラッグストア 食品 安い なぜ」 검색 1위 답: **薬・化粧品で稼いで、食品で客を呼ぶ**(R6). → 알려진 답 → **중간 보상**으로.
- 한 층 더(최종 답 후보):
  1. 싼 식품은 손해가 아니라 **"내점 횟수"를 사는 값**(R5 食品 15% vs 薬 42%).
  2. 그 내점을 회수하는 주머니가 **세 개**: 손님 지갑(식품·일용품) + 이익률 큰 약·화장품 + **공적 보험에서 오는 조제**(R2·R3·R13). 조제 매출은 전국 조제 의료비보다 5배 빠르게 늘었다(R3).
  3. 그래서 식품 비중을 반 이상으로 올려도(R7 51.3%) 이익이 늘고(R7·R8), 규모가 커질수록 더 싸게 → 10조 원 산업(R1)·2.3조 연합(R9), 반대편에서는 동네 슈퍼 도산(R11).
- ONLY-HERE FACTS: 10兆0,307億円·2万3,723店 / 食品 +13.2%(가장 빠름) / 調剤 1兆5,205億円(+8.4% vs 전국 +1.6%) / 食品 粗利 15.1% vs 医薬品 42.3%(옛 자료) / アオキ 食品 51.3% / 비축미 2万トン / 도산 358건 → 6개 이상.
