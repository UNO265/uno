# CASE #006 사전 조사 — カプセルトイ(ガチャガチャ)

조사일 2026-09-28. 1차 자료 원문(★)은 작업 환경에서 열리지 않아(prtimes·bandainamco·cross-m) 보도·검색 요약으로 교차 확인했다. 대본 전에 원문을 확인한다.

## 쓰지 않는 것 / 약한 것
- **설치 장소의 몫(20〜40%)**: 업계 해설·프랜차이즈 사이트뿐. 1차 자료가 아니다 → 숫자로 쓰지 않는다. 쓰려면 상장 오퍼레이터(ハピネット 등) 결산에서 찾는다.
- 1회당 이익(「1回いくら儲かる？」): 공개 자료 없음 → **CORE v4 2번에 따라 이 제목은 쓰지 않는다.**
