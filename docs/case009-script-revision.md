# #009 대본 보강안 (데이터 데스크 B안, 사용자 확정 대기)

확정 대본의 주제·제목·질문·결론은 바꾸지 않는다(C6). 숫자 근거만 1차 자료로 바꾸고, 바뀐 문장만 음성을 다시 만든다.

## R1. D07 (0:43) — **사실 수정 필요**

웰시아는 유가증권보고서에 **품목별 매출과 매입**을 공개한다. 「商品ごとの原価も、出していない」는 부정확.

| 지금 | 보강안 |
|---|---|
| 最初に言っておくと、食品だけでいくら儲かっているのかは、どの会社も公表していない。 / 商品ごとの原価も、出していない。 / だから今日は、業界の統計と、各社の決算で追いかける。 | 最初に言っておくと、食品だけでいくら儲かっているのかは、どの会社も公表していない。 / ただ、ある大手は、商品ごとの売上と仕入れの金額を、決算の資料に載せている。 / だから今日は、業界の統計と、その資料で追いかける。 |

## R2. D12 (1:49~) — 2019년 보도 → 2025년 1차 자료

| 지금 | 보강안 |
|---|---|
| 2019年の報道では、ドラッグストアの食品の粗利、つまり売値から仕入れ値を引いた残りは、売上の15.1%。 / コンビニの、半分ほどだ。 / しかも粗利は、まだ利益ではない。 / ここから、店員の給料も、家賃も、電気代も払う。 / 一方、薬は42.3%。 / 100円分の食品を売って残るのは15円ほど、100円分の薬なら42円ほど、という計算になる。 | ウエルシアの2025年2月期の資料では、食品の売上は2995億円、仕入れは2457億円。 / 差し引くと、100円分の食品を売って残るのは、18円ほどだ。 / しかもこれは、まだ利益ではない。 / ここから、店員の給料も、家賃も、電気代も払う。 / 同じ計算をすると、薬は100円で39円ほどが残る。 / 食品の、およそ2倍だ。 |

- 근거: 식품 1−245,720/299,514 = 18.0%, 의약품 1−142,933/233,255 = 38.7%(계산). 매입과 매출의 차이라 재고 변동 등으로 실제 매출총이익과 다를 수 있다 → 화면에 「計算・目安」.
- 「コンビニの半分ほど」는 2019년 보도 기준이라 뺀다.

## R3. D23 (7:41 「三つ目が、調剤だ」 뒤) — 세 번째 지갑을 숫자로

| 지금 | 보강안 (추가 1문장) |
|---|---|
| 値下げ競争に、巻き込まれない売上なのだ。 | 値下げ競争に、巻き込まれない売上なのだ。 / **ウエルシアの資料で同じ計算をすると、調剤は100円で37円ほどが残る。** |

- 근거: 1−177,456/282,548 = 37.2%(계산).

## 분량

R1·R2는 거의 같은 길이, R3는 한 문장 추가(약 40자). 4,053자 → 약 4,100자(C3 충족 유지).
