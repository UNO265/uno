## 계산(精米5kg 기준, 「計算」 표기)

| 항목 | 2025년산(概算金 30,000) | 2026년산(概算金 18,500) |
|---|---|---|
| 농가가 받는 돈 | **約2,778円** | **約1,713円** |
| 생산 비용(지표) | 約1,839円(19,860) | 約1,902円(20,535) |
| 차이 | **約+940円** | **約−190円** |

- 「−」는 **가족 노동을 임금으로 친 비용까지 넣었을 때** 모자란다는 뜻(현금 적자와 다름). 대본에서 반드시 이렇게 말한다(C4).
- 概算金은 지역·품종·등급별로 다르다 → 「新潟の一般コシヒカリの場合」로 한정하고 범위(1万5千~1万8千円台)를 함께.

## ANSWER CARD (01 P2)

| 항목 | 내용 |
|---|---|
| 제목 질문 / 답의 형식 | 「お米5キロ、農家に残るのは？」 / **숫자** |
| 공개 자료로 말할 수 있는 답 | 5kg에서 농가가 받는 돈은 2025년산 약 2,800円 → 2026년산 약 1,700円. 공적 비용 지표(약 1,900円)를 넣으면 **작년엔 약 900円 남았지만, 올해는 0円 이하**(계산, 新潟コシヒカリ 기준) |
| 출처(1차) | ①米穀機構 コスト指標 ②農水省 相対取引価格 ③農水省 米生産費統計 (+ JA 概算金 보도, 소매가 농수성 POS) |
| 공개되지 않는 부분과 처리 | 농가 개별 이익은 비공개 → 첫 1분에 「一軒ごとの儲けは公表されていない。でも、国と業界の数字で5キロの中身は分けられる」 |
| 처음 답하는 시각 | 2분 안(영상의 약 15%) |
| 상식 점검(깊이 점검 1) | 「農家の手取りは少ない」「JA·流通이 가져간다」는 흔한 이야기 → 반증: 비용의 약 68%는 생산 단계, 유통·소매는 약 32% → 중간 보상. 최종 답은 「값이 비싸도 농가가 남지 않는 해가 있다 = 가격이 아니라 **흔들림**이 문제」 |
| ONLY-HERE FACTS | ①5kg 2,816円의 단계별 분해(생산 1,902·소매 462…) ②농가 몫이 1년 만에 +940 → −190円(계산) ③소매가는 내려가도 4할 덜(4,279→3,191, 약 −25%), 농가 몫은 약 −38% → 하락은 농가 쪽이 더 크다 |
| 정치 중립 | 정책 찬반·정치인 이름 없이, 숫자와 구조만. BGM(OpenTracks) 규약상 정치 콘텐츠 금지도 고려 |
