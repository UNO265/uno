## P2. 첫 제작 테스트 (원본 §21)

| 항목 | 내용 |
|---|---|
| 후보 원본 | **Finally Free — Japan Was Not What We Expected** |
| 콘셉트 후보(제목) | 「日本は想像とまったく違った… 初来日の60代夫婦が、わずか1日で気づいたこと」 |
| 한국어 | 일본은 상상과 전혀 달랐다… 처음 일본을 찾은 60대 부부가 단 하루 만에 깨달은 것 |
| 판정 원칙 | **원본 전체를 실제로 확인한 뒤 스토리성이 부족하면 과감히 교체한다. 첫 영상이라는 이유로 억지로 만들지 않는다.** |
| 상태 | **본편 미확인**(2026-10-01). 네트워크는 열렸지만 YouTube가 클라우드 IP의 영상·자막 요청을 봇 확인으로 차단 → 사용자가 자막 텍스트(또는 허락받은 원본 파일)를 제공해야 진행 |

원본 메타데이터(2026-10-01 확인, 설명란 기준 — 본편 확인 전이므로 아래는 "제작자 본인 설명"이다):

| 항목 | 내용 |
|---|---|
| URL | https://www.youtube.com/watch?v=Ik_w20be0Cw |
| 채널 | Finally Free(구독자 약 2,290명) — 미국에서 5th wheel 트레일러로 RV 여행하는 John·Brenda 부부 |
| 업로드 | 2026-04-02, 12:58, 조회 약 2,900회 |
| 인물 | 설명란: "a couple in our 60s", 첫 일본 여행 |
| 기간 | 설명란: "This was only our first day" — 첫날 영상 |
| 챕터 | 0:00 첫인상 / 0:14 존중 문화(손녀가 스쿨버스에서 선생님께 인사) / 0:43 고토쿠인 대불 / 1:14 하세데라 예절 / 3:48 길거리 음식 먹는 법 / 5:47 맥도날드 / 6:34 일본의 RV / 7:32 돈키호테 / 8:14 iPad 주문 / 10:27 서빙 로봇 / 12:27 첫날 솔직한 소감 |

- 제목의 "60대 부부", "하루"는 설명란과 일치한다. 본편 발언으로 다시 확인한다(F3).
- **확인할 점(S2)**: 손녀가 일본 학교에 다닌다 → 가족이 일본에 산다. 영상은 부부가 자기 채널용으로 직접 찍었으므로 S1-③은 충족할 가능성이 높다. 다만 "장기 거주자가 가족을 초대해 반응을 목적으로 기획한 콘텐츠"(S2)가 아닌지는 본편에서 확인한다.
- 챕터 구성상 관광지 나열형일 위험이 있다. "무엇을 했는가"가 아니라 "무엇을 느꼈는가"(F9)가 남는지는 첫날 소감(12:27~)과 각 장면의 실제 발언으로 판정한다.

## P4. 레포 안에서의 위치

- 이 채널의 모든 파일은 `channels/foreigner-story/` 안에 둔다. CASE별 작업은 `channels/foreigner-story/cases/<번호>/`.
- 렌더링 도구(Remotion·ffmpeg·VOICEVOX 스크립트)는 레포 루트 `video/`의 것을 참고·재사용할 수 있지만, **KANENAZO 전용 규칙(실사 없음, 분량 4,000자, 고정 엔딩, CASE 브랜드 요소 등)은 이 채널에 적용하지 않는다.**
