# 05 SHORTS — 롱폼 요약본이 아니라, 자체적으로 끝나는 작은 이야기

> 원본: [v1.2](source/foreigner_story_guide_v1.2.md) §6. 상위 원칙은 [00_CORE](00_CORE.md), 자막은 [04_EDIT_SUBTITLE](04_EDIT_SUBTITLE.md).

## SH1. A. 단일 사건형 — 우선 시험할 형식

레퍼런스 R06(가방)처럼 「선택 → 시간 경과 → 의문 → 눈으로 확인되는 결과」가 있는 사건에 맞는다. **약 35~55초**를 초안 범위로 하되 원본의 의미가 우선.

| 대략의 순서 | 역할 |
|---|---|
| 0~3초 | 무엇이 궁금한지 즉시 알 수 있는 실제 장면과 짧은 제목 |
| 3~10초 | 인물과 상황, 무슨 선택을 했는지 |
| 10~30초 | 행동·대화·변화. 결과를 궁금하게 만드는 실제 정보 |
| 30~45초 | 결과를 보여 주고 당사자의 반응까지 유지 |
| 끝 2~5초 | 반응 또는 짧은 여운으로 끝냄 |

- 「1時間後」 같은 자막은 원본 근거가 있을 때만.
- 긴장감을 만들려고 걱정하지 않은 사람을 걱정한 것으로 바꾸지 않는다.
- **결과 장면을 내레이션으로 대신하지 않는다.**

## SH2. B. 한 인물의 연속 발견형

레퍼런스 R04처럼 한 인물·주제로 짧은 발견 여러 개를 묶는다. 사건이 많다고 더 좋은 것은 아니다. 초안은 **연결되는 2~3개 발견**부터 시험한다.

- 각 발견은 `대상/상황 → 실제 한마디 → 다음 발견`으로 이해될 만큼 남긴다.
- 마지막에는 가장 선명한 반응이나 가벼운 반전.
- 유명세·구독자 수에 기대려면 그 수치의 근거와 시점을 확인한다.

## SH3. 롱폼에서 쇼츠를 뽑는 기준

- 독립적으로 이해되는 사건을 고르고, **쇼츠만 봐도 결과를 알 수 있게 완결**한다. 롱폼으로 유도하려고 결과를 일부러 자르지 않는다.
- 16:9를 단순 확대하지 말고 얼굴·손·결과물이 보이게 **9:16으로 다시 구성**한다. 공간 관계가 중요하면 가로 화면을 보존하고 상하 영역을 활용한다.
- 롱폼마다 독립된 사건 1개를 쇼츠로 만든다(→ [03_PRODUCTION](03_PRODUCTION.md) P1 7단계).
