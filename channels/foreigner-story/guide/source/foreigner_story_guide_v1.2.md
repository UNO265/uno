# 일본 방문 외국인 스토리 채널 제작 지침 v1.2

작성일: 2026-10-01 · 기존 v1.1의 보완판 · 사용자 제공 레퍼런스 6편과 첫 제작 영상 비교

**다음 영상부터의 핵심 원칙: 설명할 소재보다, 끝까지 지켜볼 만한 사람의 행동을 먼저 찾는다.**

이 문서는 기존 v1.1의 ‘실제 방일 여행자, 원본 근거, 이야기 중심, 과장하지 않는 해설’ 원칙을 유지한다. 한국 대상 채널의 말투를 일본어로 그대로 옮기는 방식이 아니라, 레퍼런스에서 관찰한 이야기 구조를 일본어 콘텐츠 제작에 적용한다. 시청 성과 자료는 없으므로 아래 길이·배치 수치는 시험 편집의 출발점이며 성공 공식이 아니다.

## 1. 이미 확정한 채널 방향과 표현

| 항목 | 유지할 기준 |
|---|---|
| 시청 대상 | 일본어로 시청하는 사람. 특정 연령대의 취향은 아직 검증되지 않음 |
| 주인공 | 해외를 기반으로 활동하며 실제 일본 여행을 기록한 외국인 여행자 |
| 핵심 | ‘일본이 대단하다’는 결론보다, 이 사람이 무엇을 겪고 어떤 반응을 보였는지 |
| 원본과 해설 | 원본 발언은 근거, 내레이션은 필요한 맥락과 연결. 추측을 인용처럼 쓰지 않음 |
| 내레이션 자막 | 흰색 굵은 글자 + 검정/짙은 배경 띠 |
| 현장 발언 번역 자막 | 노란색 굵은 글자 + 검정 테두리 |
| 가독성 | 한 줄을 우선하되 긴 문장은 의미 단위로 나눔. 한 줄에 넣으려고 글자를 축소하지 않음 |
| 일본어 | 자연스러운 구어 번역, 차분한 설명체. 화자의 확신·유머·망설임을 보존 |
| 최종본 | ‘검토용’, ‘구성·일본어 내레이션을 추가한 버전’ 등 제작 메모를 화면·엔딩에서 제거 |

‘일본인이 좋아하는 폰트’라는 단일 정답은 가정하지 않는다. 일본어 글꼴의 명확한 획, 큰 크기, 안정적인 대비를 우선한다. 서체 선택이 다큐멘터리의 신뢰감을 대신하지는 않는다.

## 2. 소재를 찾을 때부터 이야기 가능성을 판단한다

검색은 채널을 찾는 출발점이다. 제목의 ‘first time’, ‘shocked’만 보고 채택하지 않는다. 원본을 확인하고 다음 여섯 질문에 답한다.

1. **사람:** 누가 여행하는가? 부부·가족·친구 관계가 장면 안에서 드러나는가?
2. **목적:** 지금 무엇을 하려는가? 주문, 이동, 구매, 체험처럼 구체적인가?
3. **불확실성:** 무엇을 모르거나 예상하지 못하는가? 위험할 필요는 없다.
4. **행동:** 직접 선택하고 시도하는 장면이 있는가?
5. **반응:** 그 순간의 원래 말·표정·상대방 답변이 남아 있는가?
6. **결과:** 무엇이 실제로 일어났고, 처음과 무엇이 달라졌는가?

**채택 판단:** 목적·행동·반응·결과가 이어지면 주 이야기 후보. 아름다운 풍경과 “와!”만 있으면 보조 장면 후보. 인물의 기대와 변화를 내레이션으로 만들어 넣어야만 성립하면 보류한다.

검색 조합 예시: `first time Japan family travel vlog`, `Japan first day couple ordering food`, `Japan rural trip language barrier vlog`, `Japan train first time family`, `Tokyo unexpected experience travel vlog`. 발견 후에는 채널의 평소 활동, 실제 여행 여부, 원본 업로드 맥락을 확인한다. 검색 문구에 맞는 사건이 실제로 있었다고 가정하지 않는다.

### 채택 카드

```text
원본 URL / 채널 / 업로드일:
주인공과 여행 상황:
이야기를 한 문장으로:
처음의 목적·기대 — 근거 타임코드:
직접 행동 — 근거 타임코드:
뜻밖의 지점 — 근거 타임코드:
실제 반응 — 원문과 타임코드:
결과·변화 — 근거 타임코드:
확인이 필요한 주장:
이용 허락·라이선스 확인 상태:
롱폼 주 이야기 / 쇼츠 단일 사건 / 보조 장면 / 보류:
```

출처 표기와 이용 허락 확인은 별도로 기록한다. 이용 허락 상태가 확인되지 않았다면 확인된 것으로 기재하지 않는다.

## 3. 롱폼: 큰 질문 하나 안에서 작은 사건을 완결한다

레퍼런스 롱폼 4편은 약 19~29분이지만, 그 길이를 채널의 목표로 복사하지 않는다. 우리 채널은 먼저 **8~12분 정도의 한 이야기**를 시험할 수 있다. 사건이 적으면 더 짧게, 유의미한 대화가 많으면 더 길게 편집한다. 분량을 채우기 위해 관광지와 감탄을 추가하지 않는다.

### 시험용 구성

| 구간 | 해야 할 일 | 피할 일 |
|---|---|---|
| 첫 0~8초 | 실제 행동·발언·뜻밖의 반응으로 시작 | 긴 인사, 채널 로고, 추상적인 국가 칭찬 |
| 약 8~25초 | 누구에게 어떤 일이 생겼는지, 지금 볼 이유 제시 | 결과를 전부 설명한 뒤 같은 장면 재생 |
| 약 25~45초 | 이해에 필요한 인물·시간·장소만 되짚기 | 관계없는 여행 이력과 배경 설명 |
| 본문 초반 | 첫 작은 문제나 궁금증을 실제 결과까지 보여 주기 | 제목의 보상을 끝까지 전부 미루기 |
| 본문 중반 | 선택·시도·대화가 달라지는 2~4개 사건으로 전개 | ‘설명 → 짧은 감탄 → 설명’만 반복 |
| 마지막 | 핵심 질문 회수, 가장 구체적인 당사자 반응, 짧은 여운 | 모든 방문지 재설명, 근거 없는 감동 선언 |

위 시간은 편집 초안용이다. 첫 장면에 필요한 행동이 길면 자르지 않고, 짧아도 뜻이 완성되면 넘어간다. 첫 30초 안에 상황을 파악할 수 있는지 실제로 확인하는 것이 초 단위 준수보다 중요하다.

### 장면 한 묶음의 기본 순서

**상황 → 선택/시도 → 상대의 답 또는 실제 결과 → 당사자의 반응 → 다음 행동**

예: 메뉴를 이해하지 못함 → 메뉴를 가리키며 질문 → 직원이 설명 → 본인이 선택 → 음식이 도착 → 실제 맛 평가. 원본에 이 과정이 있을 때만 사용한다. 질문만 있고 답이 없으면 답을 다른 장면에서 만들어 붙이지 않는다.

모든 사건에 다섯 단계를 강제로 넣지는 않는다. 이미 화면으로 이해되는 상황 설명은 생략한다. 편집의 단위는 ‘5초짜리 컷’이 아니라 **하나의 행동 또는 의미가 끝나는 지점**이다.

### 다음 장으로 넘어가는 이유

‘다음 장소에서도 놀랐습니다’ 대신 실제 연결을 쓴다. 식사 후 결제가 남았거나, 주문을 마친 뒤 받는 방법이 궁금해지거나, 이동 때문에 새로운 선택이 생기는 식이다. 인과관계가 없다면 ‘그 뒤 다른 날’처럼 시간 변화를 명확히 밝힌다.

## 4. 내레이션은 대화가 할 수 없는 일만 한다

| 필요한 역할 | 문장 예시/방향 |
|---|---|
| 생략된 상황 연결 | 「注文を終えた二人。次は、料理をどう受け取るのかが気になります。」 단, 궁금해하는 발언이 실제로 있을 때 |
| 시간·장소 이동 | 「翌日、二人が向かったのは——。」 다음 날이라는 근거 확인 |
| 이해에 필요한 사실 | 인물 관계, 주문한 음식명, 다음 행동의 이유 |
| 범위가 명확한 정리 | 「この店の注文方法は、二人にとって初めての体験でした。」 해당 경험 근거 필요 |

다음 문장은 우선 삭제 검토한다.

- 화면에 이미 보이는 동작을 그대로 읽는 문장.
- 곧 나올 원본 대사의 의미를 미리 말하는 문장.
- 원본 대사가 끝난 직후 같은 뜻을 다시 요약하는 문장.
- 「驚きを隠せません」「日本の素晴らしさに感動」처럼 근거보다 감정을 크게 규정하는 문장.
- 이야기를 진행하지 않는 ‘또 다른 발견’, ‘새로운 시선’, ‘평범한 일상의 특별함’의 반복.

**편집 진단용 시작점:** 본문에서 내레이션 구간이 절반을 넘으면 설명이 과한지 검토한다. 이는 정답 비율이 아니며 원본의 정보 밀도에 따라 달라진다. 연속 설명이 약 15~20초를 넘으면 중복 여부를 점검하되, 맥락상 필요하면 유지한다. 외국인의 원본 발언은 감탄 한마디뿐 아니라 질문과 답, 망설임과 웃음까지 하나의 의미로 남긴다.

## 5. 컷과 소리의 리듬

- 행동을 준비하는 손 → 행동/물건 → 얼굴의 반응을 연결하되 원래 시공간을 유지한다.
- 표정이 바뀌는 순간과 상대의 답변이 끝나기 전에 자르지 않는다.
- 정적인 대사라도 새로운 정보나 관계가 드러나면 유지한다. 반대로 화면이 많이 바뀌어도 의미가 같으면 줄인다.
- 새 장소를 보여 주는 짧은 컷, 대화가 이어지는 긴 컷, 결과를 확인하는 컷을 섞는다. 일정한 초 간격의 기계적 교대는 피한다.
- 이동·가격·선택지 설명에만 지도, 금액, 화살표 등의 보조 정보를 쓴다. 시청자가 봐야 할 대상을 가리는 장식은 제거한다.
- 원본 음성을 우선하고, 대사 중 배경음악은 낮춘다. 환경음과 짧은 침묵도 현장감을 만드는 재료다.
- 실제 반응보다 과한 충격음·확대·반복을 사용하지 않는다. 필요한 강조는 사건의 핵심 순간에 제한한다.
- 다른 때의 얼굴을 붙여 현재 사건에 반응한 것처럼 보이게 하지 않는다. 관련 없는 스톡 인물을 ‘해외 시청자 반응’의 증거로 쓰지 않는다.

음악 크기와 전환 속도는 레퍼런스의 정밀 측정값이 아니라 우리 제작 시 확인할 기준이다.

## 6. 쇼츠: 롱폼 요약본이 아니라, 자체적으로 끝나는 작은 이야기

### A. 단일 사건형 — 우선 시험할 형식

가방 레퍼런스 R06처럼 ‘선택 → 시간 경과 → 의문 → 눈으로 확인되는 결과’가 있는 사건에 적합하다. **약 35~55초**를 초안 범위로 삼되 원본의 의미를 우선한다.

| 대략의 순서 | 역할 |
|---|---|
| 0~3초 | 무엇이 궁금한지 즉시 알 수 있는 실제 장면과 짧은 제목 |
| 3~10초 | 인물과 상황, 무슨 선택을 했는지 |
| 10~30초 | 행동·대화·변화. 결과를 궁금하게 만드는 실제 정보 |
| 30~45초 | 결과를 보여 주고 당사자의 반응까지 유지 |
| 끝 2~5초 | 반응 또는 짧은 여운으로 끝냄 |

‘1시간 후’ 같은 자막은 원본 근거가 있을 때만 넣는다. 긴장감을 만들기 위해 걱정하지 않은 사람을 걱정한 것으로 바꾸지 않는다. 결과 장면을 내레이션으로 대신하지 않는다.

### B. 한 인물의 연속 발견형

R04처럼 하나의 인물·주제로 짧은 발견 여러 개를 묶는 방식이다. 사건이 많다고 무조건 더 좋은 것은 아니다. 우리 초안은 **연결되는 2~3개 발견**부터 시험한다.

각 발견은 `대상/상황 → 실제 한마디 → 다음 발견`으로 이해될 만큼 남긴다. 마지막에는 가장 선명한 반응이나 가벼운 반전을 둔다. 유명세·구독자 수에 의존하려면 해당 수치의 근거와 시점을 확인한다.

### 롱폼에서 쇼츠를 뽑는 기준

독립적으로 이해되는 사건을 선택하고, 쇼츠만 봐도 결과를 알 수 있게 완결한다. 롱폼 시청을 유도하려고 결과를 고의로 잘라내지 않는다. 16:9를 단순 확대하지 말고 얼굴·손·결과물이 보이는지 9:16으로 다시 구성한다. 공간 관계가 중요하면 가로 화면을 보존하고 상하 영역을 활용한다.

## 7. 자막과 일본어 검수

현재 720p 롱폼의 Yu Gothic Bold 56px를 출발점으로 삼는다. 1080p에서는 같은 비율의 약 84px부터 확인한다. 이 수치를 모든 화면에 고정하지 않고 실제 휴대폰 크기로 읽히는지 확인한다. 상업용 프로젝트에서 사용하는 글꼴의 이용 조건도 확인한다.

| 항목 | 적용 방법 |
|---|---|
| 한 줄 | 720p 기준 우선 약 12~18자를 편하게 읽히는 초안으로 사용. 문장·영문·숫자 폭에 따라 조절 |
| 긴 문장 | 조사·수식 관계를 끊지 않는 짧은 의미 단위로 순차 표시 |
| 예외 | 두 줄이 의미와 읽기 시간을 더 잘 지키면 제한적으로 사용. 큰 글씨 유지 |
| 색 | 해설 흰색 / 현장 번역 노란색을 고정. 화자 구분이 필요하면 짧은 이름 표기 |
| 위치 | 입·표정·손·메뉴를 피하고 하단 여백 확보. 쇼츠 우측 버튼과 하단 UI 영역도 미리보기에서 확인 |
| 표시 시간 | 음성과 맞추고 읽을 여유를 확보. 같은 문장을 단어마다 과도하게 깜빡이지 않음 |
| 출처 | 작지만 읽을 수 있게, 주 자막과 분리. 크레딧은 제작 메모와 분리 |

### 번역 절차

1. 원본 음성을 기준으로 원문을 확정한다. 자동 전사와 기존 편집 영상의 번역 자막은 보조 자료다.
2. 누가 누구에게 말하는지, 농담·비꼼·의문·추측인지 확인한다.
3. 일본어로 자연스럽게 옮기되 평가의 강도를 높이지 않는다. ‘좋다’를 ‘인생 최고’로 바꾸지 않는다.
4. 일본어 독자가 빠르게 읽을 수 있게 나눈다. 짧게 만드는 과정에서 부정어·조건·비교 대상을 누락하지 않는다.
5. 고유명사·숫자·장소·시간·음식명과 대조한다. 불명확하면 보류 표시 후 해결하거나 제외한다.
6. 내레이션과 원본 발언을 서로 대조해 중복과 의미 불일치를 제거한다.

예시: R05의 “Japan is going to spoil me with fish”를 「魚に甘やかされそう」처럼 직역하면 어색하다. 문맥에 맞게 「日本の魚を食べたら、舌が肥えちゃうね」처럼 취지를 살릴 수 있다. 이는 이 문장의 번역 방향 예시이며 R05 전체 번역을 보증하는 뜻은 아니다.

## 8. 제목·도입의 약속을 지킨다

제목은 **사람 + 구체적 상황 + 실제 생긴 일/궁금증**으로 만든다. ‘전 세계 경악’, ‘1억 명 충격’, ‘눈물’, ‘10년의 꿈’은 증거가 없으면 쓰지 않는다. 작은 놀람에 맞는 제목도 충분히 가능하다.

가령 원본에 실제 주문 질문과 로봇 도착이 있다면 「初めての日本のファミレス。料理はどうやって届く？」 같은 범위에서 출발할 수 있다. 이 제목을 쓰면 주문·도착을 이야기의 중심에 두고, 무관한 관광 장면을 길게 끼워 넣지 않는다.

제목이 ‘공항 도착 직후’라고 말한다면 본문의 증거도 그 시간·장소여야 한다. 나중 장면을 미리 보여 주는 도입은 가능하지만, 그 반응이 공항에서 발생한 것처럼 바꾸지 않는다. 감탄하는 장면을 불쾌·공포로 오해하게 만드는 편집도 피한다.

## 9. 다음 편부터 적용할 실제 작업 순서

1. 원본 후보를 확보하고 채택 카드 작성.
2. 전체 흐름을 확인한 뒤 주요 장면을 USE / SUPPORT / DELETE로 분류.
3. 내레이션 없이 원본 행동과 대화만으로 이야기의 뼈대 편집.
4. 제목의 질문과 결과가 실제 장면으로 연결되는지 확인.
5. 빠진 맥락에만 짧은 일본어 내레이션 추가.
6. 원본 음성·일본어 번역 대조, 큰 자막 배치, 음악·환경음 정리.
7. 롱폼에서 독립된 사건 1개를 골라 쇼츠로 재구성.
8. 처음부터 끝까지 재생하면서 의미, 음성, 자막, 장면 순서 확인.
9. 최종 내보내기 파일의 시작·중간·끝과 전체 재생 오류 확인. 검토용 문구 제거 확인.

## 10. 완성 전 체크리스트

- [ ] 영상의 질문을 한 문장으로 말할 수 있다.
- [ ] 주인공의 목적과 관계를 초반에 이해할 수 있다.
- [ ] 제목과 도입의 약속을 실제 화면·발언으로 회수한다.
- [ ] 원본의 질문·답·반응을 내레이션이 가로채지 않는다.
- [ ] 모든 장면은 새 정보, 행동, 관계, 결과 중 하나를 더한다.
- [ ] 설명 전후에 같은 의미를 반복하는 부분을 줄였다.
- [ ] 시간·장소 이동과 다른 날의 장면을 오해하지 않게 표시했다.
- [ ] 일본어 자막의 의미·화자·부정어·수치를 원본과 대조했다.
- [ ] 휴대폰 크기에서도 자막이 크고 읽히며 화면의 핵심을 가리지 않는다.
- [ ] 마지막에 구체적인 실제 반응이 남고, 추상적인 칭찬이 길어지지 않는다.
- [ ] 출처·이용 조건 확인 상태를 기록했고 검토용 문구가 없다.

## 11. 첫 영상은 시험 자료로 활용한다

현재 최종본은 5분 47.6초다. 편집표상 내레이션 구간은 232.2초, 현장 원본 구간은 109.4초로, 본문 구간의 약 68%가 내레이션이다. 이는 실제 발화 시간의 정밀 측정값이 아니라 구간 종류별 길이다.

다음 편에서 먼저 바꿀 것은 **원본 행동·대화의 비중과 사건의 완결성**이다. 효과음·폰트·업로드 시각까지 동시에 크게 바꾸기보다 이 변화를 우선해 관찰한다. 서로 다른 소재 영상의 수치 차이를 편집 효과로만 단정하지 않는다.

공개 후 이용 가능한 시청 데이터에서 초반 이탈, 긴 설명 구간 전후의 변화, 결과 장면 전후의 변화, 평균 시청 시간·비율, 댓글의 구체적인 지적을 함께 본다. 표본이 적으면 결론을 유보한다. 조회수 한 개로 ‘일본인은 이 스타일을 싫어한다’고 판단하지 않는다.

다음 편을 만들 때 이 지침과 원본을 함께 사용한다. 저장된 지침만으로 미확인 대사나 사건을 자동 생성하지 않는다.
