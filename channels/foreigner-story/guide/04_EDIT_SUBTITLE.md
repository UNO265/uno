# 04 EDIT & SUBTITLE — 컷·소리·자막·번역

> 원본: [v1.2](source/foreigner_story_guide_v1.2.md) §1(자막·일본어·최종본·서체) ·§5(BGM 기준 포함)·§7
> 상위 원칙은 [00_CORE](00_CORE.md). 수치는 시험 편집의 출발점이다(00 판 관계).

## E1. 컷과 소리의 리듬 (v1.2 §5)

- 행동을 준비하는 손 → 행동/물건 → 얼굴의 반응을 잇되 **원래 시공간을 유지**한다.
- 표정이 바뀌는 순간과 상대의 답변이 끝나기 전에 자르지 않는다.
- 정적인 대사라도 새 정보나 관계가 드러나면 유지한다. 반대로 화면이 많이 바뀌어도 의미가 같으면 줄인다.
- 새 장소를 보여 주는 짧은 컷, 대화가 이어지는 긴 컷, 결과를 확인하는 컷을 섞는다. 일정한 초 간격의 기계적 교대는 피한다.
- 지도·금액·화살표 같은 보조 정보는 **이동·가격·선택지 설명에만** 쓴다. 봐야 할 대상을 가리는 장식은 뺀다.
- **원본 음성을 우선**하고, 대사 중 배경음악은 낮춘다. 환경음과 짧은 침묵도 현장감의 재료다.
- 실제 반응보다 과한 충격음·확대·반복을 쓰지 않는다. 강조는 사건의 핵심 순간에만.
- (다른 때의 얼굴·스톡 인물 금지는 00 F3)
- 음악 크기와 전환 속도는 레퍼런스의 정밀 측정값이 아니라 제작 때 확인할 기준이다.

## E2. 일본어 (v1.2 §1)

- 자연스러운 구어 번역, 차분한 설명체. **화자의 확신·유머·망설임을 보존**한다.

## E3. 자막 표기 (v1.2 §1·§7)

| 종류 | 표기 |
|---|---|
| 내레이션(NARRATION) | **흰색 굵은 글자 + 검정/짙은 배경 띠** |
| 현장 발언 번역(FACT/ORIGINAL) | **노란색 굵은 글자 + 검정 테두리** |
| 화자 구분 | **주고받는 대화는 노란 계열 안에서 화자별 색을 나눈다**(2026-10-02 사용자 결정). **같은 계열이라도 밝기와 색상을 함께 벌려 한눈에 구분되게 한다**(2026-10-03 사용자 요청). CASE #002: 연한 레몬 `#FFF680`(실케), 진한 주황 `#FF8A00`(키어런), 연두 `#8EE070`(일본인 출연자). 처음 제안한 노랑 `#FFD400`·주황빛 노랑 `#FFA733`은 구분이 약했다. 흰색은 내레이션 전용으로 남긴다. 화자가 처음 나올 때만 이름을 작게 붙인다 |
| 출처 | 작지만 읽을 수 있게, 주 자막과 분리. 크레딧은 제작 메모와 분리 |

- **글꼴(2026-10-01 사용자 확정)**: **Noto Sans JP Bold**(SIL Open Font License 1.1 — 상업 이용 가능, 영상에 넣어도 표기 의무 없음). 이 서버에는 Yu Gothic이 없다(Windows 글꼴). 획이 분명하고 굵기 단계가 많아 테두리·띠와 함께 써도 뭉개지지 않는다.
- **크기**: v1.2의 출발점(720p Yu Gothic Bold 56px)을 그대로 옮겨 **720p 56px / 1080p 약 84px**부터 확인한다. 이 수치를 모든 화면에 고정하지 않고 실제 휴대폰 크기로 읽히는지 확인한다. 상업용 글꼴의 이용 조건도 확인한다.
- 「일본인이 좋아하는 폰트」라는 단일 정답을 가정하지 않는다. 명확한 획, 큰 크기, 안정적인 대비가 우선. 서체가 다큐멘터리의 신뢰감을 대신하지 않는다.

| 항목 | 적용 방법 |
|---|---|
| 한 줄 | 720p 기준 약 12~18자를 초안으로. 문장·영문·숫자 폭에 따라 조절. **한 줄에 넣으려고 글자를 줄이지 않는다** |
| 긴 문장 | 조사·수식 관계를 끊지 않는 짧은 의미 단위로 순차 표시 |
| 예외 | 두 줄이 의미와 읽기 시간을 더 잘 지키면 제한적으로. 큰 글씨 유지 |
| 위치 | 입·표정·손·메뉴를 피하고 하단 여백 확보. 쇼츠는 우측 버튼·하단 UI 영역도 미리보기에서 확인 |
| 표시 시간 | 음성에 맞추고 읽을 여유 확보. 같은 문장을 단어마다 과도하게 깜빡이지 않음 |

## E4. 번역 절차 (v1.2 §7)

1. **원본 음성을 기준으로 원문을 확정한다.** 자동 전사와 기존 편집 영상의 번역 자막은 보조 자료다.
2. 누가 누구에게 말하는지, 농담·비꼼·의문·추측인지 확인한다.
3. 자연스럽게 옮기되 **평가의 강도를 높이지 않는다.** 「良い」(좋다)를 「人生最高」(인생 최고)로 바꾸지 않는다.
4. 빠르게 읽히게 나누되, 줄이는 과정에서 **부정어·조건·비교 대상을 빠뜨리지 않는다.**
5. 고유명사·숫자·장소·시간·음식명을 대조한다. 불명확하면 보류 표시 후 해결하거나 제외한다.
6. 내레이션과 원본 발언을 대조해 중복과 의미 불일치를 없앤다.

예: "Japan is going to spoil me with fish"를 「魚に甘やかされそう」(생선에게 응석받이가 될 것 같다 — 어색한 직역)로 직역하면 어색하다. 문맥에 맞게 「日本の魚を食べたら、舌が肥えちゃうね」(일본 생선을 먹다 보면 입맛이 고급이 되겠네)처럼 취지를 살린다(이 문장의 방향 예시일 뿐 R05 전체 번역을 보증하지 않는다).

## E5. 최종본 (v1.2 §1)

「検討用」(검토용)「構成・日本語ナレーションを追加したバージョン」(구성·일본어 내레이션을 추가한 버전) 같은 **제작 메모를 화면·엔딩에서 제거**한다.

## E6. 음악·효과음 (v1.2 §5 「BGM 제작·배치 기준」 + 2026-10-01 사용자 확정)

- **BGM·효과음은 CASE마다 자체 작곡**한다(가사 없는 기악곡, FluidR3_GM 사운드폰트 기반, 레포 루트 `video/scripts/music.py`·`sfx.py` 방식을 참고). 외부 음원을 쓰지 않으므로 음악 저작권 문제가 없다.
- 감정과 사건을 과장하지 않는 기악곡이 기본이다. **일본을 다룬다는 이유만으로 전통 악기나 웅장한 음악을 의무적으로 쓰지 않는다.**
- **현장 대화 구간에서는 내레이션 구간보다 음악을 더 낮춰** 발음·웃음·환경음이 들리게 한다.
- 실제 발화에 반응하는 **완만한 자동 감쇄(덕킹)**를 보조로 쓴다. 말끝마다 음량이 출렁이면 감쇄·복귀 속도를 조절한다.
- 컷마다 음악을 끊지 않는다. **장면 묶음 단위로 잇고, 큰 시간·장소 변화에서만 분위기를 바꾼다.**
- 사건의 정적이 중요하면 음악을 줄이거나 비운다. 음악으로 모든 빈틈을 채우지 않는다.
- 완성본에서 대사 명료도, 음악 전환, 클리핑, 마지막 페이드와 영상 길이를 확인한다. **음악 원본도 따로 보관**한다.
- 첫 영상 적용 예(v1.2): 잔잔한 건반 음색과 지속음 중심, 사찰 구간은 성기게, 상점 구간은 약한 리듬, 음식 도착 때는 대화·현장 소리 우선, 엔딩은 짧게 음악을 살린 뒤 페이드아웃.
- (원본 음성 우선·대사 중 음악 낮춤은 E1)
- CASE마다 사용한 악기·사운드폰트·라이선스를 `cases/<번호>/audio-credits.md`에 기록한다.

## E7. 내레이션 음성 (2026-10-02 사용자 확정)

- **VOICEVOX No.7 「読み聞かせ」(동화 읽어 주기) 스타일, style ID 31**(음성 모델 6.vvm). 카네나조의 雀松朱司(와카마쓰 아카시)와 겹치지 않게 다른 목소리를 쓴다.
- **크레딧 필수**: 설명란에 `VOICEVOX:No.7`.
- **이용 조건**(2026-10-02 [No.7 공식 약관](https://voiceseven.com/#j0200) 확인): 「個人や同人サークルのアカウントが動画投稿することで発生する広告収入」(개인·동인 서클 계정이 동영상을 올려 생기는 광고 수입)은 **비상업 이용**으로 무료·사전 신청 없이 가능. 「企業アカウントが動画投稿することで発生する広告収入」(기업 계정의 광고 수입)은 **상업 이용**이라 No.7 제작위원회와 사전 상담·라이선스(목안 15,000엔~)가 필요하다. → **채널을 법인·기업 계정으로 운영하게 되면 다시 확인한다.**
- 금지: 캐릭터 이미지를 크게 해치는 이용, 반사회적 세력의 이용 등(약관 원문 참고).

## E8. 화면 비율 (2026-10-03 사용자 결정: 「유튜브 롱폼 비율로」)

- 롱폼은 **16:9 화면 가득**(1280×720 이상). 원본이 가로로 더 긴 영화 비율(예: 2.37:1)이면 위아래 검은 띠를 두지 않고 좌우를 잘라 확대한다(`plan["frame"]="fill"`).
- 사람이 화면 가장자리에 있는 장면은 클립마다 자르는 위치(`cx`, 0~1)를 옮겨 얼굴이 잘리지 않게 한다. 렌더링 전에 장면별 자르기 창을 그린 확인 시트로 점검한다.
- 자막이 화면 위에 올라가므로 테두리와 그림자를 더하고, 원본에 박힌 글자(영어 자막)보다 위에 오도록 자막 높이를 올린다.
