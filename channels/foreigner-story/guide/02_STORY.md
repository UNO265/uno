# 02 STORY — 원본 분석·스토리 구성·제목·첫 30초

> 원본: [GUIDE v1.0](source/japan_foreigner_story_channel_guide_v1.0.pdf) §3·§9·§14·§15·§16·§17
> 상위 원칙은 [00_CORE](00_CORE.md)(특히 F3 팩트, F4 FACT/NARRATION 구분). 분석 결과는 [source-analysis](../templates/source-analysis.md) 2~3부에 적는다.

## T1. 기본 스토리 공식 (원본 §3)

**EXPECTATION → EXPERIENCE → DISCOVERY → REACTION → CHANGE**
**예상 → 경험 → 발견 → 반응 → 변화**

- 모든 단계가 꼭 있어야 하는 것은 아니다.
- **최소한 「경험 + 실제 반응 + 의미 있는 변화 또는 발견」**이 있어야 우선 제작 후보가 된다.
- 각 단계는 원본의 실제 장면(타임코드)으로 채운다. 원본에 없는 단계를 내레이션으로 만들어 메우지 않는다(F3).

## T2. 원본 분석 — USE / SUPPORT / DELETE (원본 §16)

| 분류 | 기준 |
|---|---|
| **USE** | 반드시 사용할 핵심 장면 |
| **SUPPORT** | 스토리를 이해하는 데 필요한 보조 장면 |
| **DELETE** | 관광 기록, 반복 장면, 의미 없는 이동 등 스토리에 필요 없는 장면 |

## T3. 장면 선택 핵심 질문 (원본 §17)

> **「이 장면을 빼면 이야기가 약해지는가?」 — NO라면 과감히 삭제한다.**

## T4. 제작 형태 (원본 §9)

- **TYPE A — ONE STORY**: 한 외국인·커플·가족의 이야기가 충분히 강하면 한 팀을 중심으로 전체를 구성한다.
- **TYPE B — THEME STORY**: 한 사람의 이야기만으로 부족하면 같은 일본 경험을 한 여러 외국인의 사례를 결합한다. **단순 반응 모음집이 되지 않도록 하나의 질문 또는 주제가 전체 영상을 관통해야 한다.**

## T5. 제목 기본 공식 (원본 §14)

**WHO + CONDITION + EVENT + CHANGE + MYSTERY**

- 예: 「日本は想像とまったく違った… 初来日の60代夫婦が、わずか1日で気づいたこと」
- **핵심 결과를 제목에서 전부 공개하지 않고 「なぜ？」를 남긴다.**
- 제목에 쓰는 사실(나이·관계·기간·사건)은 원본에서 확인된 것만 쓴다(F3). 원본에 없는 칭찬형 결론으로 몰지 않는다(F5).

## T6. 첫 30초 기본 원칙 (원본 §15)

**HOOK → QUESTION → REWIND → STORY**

1. **HOOK**: 가장 강한 실제 반응을 먼저 보여준다.
2. **QUESTION**: 그 반응으로 질문을 만든다.
3. **REWIND**: 시간을 되돌려 인물을 소개한다.
4. **STORY**: 이야기를 시작한다.

- 영상 시작부터 여행자의 자기소개를 길게 하지 않는다.
- 정확한 편집 템포와 영상 길이는 **방향 확정 이후 별도로 결정**한다(→ [03_PRODUCTION](03_PRODUCTION.md) P3).
