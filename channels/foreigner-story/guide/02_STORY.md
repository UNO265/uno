# 02 STORY — 원본 분석·스토리 구성·제목·첫 30초

> 원본: [GUIDE v1.0](source/japan_foreigner_story_channel_guide_v1.0.pdf) §3·§9·§14·§15·§16·§17 / [v1.2](source/foreigner_story_guide_v1.2.md) §3·§4·§8
> 상위 원칙은 [00_CORE](00_CORE.md)(특히 F3 팩트, F4 FACT/NARRATION 구분). 장면 분류는 [edit-table](../templates/edit-table.md)에 적는다.

## T1. 기본 스토리 공식 (원본 §3)

**EXPECTATION → EXPERIENCE → DISCOVERY → REACTION → CHANGE**
**예상 → 경험 → 발견 → 반응 → 변화**

- 모든 단계가 꼭 있어야 하는 것은 아니다.
- **최소한 「경험 + 실제 반응 + 의미 있는 변화 또는 발견」**이 있어야 우선 제작 후보가 된다.
- 각 단계는 원본의 실제 장면(타임코드)으로 채운다. 원본에 없는 단계를 내레이션으로 만들어 메우지 않는다(F3).

## T2. 원본 분석 — USE / SUPPORT / DELETE (원본 §16)

| 분류 | 기준 |
|---|---|
| **USE** | 반드시 사용할 핵심 장면 |
| **SUPPORT** | 스토리를 이해하는 데 필요한 보조 장면 |
| **DELETE** | 관광 기록, 반복 장면, 의미 없는 이동 등 스토리에 필요 없는 장면 |

## T3. 장면 선택 핵심 질문 (원본 §17)

> **「이 장면을 빼면 이야기가 약해지는가?」 — NO라면 과감히 삭제한다.**

## T4. 제작 형태 (원본 §9)

- **TYPE A — ONE STORY**: 한 외국인·커플·가족의 이야기가 충분히 강하면 한 팀을 중심으로 전체를 구성한다.
- **TYPE B — THEME STORY**: 한 사람의 이야기만으로 부족하면 같은 일본 경험을 한 여러 외국인의 사례를 결합한다. **단순 반응 모음집이 되지 않도록 하나의 질문 또는 주제가 전체 영상을 관통해야 한다.**

## T5. 제목 기본 공식 (v1.0 §14, v1.2 §8)

**WHO + CONDITION + EVENT + CHANGE + MYSTERY**

- 예: 「日本は想像とまったく違った… 初来日の60代夫婦が、わずか1日で気づいたこと」(일본은 상상과 전혀 달랐다… 처음 일본에 온 60대 부부가 단 하루 만에 깨달은 것)
- **핵심 결과를 제목에서 전부 공개하지 않고 「なぜ？」(왜?)를 남긴다.**
- 제목에 쓰는 사실(나이·관계·기간·사건)은 원본에서 확인된 것만 쓴다(F3). 원본에 없는 칭찬형 결론으로 몰지 않는다(F5).
- (v1.2) 제목은 **사람 + 구체적 상황 + 실제 생긴 일/궁금증**. 「世界が驚愕」(전 세계 경악)「1億人衝撃」(1억 명 충격)「涙」(눈물)「10年の夢」(10년의 꿈)은 증거가 없으면 쓰지 않는다. 작은 놀람에 맞는 제목도 충분하다.
  - 예: 원본에 실제 주문 질문과 로봇 도착이 있다면 「初めての日本のファミレス。料理はどうやって届く？」(처음 가 본 일본 패밀리 레스토랑. 음식은 어떻게 도착할까?) 같은 범위에서 출발. 이 제목이면 주문·도착을 중심에 두고 무관한 관광 장면을 길게 끼우지 않는다.
- **제목·도입의 약속은 실제 화면·발언으로 회수한다.** 제목이 「空港に着いた直後」(공항에 도착한 직후)라면 본문 증거도 그 시간·장소여야 한다. 나중 장면을 먼저 보여 주는 도입은 되지만, 그 반응이 다른 때·곳에서 일어난 것처럼 바꾸지 않는다. 감탄하는 장면을 불쾌·공포로 오해하게 만드는 편집도 하지 않는다.

## T6. 첫 30초 기본 원칙 (v1.0 §15 → 시간 배치는 T7)

**HOOK → QUESTION → REWIND → STORY**

1. **HOOK**: 가장 강한 실제 반응을 먼저 보여준다.
2. **QUESTION**: 그 반응으로 질문을 만든다.
3. **REWIND**: 시간을 되돌려 인물을 소개한다.
4. **STORY**: 이야기를 시작한다.

- 영상 시작부터 여행자의 자기소개를 길게 하지 않는다.
- 길이·시간 배치는 v1.2가 정했다 → T7.

## T7. 롱폼 구성 — 큰 질문 하나 안에서 작은 사건을 완결한다 (v1.2 §3)

- 레퍼런스 롱폼(약 19~29분)의 길이를 목표로 복사하지 않는다. **먼저 8~12분 정도의 한 이야기**를 시험한다. 사건이 적으면 더 짧게, 의미 있는 대화가 많으면 더 길게.
- **2026-10-03 사용자 최종 결정: 롱폼 길이 20분 내외**(위 8~12분 시험 대신. 10-02의 15~20분, 10-03의 최대 30분 안은 이것으로 대체). 길이를 채우려고 관광지·감탄 장면을 넣지 않고, 대화·행동·관계가 있는 장면으로 채운다.
- **분량을 채우려고 관광지와 감탄을 넣지 않는다.**

| 구간 | 해야 할 일 | 피할 일 |
|---|---|---|
| 첫 0~8초 | 실제 행동·발언·뜻밖의 반응으로 시작 | 긴 인사, 채널 로고, 추상적인 국가 칭찬 |
| 약 8~25초 | 누구에게 어떤 일이 생겼는지, 지금 볼 이유 | 결과를 전부 설명한 뒤 같은 장면 재생 |
| 약 25~45초 | 이해에 필요한 인물·시간·장소만 되짚기 | 관계없는 여행 이력과 배경 설명 |
| 본문 초반 | 첫 작은 문제나 궁금증을 실제 결과까지 보여 주기 | 제목의 보상을 끝까지 전부 미루기 |
| 본문 중반 | 선택·시도·대화가 달라지는 2~4개 사건 | 「설명 → 짧은 감탄 → 설명」만 반복 |
| 마지막 | 핵심 질문 회수, 가장 구체적인 당사자 반응, 짧은 여운 | 모든 방문지 재설명, 근거 없는 감동 선언 |

- 위 시간은 편집 초안용이다. 첫 장면에 필요한 행동이 길면 자르지 않고, 짧아도 뜻이 완성되면 넘어간다. **첫 30초 안에 상황을 파악할 수 있는지 실제로 확인하는 것**이 초 단위 준수보다 중요하다.

### 장면 한 묶음의 기본 순서

**상황 → 선택/시도 → 상대의 답 또는 실제 결과 → 당사자의 반응 → 다음 행동**

- 예: 메뉴를 모름 → 메뉴를 가리키며 질문 → 직원이 설명 → 본인이 선택 → 음식 도착 → 실제 맛 평가. **원본에 이 과정이 있을 때만** 쓴다. 질문만 있고 답이 없으면 답을 다른 장면에서 만들어 붙이지 않는다.
- 모든 사건에 다섯 단계를 강제로 넣지 않는다. 화면으로 이해되는 상황 설명은 생략한다.
- 편집의 단위는 「5초짜리 컷」이 아니라 **하나의 행동 또는 의미가 끝나는 지점**이다.

### 다음 장으로 넘어가는 이유

「次の場所でも驚きました」(다음 장소에서도 놀랐습니다) 대신 실제 연결을 쓴다(식사 후 결제가 남음, 주문 뒤 받는 방법이 궁금해짐, 이동 때문에 새 선택이 생김). 인과관계가 없으면 「その後、別の日」(그 뒤, 다른 날)처럼 시간 변화를 밝힌다.

## T8. 내레이션은 대화가 할 수 없는 일만 한다 (v1.2 §4)

| 필요한 역할 | 예시/방향 |
|---|---|
| 생략된 상황 연결 | 「注文を終えた二人。次は、料理をどう受け取るのかが気になります。」(주문을 마친 두 사람. 다음은 음식을 어떻게 받는지가 궁금해집니다.) — 궁금해하는 발언이 실제로 있을 때만 |
| 시간·장소 이동 | 「翌日、二人が向かったのは——。」(다음 날, 두 사람이 향한 곳은——.) — 다음 날이라는 근거 확인 |
| 이해에 필요한 사실 | 인물 관계, 주문한 음식명, 다음 행동의 이유 |
| 범위가 명확한 정리 | 「この店の注文方法は、二人にとって初めての体験でした。」(이 가게의 주문 방식은 두 사람에게 처음 겪는 일이었습니다.) — 해당 경험 근거 필요 |

**우선 삭제 검토할 문장**
- 화면에 이미 보이는 동작을 그대로 읽는 문장
- 곧 나올 원본 대사의 의미를 미리 말하는 문장
- 원본 대사가 끝난 직후 같은 뜻을 다시 요약하는 문장
- 「驚きを隠せません」(놀라움을 감추지 못합니다)「日本の素晴らしさに感動」(일본의 훌륭함에 감동)처럼 근거보다 감정을 크게 규정하는 문장
- 이야기를 진행하지 않는 「また新たな発見」(또 새로운 발견)「新しい視点」(새로운 시선)「何気ない日常の特別さ」(평범한 일상의 특별함)의 반복

**편집 진단용 시작점**(정답 비율 아님, 원본 정보 밀도에 따라 다름)
- 본문에서 내레이션 구간이 절반을 넘으면 설명이 과한지 검토한다.
- 연속 설명이 약 15~20초를 넘으면 중복 여부를 점검한다. 맥락상 필요하면 유지.
- 외국인의 원본 발언은 감탄 한마디뿐 아니라 **질문과 답, 망설임과 웃음까지 하나의 의미로** 남긴다.
