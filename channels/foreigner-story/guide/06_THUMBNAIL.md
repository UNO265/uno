# 06 THUMBNAIL — 실제 장면 한 장 + 원본이 말한 것만 담은 두 줄

> 원본: 사용자가 준 [쇼츠 썸네일 지침(シネトリ용)](source/shorts_thumbnail_guide_cinetori.md)(2026-10-03)을 TABINOME 기준으로 고친 것. 상위 원칙은 [00_CORE](00_CORE.md), 제목 약속은 [02_STORY](02_STORY.md) T5.
> 이 문서가 썸네일 규칙의 유일한 위치다. 쇼츠 커버(9:16)와 롱폼 썸네일(16:9)을 함께 다룬다.

## TH1. 원본 지침에서 무엇을 가져왔나

| 원본 항목 | 처리 | 이유 |

## TH2. 장면 고르기

- 원본의 **실제 프레임 한 장**. 표정이 분명하고 얼굴이 크고 흔들리지 않은 장면.
- **썸네일 문구가 가리키는 순간**을 고른다. 「家に泊まる」(집에 묵는다)라면 그 집 안의 장면.
- 원본 VLOG 자막(영어)·원본 채널 로고가 화면에 있으면 다른 프레임을 고르거나 잘라 낸다.
- **얼굴·체형·나이·의상을 바꾸지 않는다. 새 인물·소품·장면을 그려 넣지 않는다.** AI가 얼굴을 다시 그려 달라 보이면 그 이미지는 폐기한다.
- 원본 해상도가 낮으면(CASE #002 원본은 1280×540) 9:16 커버는 3배 이상 확대되어 흐릿해진다. 고해상도 원본을 구할 수 있으면 그것으로 만든다.

## TH3. 쇼츠 커버(1080×1920)

- 얼굴(눈·코·입)은 위에서 15~50% 안. 아래로 갈수록 어둡게.
- 제목 2줄, 가운데 정렬. **블록 전체가 높이 61~88% 안**(1920 기준 위 끝 y≥1172, 아래 끝 y≤1690). 아래 끝을 86%에 맞춘다.
- 1줄 글자 높이 ≈ 10%, 2줄 ≈ 13.5%(2줄이 더 크게), 줄 간격 ≈ 1.5%.
- 좌우 여백 각 5% 이상. 글자가 길면 **위치를 내리지 않고 크기를 줄인다.**

## TH4. 롱폼 썸네일(1280×720)

- 제목 2줄을 **왼쪽 아래**, 왼쪽 정렬. 왼쪽 여백 5% 이상, 글자 폭은 화면의 72% 이하, 아래 끝 84%.
- **오른쪽 아래(가로 80% 이후·세로 85% 이후)는 비운다.** YouTube 재생 시간 표시가 덮는 자리다.
- 얼굴은 위쪽·오른쪽에 오게 자른다. 글자 쪽(왼쪽 아래)을 살짝 어둡게.
- 글자 크기: 1줄 ≈ 높이 11%, 2줄 ≈ 15%.

## TH5. 문구

- **일본어만.** 한국어는 문서에서 확인용으로만 쓴다(00).
- 1줄(흰색) 4~8자, 2줄(노란색, 핵심) 3~7자. 2줄이 더 크다.
- **원본이 실제로 말하거나 보여 준 것만 쓴다.** 원본이 말하지 않은 감정·관계·평가를 문구로 만들지 않는다.
  - 예(CASE #002): 「出会って数時間」(만난 지 몇 시간)은 원본 00:00 발언 "We had only known these people for a few hours, when they invited us to move in" 근거가 있어 쓸 수 있다. 「もう家族」(벌써 가족)는 두 사람이 그렇게 말한 적이 없어 쓰지 않는다.
- 질문형·의외성은 좋지만 **본편에서 답이 나오는 질문만**(02 T5). 원본에 답이 없는 「なぜ」(왜)는 약속하지 않는다.
- 사용자가 문구를 정해 주면 그대로 쓴다(줄 나누기 포함).
- 썸네일 문구와 영상 제목은 같은 말을 반복하지 않고 서로 보완한다.

## TH6. 넣지 않는 것

채널 로고, 화살표, 원, 이모지, 테두리, 워터마크. 추가 문구는 TH8의 실제 발언 인용 1개만 허용. (영상 안의 로고 워터마크와 별개다.)

## TH8. 클릭형 롱폼 썸네일 (2026-10-03 사용자 요청: 「클릭률 높은 것 위주로」)

조회수 상위 해외 반응·외국인 체험 썸네일 24편([조사 기록](source/thumbnail_research_2026-10-03.md))의 공통 구조를 가져온다. 클릭률 자체는 공개되지 않으므로 조회수 상위의 공통점을 따른 것이다. 업로드 후 YouTube 애널리틱스의 노출 클릭률로 다시 판단한다.

- **사진**: 웃음·놀람 같은 **반응 얼굴을 크게**. 사람이 여럿 반응하는 장면도 좋다. 채도·대비는 조금만 올린다.
- **위**: 그 장면에서 **실제로 한 말** 하나를 「」로(흰색, 두꺼운 검정 테두리). 원본 발언의 번역 그대로, 같은 장면(앞뒤 몇 초)의 말만. 지어낸 대사·평가 강화 금지.
- **아래**: 1줄 흰색(누가·상황) + 2줄 노란색 크게(핵심), 두꺼운 검정 테두리. 글자가 얼굴을 가리면 폭을 줄인다.
- 화살표·원·이모지·국기·과장 수치(「世界中が」(전 세계가) 등)는 쓰지 않는다. 글자 덩어리는 최대 3개(인용·1줄·2줄).
- 도구: `tools/thumbnail_ctr.py`(사진 장면·인용·두 줄을 넣으면 위치 검사까지).

## TH7. 만드는 방법과 확인

**기본: `tools/thumbnail.py`.** 실제 프레임을 그대로 쓰고 TH3·TH4의 위치·크기·색을 적용한 뒤, 제목 블록의 위치를 픽셀로 재서 OK/NG를 출력한다.

```
python3 tools/thumbnail.py <원본.mp4> <시각> "<1줄>" "<2줄>" <out.png> --mode shorts|long [--cx 0.5 --cy 0.5 --zoom 1.0]
```

**GPT로 만들 때**(선택): 아래 블록에 원본 영상(또는 고른 프레임)을 함께 올린다. 받은 이미지는 우리 쪽에서 위치를 다시 재고, **인물 얼굴이 원본과 같은지** 원본 프레임과 나란히 놓고 확인한다. 다르면 쓰지 않는다.

```
너는 일본 시청자용 YouTube 채널 「タビノメ」(외국인 여행자의 실제 일본 체험 이야기)의 썸네일 디자이너다.
첨부한 영상(또는 프레임)의 인물은 실제 사람이다. 얼굴·체형·나이·인종·의상·배경을 절대 다시 그리거나 바꾸지 말고,
실제 프레임 위에 보정과 글자만 더해 줘.

[크기] 쇼츠: 1080×1920 PNG / 롱폼: 1280×720 PNG (요청한 것 하나)
[장면] 제목 문구가 가리키는 순간의 인물 클로즈업 1장. 표정이 분명하고 흔들리지 않은 프레임.
  화면에 박힌 영어 자막·채널 로고가 있으면 그 프레임은 쓰지 않는다.
  해도 되는 보정: 선명도, 해상도 키우기, 밝기·대비, 색감, 배경 흐림. 새 인물·소품·장면 추가 금지.
[쇼츠 구도] 얼굴은 위에서 15~50%. 아래로 갈수록 어둡게.
  제목 2줄 가운데 정렬, 블록 전체가 높이 61~88% 안(아래 끝 y≤1690, 86% 권장). 좌우 여백 각 5% 이상.
  글자가 길면 위치를 내리지 말고 크기를 줄인다. 1줄 높이 ≈ 10%, 2줄 ≈ 13.5%, 줄 간격 ≈ 1.5%.
[롱폼 구도] 제목 2줄 왼쪽 아래 왼쪽 정렬, 왼쪽 여백 5% 이상, 아래 끝 84%, 글자 폭 72% 이하.
  오른쪽 아래(가로 80% 이후·세로 85% 이후)는 재생 시간 표시 자리라 비운다. 얼굴은 위쪽·오른쪽.
[글자] Noto Sans JP Black. 1줄 흰색(순백→아주 연한 회색), 2줄 노란색(#FFE600→#FFB400) 그라데이션.
  검은 그림자를 넓고 부드럽게, 얇은 검정 테두리. 일본어 글자는 한 글자도 틀리면 안 된다.
[문구] 내가 준 문구를 그대로(줄 나누기 포함). 한국어·영어 넣지 않는다.
[넣지 않는 것] 로고, 화살표, 원, 이모지, 테두리, 워터마크, 추가 문구.
[확인] 다 만든 뒤: 제목 블록 위치(%), 여백, 일본어 한 글자씩 대조, 얼굴이 원본 인물과 같은지를 확인하고
  아니면 고쳐서 다시 만든 뒤, 사용한 장면 시각과 확인 결과를 알려 줘.

제목 문구: 1줄 「(여기에)」 / 2줄 「(여기에)」
```

**완성 전 확인(공통)**
- [ ] 제목 블록 위치·여백이 TH3/TH4 수치 안이다(도구 출력 OK 또는 픽셀 재측정).
- [ ] 일본어 문구를 한 글자씩 대조했다. 한국어·영어가 없다.
- [ ] 문구의 사실이 원본 발언·화면으로 확인된다(TH5). 본편에서 회수된다.
- [ ] 인물이 원본과 같은 사람이고, 새로 그려 넣은 것이 없다.
