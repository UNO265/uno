# CASE #003 BGM 검색 조건 (04 E6)

> **2026-10-06 사용자 결정: Incompetech(Kevin MacLeod, CC BY 4.0)에서 AI가 직접 찾아 고르고 배치한다.** 설명란 크레딧 필수. 아래 조건은 Incompetech의 장르·분위기(feel) 검색에도 그대로 쓴다.
> 원본 VLOG의 음악은 모든 클립에서 음원 분리로 제거하고 목소리만 쓴다 → 현장음이 줄어든 자리를 BGM이 채운다.

## 공통 조건
- **라이선스: CC BY 4.0**(Incompetech). 쓴 곡은 모두 설명란에 크레딧.
- **보컬 없는 곡**(가사가 있으면 자막·말과 부딪힘).
- **길이 2분 이상**(장면이 1~6분이라 반복을 줄이려고).
- 장면마다 **2~3곡** 후보를 받아 길이·템포·음색을 확인한 뒤 고른다.

## 받은 뒤(AI)
1. 곡마다 길이·분위기·템포를 확인하고 장면에 배치, 목소리 구간은 자동으로 음량을 낮춤(사이드체인).
2. 쓴 곡은 `audio-credits.md`에 곡명·아티스트·라이선스 종류를 기록(「저작자 표시 필요」 곡은 설명란 크레딧 문구까지).
3. 비공개 업로드 후 「검사」에서 저작권 문제 없는지 확인.
