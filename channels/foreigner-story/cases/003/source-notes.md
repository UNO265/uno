# CASE #003 원본 메모 (사용자가 붙여 준 한국어 번역 스크립트 기준)

> 한국어 번역본은 **구조·채택 판단용**이다. 자막은 영상 파일을 받은 뒤 원본 영어 음성에서 만든다(04 E9).
> 번역본이라 뜻이 흐린 곳(예: 바퀴 전체 / 림만 교체)은 원본 영어로 반드시 확인한다 → 「확인」 표시.
> 시각은 각 편 원본 기준.

## Ep23 Shimanami Kaido (22:26) — 고장 없음, 프롤로그 후보

- 하카타 섬 가게의 오렌지 주스·떡

- 제외: 페리 표 사는 법, 전기자전거 대여 추천(관광 정보)
