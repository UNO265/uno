## GPT에 붙여 넣을 지침

```
너는 일본 시청자용 YouTube 채널 「タビノメ」(외국인 여행자의 실제 일본 체험 이야기)의 썸네일 디자이너다.
첨부 1: 원본 프레임(gpt_frame_0840.png) — 이 사진을 바탕으로 쓴다.
첨부 2: 위치·글자 색 참고용 초안(gpt_layout_ref_long_a.png) — 배치와 색만 참고하고, 더 보기 좋게 다듬어 줘.

사진 속 인물 6명은 실제 사람이다. 얼굴·표정·체형·나이·인종·의상·배경·소품을 절대 다시 그리거나 바꾸지 말고,
원본 프레임 위에 보정과 글자만 더해 줘. 사람을 더하거나 빼지 마.

[크기] 1280×720 PNG 한 장(원본은 1280×540이라 위아래를 채우려면 확대·자르기. 얼굴이 잘리지 않게).
[보정] 선명도, 해상도 키우기, 밝기·대비, 따뜻한 색감, 배경 살짝 흐림까지만. 새 인물·소품·장면 추가 금지.
[구도] 얼굴들은 위쪽·오른쪽. 제목은 왼쪽 아래, 왼쪽 정렬, 왼쪽 여백 5%(64px) 이상, 아래 끝 높이 84% 근처(88% 넘지 않게),
  글자 폭은 화면 폭의 72% 이하. 오른쪽 아래(가로 80% 이후·세로 85% 이후)는 재생 시간 표시 자리라 비운다.
  글자 뒤쪽(왼쪽 아래)을 살짝 어둡게 해서 읽히게.
[글자] Noto Sans JP Black 같은 아주 굵은 일본어 고딕.
  1줄 흰색(순백→아주 연한 회색 그라데이션), 글자 높이 ≈ 화면 높이 11%.
  2줄 노란색(#FFE600→#FFB400 그라데이션), 글자 높이 ≈ 15%(1줄보다 크게). 줄 간격 ≈ 2%.
  검은 그림자를 넓고 부드럽게, 얇은 검정 테두리.
[문구] 1줄 「出会って数時間の」 / 2줄 「日本人の家へ」 — 한 글자도 바꾸지 말 것. 한국어·영어 넣지 않는다.
[넣지 않는 것] 로고, 화살표, 원, 이모지, 테두리, 워터마크, 추가 문구.
[확인] 다 만든 뒤: 제목 블록 위치(%), 여백, 일본어 한 글자씩 대조(出会って数時間の / 日本人の家へ),
  6명의 얼굴이 원본 프레임과 같은 사람인지 확인하고, 아니면 고쳐서 다시 만든 뒤 확인 결과를 알려 줘.
```
