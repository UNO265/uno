# CASE #002 업로드 문구 (2026-10-03 초안, 사용자 확인 전)

> 업로드 문구는 **일본어만**. 괄호 안 한국어는 확인용이며 올리지 않는다.
> 근거: 「3泊」(3박) = 원본 13:12 "our bed for the next three nights" / 「ゴールデンウィーク」(골든위크) = 13:40·30:55 / 「出会って数時間」(만난 지 몇 시간) = 00:00 "We had only known these people for a few hours" / 「ヒッチハイク」(히치하이크) = 00:00·01:15.
> 쓰지 않는 것: 두 사람의 국적, 모리 씨 가족 관계의 세부(미확인), 「なぜ招いたのか」(왜 초대했나, 원본에 답 없음), 사용 허락을 받았다는 표현(미확인).

## 제목 후보

썸네일이 「ヒッチハイクで出会った / 日本人の家へ」(히치하이크로 만난 / 일본인의 집으로)이므로, 제목은 같은 말을 반복하지 않고 **기간(3박·골든위크)과 관계 변화**를 더한다(06 TH5).

1. **(추천)** 出会って数時間の日本人家族の家に3泊。ゴールデンウィークを一緒に過ごした外国人カップル
   (만난 지 몇 시간 된 일본인 가족의 집에서 3박. 골든위크를 함께 보낸 외국인 커플)
2. 車を止めてくれた日本人の家で過ごした3日間。外国人カップルが見た、ふだんの日本の家族
   (차를 세워 준 일본인의 집에서 보낸 3일. 외국인 커플이 본 평소의 일본 가족)

