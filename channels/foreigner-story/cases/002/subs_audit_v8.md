# CASE #002 자막 전수 검수 (v8, 2026-10-03)

> 사용자: 「자막에 오류가 있어서는 절대 안 돼. 검수를 잘해야겠다」. 영상에 쓰이는 노란 자막 278개 전부를 검수했다.

## 방법

1. **화면·원문 대조 시트**: 자막마다 그 순간의 원본 화면 + 원본 영어(단어 시각 포함) + 일본어 자막 + 화자 색을 한 칸에 모아 24장으로 만들어 전부 눈으로 확인.
2. **화자 판정**: 목소리 높낮이(pitch)만으로는 여성 목소리를 절반 높이로 잘못 재는 경우가 있어 신뢰할 수 없었다(예: 실케가 화면에서 직접 말하는 장면이 키어런으로 표시). → **목소리 특징 임베딩(Resemblyzer)** 으로 실케·키어런 대표 구간(화면으로 확인한 구간)과 비교해 차이가 뚜렷한 것은 그에 따르고, 일본인 출연자가 영어로 한 말은 화면으로 확인해 지정.
3. **시각**: 어긋난 자막은 원본 단어 시각에 맞춰 다시 배치.

## 고친 것

| 종류 | 수 | 예 |
|---|---|---|
| 화자 색 | 약 60곳 | 도이곶·연못 장면의 실케 셀카 발언(키어런 → 실케), 독수리 이야기(실케 → 키어런), 징 장면·술·「ねるねるねるね」(→ 일본인 출연자) |
| 원본에 없는 문장 삭제 | 1 | 「アリサさんは3日間ずっと料理を作ってくれた」(아리사 씨는 3일 내내 요리를 해 줬다) → 실제 발언은 "Bon appétit!" 뿐 → 「さあ、食べよう！」(자, 먹자!) |
| 오역 | 4 | 「モリさんに教わったの」(모리 씨한테 배웠어) → 「みんなから教わったの」(다들 여러분한테 배웠어, 원문 "from all of you") / 「もちろんイエス」(물론 예스) → 「もちろん『行く』って答えた」(당연히 "갈게"라고 했다) 등 |
| 빠진 발언 추가 | 3 | 「九州しょうゆ味のポテトチップス」(규슈 간장 맛 감자칩, 봉지 글자로 확인) / 「日本の定番っぽいものを食べてみる」(일본의 대표적인 걸 먹어 볼게) / 「うん、別の次元」(응, 다른 차원) |
| 시각 어긋남 | 약 25곳 | 징 장면·이불 장면(2~3초 이르게 나옴), 과자 이름 장면(질문 자막이 다른 말 위에), 고관절 장면 순서 |
| 너무 짧아 읽을 수 없는 자막 | 2쌍 합침 + 길이 보정 | 「モリさんの兄弟」(0.3초) + 「シュウさんが迎えに来てくれた」 → 한 줄 |

## 남은 한계(정직하게)

- 화면 밖에서 말하는 짧은 감탄(「あっ！」(앗!), 「7時半」(7시 반) 등) 몇 개는 목소리 차이가 작아 화자가 확실하지 않다. 색만의 문제이고 내용은 원문과 맞다.
- 「見て、二人のこの笑顔」(봐, 두 사람의 이 웃는 얼굴)는 음성 인식이 "Look at that beautiful baby!"로 들었다. 화면에 아기는 없어 기존 번역을 유지했다.
