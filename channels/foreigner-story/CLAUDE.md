# 외국인 일본 체험 스토리 채널 (가칭)

일본 시청자 대상, 해외 여행자의 실제 일본 체험 VLOG에서 이야기를 발견해 일본어로 전달하는 YouTube 채널. 
**KANENAZO(카네나조)와 다른 채널이다.** 이 폴더 안의 작업에는 레포 루트의 KANENAZO 지침(`docs/guide/`)을 적용하지 않는다. 반대로 이 폴더의 규칙도 KANENAZO에 적용하지 않는다.

## 지침 (v1.0, 2026-10-01: 이 4개가 전부다)

원본은 사용자가 준 [CHANNEL & CONTENT PRODUCTION GUIDE v1.0](guide/source/japan_foreigner_story_channel_guide_v1.0.pdf). 규칙 하나는 한 곳에만 있고, 원본 항목 번호(§1~§24)가 어디로 갔는지는 각 문서 머리에 적었다.

| 문서 | 언제 |
|---|---|
| **[00_CORE](guide/00_CORE.md)** | 항상. 최상위(채널 정의·핵심 원칙·팩트·권리·변경 금지 기준·최종 판단) |
| [01_SOURCE](guide/01_SOURCE.md) | 원본 VLOG 찾기·선정·제외·평가 |
| [02_STORY](guide/02_STORY.md) | 원본 분석(USE/SUPPORT/DELETE)·스토리 구성·제작 형태·제목·첫 30초 |
| [03_PRODUCTION](guide/03_PRODUCTION.md) | 제작 순서·첫 테스트 영상·아직 정하지 않은 것 |

양식: [templates/source-analysis.md](templates/source-analysis.md)(원본 평가 + 장면 분류). CASE 기록은 `cases/` 아래에 영상마다 폴더 하나.

## 꼭 기억할 것 (자세한 내용은 위 문서)

- **우리는 일본을 소개하는 채널이 아니다. 외국인의 눈을 통해 일본을 다시 발견하는 채널이다.** VLOG를 번역하지 않고, 그 안에서 이야기를 발견한다. (00)
- **원본에 없는 이야기를 만들지 않는다.** 외국인이 말하지 않은 감정·생각을 지어내지 않는다. 실제 발언(FACT)과 제작자 해설(NARRATION)을 구분한다. (00)
- **일본 칭찬을 강요하지 않는다.** 불편했던 점·이상했던 점도 소재다. (00)
- **출처 표기만으로 사용권이 생기지 않는다.** "원본 + 일본어 자막"으로 만들지 않는다. 사용 허락·라이선스를 확인한다. (00)
- 원본은 **해외 기반 외국인이 직접 일본을 방문해 스스로 찍은 VLOG + 실제 반응**만 쓴다. 일본 쪽이 기획한 외국인 콘텐츠는 제외한다. (01)
- 스토리 공식: **예상 → 경험 → 발견 → 반응 → 변화**. 최소한 "경험 + 실제 반응 + 의미 있는 변화나 발견"이 있어야 한다. (02)
- 스토리성이 부족하면 **과감히 교체**한다. 첫 영상이라는 이유로 억지로 만들지 않는다. (03)
- 영상 길이·편집 템포·자막 방식·썸네일 담당 등은 **아직 정해지지 않았다**. 정하지 않은 것을 AI가 임의로 정하지 말고 사용자에게 묻는다. (03)
