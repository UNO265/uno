# 업로드 (니마루): 顔に見えるけど全部イカです

> **소재: NOAA Ocean Exploration — 퍼블릭 도메인.** 2026-10-07 제작.
> 원본: https://oceanexplorer.noaa.gov/multimedia/video-playlist-ex2304-glass-squid/ (dive01-glass-squid-1280x720-1.mp4, 68초, Seascape Alaska 3 / 2023, 수심 약 700m, Taonius borealis)
> **설명란에 「映像：NOAA Ocean Exploration」 크레딧 필수.**
> 결정: 제목 B + 내레이션 ③(오징어 속마음·외계인 말투), 내레이션 **30%**(6줄 중 2줄 목소리).

- 업로드 제목: この顔の正体、わかる？🦑 （이 얼굴의 정체, 알겠어?）
- 영상 속 제목(상단 띠): 顔に見えるけど（흰색） / 全部イカです（빨강） （얼굴로 보이지만 / 전부 오징어입니다）
- 썸네일 시점(이미지는 사용자가 직접): **추천 17.9초**(정면 "얼굴" — 두 눈·하얀 뿔·초승달 아가미, 자막 없음) / 대안 6.7초(비스듬히 다가오는 투명한 몸)
- 세로 변환: `crop=405:720:420:0` → 1080x1920 + 노이즈 제거·선명화(`vert.mp4`). 오징어가 세로로 길어 크롭에 잘 맞음. 왼쪽 위 NOAA 로고·처음 영어 정보 문구는 크롭으로, 엔딩 카드(64초~)는 구간 선택으로 제외
- 편집(68초 → 21.5초): 떠 있음 6.5–10.0 → 다가감 14.0–19.5 → 정면 "얼굴" 28.0–37.0 → 몸통 클로즈업 60.0–63.5
- 자막 위치: 정면에서 눈 아래~빨간 소화샘 위가 투명한 부분이라 `sub_y` 0.58. 속마음이라 전부 괄호 + 크림색
- 목소리: 琴詠ニア (14/74), 0.95배 — 정중한 "외계인" 말투. 목소리: 「（……地球のみなさん、こんにちは）」「（……あの、見すぎです）」 / 자막만: 「（深海から、来ました）」「（中身も、ぜんぶお見せします）」「（この赤いのは……おなかです）」「（……目が、合いましたね）」
- 사실: 가운데 빨간 것=소화샘(「おなか」로 쉽게 표현), 하얀 초승달=아가미. NOAA는 눈의 움직임을 "깜빡임으로 여겨진다"고만 해서, 깜빡이는 정확한 순간을 특정할 수 없어 「パチッ」 대신 「目が、合いましたね」로 바꿈
- BGM: "우주와의 교신" 느낌(패드 긴 화음 + 소나 「핑」 + 카림바 높은 아르페지오) → 정면 얼굴에서 일렉 피아노·베이스 → 「見すぎです」 뒤 스틸드럼 「포롱」. 원본 무음
- 음량: 마지막 인코딩에서 +0.8dB·리미터로 -14.3 LUFS
