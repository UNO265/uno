# 업로드 (니마루): この手は反則でしょ

> 모후피타 `kitten/`(立ち上がってだっこをせがむ子猫)와 같은 원본 → 모후피타 미업로드로 보고 **니마루로 옮김**(2026-10-02 규칙). 2026-10-04 제작.
> 결정: 제목 B + 내레이션 ②(아기 고양이 속마음 중심), 내레이션 **30%**(6줄 중 2줄 목소리).

- 업로드 제목: この子に、こんな顔されたら…🐱 （이 아이가, 이런 표정을 하면…）
- 영상 속 제목(상단 띠): この手は（흰색） / 反則でしょ（빨강） （이 손은 / 반칙이잖아）
- 썸네일 시점(이미지는 사용자가 직접): 추천 6.7초(두 앞발을 들고 올려다보는 장면) / 대안 10.5초(입을 벌리고 올려다보는 마지막 얼굴)
- 편집: 모후피타 때와 같음(일어서는 순간 0.6배 슬로, 확대). `fit` 위치도 그대로 — 니마루 띠 아래로 고양이 얼굴이 들어오는 것을 프레임으로 확인
- 목소리: 満別花丸 ぶりっ子 (14/72) — 고양이 속마음 목소리. 목소리 넣은 줄: 「（……だめ？）」「（だっこ！）」 / 자막만: 「ごはん中の子猫が……」「（あ、来た）」「（よいしょっ）」「（ねえねえ、こっち！）」
- 속마음 줄은 괄호 + 크림색(`narration`의 `"color": "cream"`, 이번에 추가)
- BGM: 나일론 기타·셰이커 → 「あ、来た」에 카림바 → 일어설 때 올라가는 슬라이드 휘슬 → 조르기에 카림바·일렉 피아노 → **「だめ？」에서 음을 멈춤(틈)** → 「だっこ！」에 스틸드럼+카림바 「キュン♪」
- 깜놀 자막·`w` 없음(힐링·귀여움). 품종은 확실하지 않아 말하지 않음
- 출력: 호환성 형식(H.264 Main, AAC 44.1kHz), 음량 -1.5dB 보정
