# 니마루 채널 지침서 — 해외 동물 영상 → 일본 타깃 쇼츠

> 새 창(새 세션)에서 이 문서 하나만 읽으면 같은 방식으로 작업할 수 있게 정리한 지침서다.
> `GUIDE_CHANNEL_A.md`를 복사해 **니마루 채널에서 달라지는 부분만** 바꾼 문서다(2026-10-01 사용자 결정: §3 화면 템플릿, §4 목소리·BGM은 모프비타(채널 A)와 겹치지 않게). 나머지 작업 방식은 채널 A와 같다.
> **모든 니마루 CASE의 `script.json`에는 `"channel": "nimaru"`를 넣는다.** 이 값으로 `common/styles.py`의 니마루 템플릿(제목 띠·폰트·크기)이 적용된다. 빠뜨리면 채널 A 모양으로 나온다.
> KANENAZO 지침(`docs/guide/`, 레포 루트 `CLAUDE.md`)은 **이 작업에 적용하지 않는다**(사용자 결정).
> 니마루 기준 작품: `foreign_shorts/nimaru_pup_kitten/` (子犬と子猫の本気のじゃれあい, 첫 니마루 완성본). 편집 판단의 원래 기록은 §9.

## 0. 새 세션 시작할 때

```bash
bash foreign_shorts/common/setup.sh        # ffmpeg·fluidsynth·VOICEVOX·폰트 설치 (몇 분)
# 마지막 줄의 FONT= 경로를 build.py / thumb.py 에 넘긴다(니마루 폰트 Dela Gothic One·Mochiy Pop One도 같이 받는다)
```

- 작업 브랜치: `claude/foreign-video-japan-shorts-8kqpxd` (새 세션에서 지정된 브랜치가 다르면 그 지시를 따른다)
- 원본 영상·완성 MP4·썸네일은 **레포에 넣지 않는다**. 작업 파일은 세션 스크래치패드에 둔다.
- 사용자에게 파일을 보낼 때 30MB 제한이 있다(넘으면 CRF를 올려 다시 인코딩).

## 1. 작업 순서 (영상 1편)

1. **분석**: 길이·해상도·화면비, 자동 자막 트랙(wvtt) 유무, 장면 전환 시각(`select='gt(scene,0.3)'`), 소리 성격(음악인지 현장음인지: RMS·스펙트럼), 프레임 시트로 내용 파악.
   - 저는 소리를 직접 못 들으므로 음성·소리 판단은 "추정"이라고 밝힌다.
2. **판단**: 여러 클립이면 순서 재배치/분할, 자를 구간, 오프닝 훅·해설 그래픽을 쓸지(§5), 목소리(§4).
3. **바로 제작까지 진행**하고 결과를 보고한다(사용자는 렌더링 점검 때 수정 사항을 말해 준다). 위험(학대 논란·저작권 등)이 크면 먼저 알린다.
4. **같이 내는 것**: 영상 + 썸네일 시점(추천/대안, **완성 영상 기준 초**만 — 이미지는 만들지 않음, 2026-10-01 사용자 결정) + 업로드 제목 + 설명란(+한국어 번역) → `CASE/UPLOAD.md`에 기록 → 커밋·푸시.

## 2. 파일 구성

```
foreign_shorts/
  common/setup.sh       환경 설치
  common/narration.py   VOICEVOX 내레이션 → WORK/voice/NN.wav  (겹치면 ⚠ 표시)
  common/build.py       편집·믹스·자막·연출 → OUT.mp4
  common/thumb.py       썸네일(영상과 같은 확대·레이아웃 + 제목 띠)
  CASE/script.json      대본·구간·연출 설정 (아래 §7)
  CASE/music.py         그 영상 전용 BGM 작곡(FluidR3_GM, 필요하면 numpy 효과음)
  CASE/UPLOAD.md        업로드 제목·영상 속 제목·썸네일 시점·설명란(+번역)
```

```bash
S=<스크래치패드>/caseX; F=<원본.mp4>; FONT=<setup.sh가 출력한 경로>
python3 foreign_shorts/common/narration.py foreign_shorts/CASE/script.json $S/voice
python3 foreign_shorts/CASE/music.py $S/music
python3 foreign_shorts/common/build.py foreign_shorts/CASE/script.json "$F" $S $S/CASE_v1.mp4 $FONT
# 니마루는 썸네일 이미지를 만들지 않는다(thumb.py 안 씀). 시점만 초로 보고한다.
```

## 4. 소리·목소리 (니마루 전용 — 모프비타(채널 A)와 겹치지 않게)

### 목소리
- **모프비타가 쓰는 캐릭터는 쓰지 않는다**(四国めたん·ずんだもん·春日部つむぎ·雨晴はう·冥鳴ひまり·九州そら·波音リツ·白上虎太郎·剣崎雌雄·青山龍星·WhiteCUL). KANENAZO의 雀松朱司도 제외. 같은 목소리가 두 채널에 나오면 시청자·알고리즘 모두에게 같은 운영자의 재가공 채널로 보이기 쉽다.
- 아래 니마루 전용 풀 안에서 **영상 분위기마다** 고르고, 같은 목소리를 연속으로 쓰지 않는다.

|---|---|---|
| 귀여움·태클 (주력) | 猫使アル うきうき (13/57), 満別花丸 元気 (14/70), 春歌ナナ (13/54) | `VOICEVOX:猫使アル` / `VOICEVOX:満別花丸` / `VOICEVOX:春歌ナナ` |
| 놀람·허둥지둥 | 中国うさぎ おどろき (3/62) | `VOICEVOX:中国うさぎ` |

- 쓰지 않는 것: No.7(상업 이용은 사전 확인 필요), もち子さん(기업 관여 시 사전 확인 필요). 새 캐릭터를 쓰려면 먼저 `video/.voicevox/TERMS.txt`에서 크레딧 표기와 조건을 확인한다.
- 속도는 1.0~1.15 기본, 장면 안에 안 들어가는 줄만 `speed`로 개별 조정. 이전 줄 끝과 다음 줄 시작이 겹치지 않게(⚠ 표시가 0.1초 이내면 문장 끝 무음이라 괜찮음).
- 크레딧: 설명란 끝에 `ナレーション：VOICEVOX:캐릭터명` (필수, 위 표의 표기 그대로).

### BGM
- **영상마다 `CASE/music.py`로 새로 작곡**한다(파일·멜로디 재사용 없음). **원본 음악은 빼고**(`orig_audio: 0`), 원본 소리가 현장음·동물 소리이고 재미에 도움이 되면 작게 남긴다(`orig_audio` 0.45~0.6, 이때는 `speed`·`freeze_end` 사용 불가).
- **음색도 모프비타와 다르게**: 모프비타는 피치카토(45)·글로켄(9)·피아노(0)·현악(48/49)·바순·클라리넷의 "귀여운 오케스트라" 계열. 니마루는 **경쾌한 팝 밴드** 계열로 간다.
  - 주 악기: 우쿨렐레풍 나일론 기타(24), 일렉 피아노(4), 뮤트 기타(28), 핑거 베이스(33), 칼림바(108), 휘파람·오카리나(78/79), 스틸 드럼(114), 스퀘어 리드(80, 개그 장면 칩튠)
  - 리듬: GM 드럼(채널 10)으로 가벼운 비트(킥·스네어·셰이커/탬버린)
  - 효과음: 긴장→드럼 롤·심벌, 실수→슬라이드 휘슬·"뾰옹", 오치(落ち)→**칼림바/스틸드럼 "짠♪"**(모프비타의 글로켄 짠과 구분)
  - 피치카토·글로켄을 주선율로 쓰지 않는다(감동 영상에서 피아노·현악이 꼭 필요하면 일렉 피아노·패드(89)로 대신).
- 내레이션 중에는 자동으로 볼륨이 내려간다.

## 5. 가공 (재사용 콘텐츠 대응)

재사용 콘텐츠 심사는 사람이 "새로운 가치(해설·편집·연출)를 더했는가"를 본다. **좌우 반전·검출 회피용 변형은 하지 않는다**(효과도 없고 저작권 문제도 그대로). 대신:

1. **이야기 재구성**: 여러 클립이면 첫 1초가 가장 강한 장면, 마지막이 가장 큰 웃음/감동이 되도록 순서 변경. 반복·지루한 구간은 삭제(`segments`).
2. **모음 영상**(여러 사람의 클립): 테마로 묶어 2~3편(각 15~25초)으로 나눈다.
3. **펀치인 줌·슬로모션**: 웃음·반전 순간에 `zooms`(back:true로 다시 빠짐), 결정적 순간 `speed` 0.5~0.65. 피사체가 작으면 전체를 1.3~1.6배 확대.
4. **오프닝 훅**(맞을 때만): 감동·재회처럼 결말을 보여 줘도 궁금해지는 영상에만. 결정적 장면 1~1.5초 + 「このあと…」 → 화이트 플래시 → 본편(대사·BGM은 그만큼 뒤로). **반전이 웃음 포인트인 개그 영상에는 쓰지 않는다.**
5. **해설 그래픽**(필요할 때만): 대상이 작거나 여러 마리라 헷갈릴 때, 또는 "바로 거기 있는데 못 찾음" 같은 포인트를 짚을 때 화살표/동그라미(`marks`).
6. **외국어 문구**: ①확대 트리밍으로 화면 밖으로 → ②안 되면 흐림(`blur`) + 일본어로 교체. 이어 붙인 구간 경계에서 1~2프레임 문구가 보일 수 있으니 줌은 전환보다 0.05초 일찍 바꾸고 프레임 단위로 확인.
7. 위험 신호(영장류를 돌리기 등 학대 논란, 여러 원작자 모음 재업로드)는 제작 전에 알린다. 가장 확실한 방법은 원작자 허락이라는 점도 필요하면 언급.

## 6. 내레이션·제목·설명란 스타일

- **내레이션**: 장면 설명만 하지 말고 태클·감정·해석을 넣는다. 짧은 문장, 「……」로 뜸 들이기. 마지막 줄이 오치(落ち).
- **「w」**: 웃긴 영상에서만, 한 편에 1~2번, 결정적 태클 대사의 **자막(`sub`)에만** 붙인다(`say`에는 넣지 않음). 감동 영상에는 쓰지 않는다.
- **영상 속 제목(상단 띠)·썸네일**: 내용이 드러나는 제목. 2줄, 한 줄 8자 안팎(글자가 커서 길면 작아진다). 핵심(웃음·놀라움)을 빨간 2줄에. 예) 子犬と子猫の / 本気のじゃれあい
- **업로드 제목**: **궁금증을 만드는 부제목 + 이모지 1개만**. 예) `最後、子猫はどこへ消えた？🐱` (영상 속 제목을 붙이지 않음, #Shorts도 붙이지 않음)
- **썸네일**: **이미지는 만들지 않고 시점(초)만** 알려 준다. 추천 1개 + 대안 1개, 완성 영상 기준 초(예: 11.0초). 결말(오치)은 숨기는 장면을 추천. 시점을 고를 때 완성 영상에서 그 프레임을 뽑아 직접 확인한다.
- **설명란** 형식:

```
<내용 요약 1~2줄, 결말은 「……」로 숨김><이모지>

<시청자에게 묻는 한 줄>（웃긴 영상이면 끝에 w 가능）
コメントで教えてください🐾

#해시태그 5개

――――――――――
ナレーション：VOICEVOX:<캐릭터명>
```
- 「元動画」 줄은 넣지 않는다.

## 7. script.json 항목

| 키 | 뜻 |
|---|---|
| `channel` | **`"nimaru"` 필수**(§3 템플릿) |
| `title` | 상단 띠 2줄 `[{text,color:white}, {text,color:red}]` |
| `layout`, `fit_h`, `fit_y` | `fit`이면 원래 비율로 배치. `fit_h`=영상 높이(화면비), `fit_y`=위쪽 위치 |
| `voice` | `{name, vvm, style, speed, credit}` |
| `source.segments` | 쓸 구간을 **이어 붙일 순서대로**. `[from,to]` 또는 `{from,to,speed,freeze_end}` |
| `source.orig_audio` | 원본 소리 배율(0이면 끔) |
| `source.blur` | `{x,y,w,h,t0,t1,src_w,src_h}` 원본 좌표 기준 흐림 |
| `zooms` | `{t0,t1,from,to,cx,cy,from_cx,from_cy,ramp,back}` 편집 후 시간·화면비 좌표 |
| `marks` | `{type: arrow/circle/flash, t0, t1, path:[[t,x,y],…], label, r}` |
| `narration` | `{start, say(읽을 문장), sub(자막, \n 줄바꿈), hl(노란 강조어), speed, ko(한국어)}` |
| `captions` | 내레이션 없는 자막(오프닝 훅 「このあと…」 등) `{start,end,text,color,size}` |
| `upload` | `{title, title_ko, hashtags}` |

1. 영상 파일 전송(썸네일 이미지는 보내지 않음)

5. 업로드 제목(+한국어 뜻)
6. 설명란(일본어 코드 블록) + **한국어 번역 코드 블록**

## 9. 작업 방식 기준 작품(채널 A): `pup_kitten/` (子犬と子猫の本気のじゃれあい)

> 화면 모양은 §3 니마루 템플릿을 따른다. 아래는 편집·연출·소리 판단의 참고용.

- 원본 27.9초 원테이크(위에서 촬영, 두 마리가 작음) → 반복되는 뒹굴기 4초 삭제 → 23.9초
- 전체 1.55배 확대, 고양이가 위가 되는 순간 펀치인 줌, 마지막은 천천히 다가가는 줌
- 목소리 WhiteCUL たのしい, 원본 소리는 거의 무음이라 끔
- BGM: 노려볼 때 트레몰로 → 「試合開始」에 공 소리(numpy 합성) → 경쾌한 피아노 → 도망 후 엉뚱한 클라리넷 → 「見失ってるw」에 "짠♪"
- 오치: 고양이가 바로 옆 상자 위에 있는데 강아지가 못 찾음 → 동그라미 `marks` + 자막 「……どこ行ったの？（すぐそこ）」
- 오프닝 훅 없음(오치가 웃음 포인트), `w` 1번
- 업로드 제목 `最後、子猫はどこへ消えた？🐱`, 썸네일 추천 11.0초(뒹구는 장면)

### 니마루에서 확인된 점 (`nimaru_pup_kitten`)
