# 업로드 (니마루): 失った前足、新しい一歩

> 새 원본(모후피타 폴더와 겹치지 않음). 2026-10-03 제작. v1(밝은 반말·琴詠ニア)은 폐기 → v2: 사용자와 다각도 분석 후 **감동 다큐 · 코끼리 1인칭 독백**으로 방향 변경.
> 결정: 제목 C + 내레이션 ③(코끼리 독백), 내레이션 **60%**(8줄 중 5줄 목소리), 첫걸음 0.7배 슬로 + 첫걸음 직전 BGM 무음 한 박자.

- 업로드 제목: この足で、もう一度…🐘 （이 발로, 다시 한번…）
- 영상 속 제목(상단 띠): 失った前足（흰색） / 新しい一歩（빨강） （잃어버린 앞발 / 새로운 한 걸음）
- 썸네일 시점(이미지는 사용자가 직접): 추천 6.5초(「これが、ボクの新しい足」 의족을 들어 올린 장면, 걷는 결말은 숨김) / 대안 17.5초(「また歩ける」 의족으로 걷는 장면)
- 편집: 훅(걷는 모습 1.2초) → 가루 → 양말 → 의족 → 벨트 → **첫걸음 16.0–18.5를 0.7배** → 걷기 → 다른 날 걷기. 24.7초. 원본 소리(배경음악 추정)는 끔
- 목소리: 猫使ビィ おちつき (13/59), 1.0배 — 코끼리의 1인칭(ボク)
- 목소리 넣은 줄(5/8): 「ボクは、前足を一本なくした。」「これが、ボクの新しい足。」「みんなの手が、あったかい。」「歩ける。ボク、また歩ける。」「この足で、明日も。」 / 자막만(3/8): 「みんなが、ていねいに準備してくれる。」「ちょっと重たい。でも……」「……一歩。」
- BGM: 조용한 나일론 기타 아르페지오(F#m-D-A-E) → **12.6–13.6초 무음 한 박자** → 「……一歩。」에 카림바 한 음 → 패드가 퍼짐 → 「また歩ける」에서 가장 크게 → A 화음으로 끝
- 출력: 호환성 형식(H.264 Main, AAC 44.1kHz, mp42)으로 다시 인코딩해 파일로 전달
- 사실 주의: 다리를 잃은 이유·코끼리 이름·장소는 말하지 않음
