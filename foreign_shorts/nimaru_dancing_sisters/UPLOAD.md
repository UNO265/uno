# 업로드 (니마루): わたしの妹はワンちゃんです

> 새 원본(원제 「Dancing sisters」, 60초 정사각형). 2026-10-06 제작. 모후피타 폴더와 겹치지 않음.
> 결정: 제목 B + 내레이션 ②(여자아이 1인칭, 언니 시점), 내레이션 **60%**(7줄 중 4줄 목소리), 약 20초.

- 업로드 제목: この姉妹、ちょっと普通じゃない…🐶 （이 자매, 좀 평범하지 않아…）
- 영상 속 제목(상단 띠): わたしの妹は（흰색） / ワンちゃんです（빨강） （내 여동생은 / 강아지예요）
- 썸네일 시점(이미지는 사용자가 직접): 추천 15.3초(개가 뒷발로 서서 아이에게 안긴 장면 = "여동생") / 대안 7.7초(개가 아이를 뛰어넘는 순간)
- 편집(60초 → 19.4초): 하이파이브(50.4–53.0) → 같이 구르기(4.8–7.3) → 물구나무 위로 점프(7.3–8.6, 7.7–8.6은 0.5배) → 한 번 더 점프(22.0–23.2) → 서서 춤(43.3–46.2) → 데굴(46.4–49.6) → 안기기(53.0–54.4) → 나란히 결정 포즈(56.4–59.8)
- 화면: `fit_h` 0.52 / `fit_y` 0.232 — 니마루 띠 바로 아래, 아이·개가 자막보다 위에 오도록 작게
- 원본 소리: 전체가 같은 음량의 댄스곡으로 추정 → 저작권 위험으로 끔, BGM 새로 작곡
- 목소리: 春歌ナナ (13/54), 1.05배 — 여자아이(언니). 목소리 넣은 줄: 「わたしの妹を、紹介します。」「妹は、飛ぶ。」「……ちょっと、毛が多いけど。」「自慢の妹です。」 / 자막만: 「わたしが転がると、妹も転がる。」「わたしが逆立ちすると……」「ダンスも、いっしょ。」
- BGM: 댄스 팝 120BPM(4박 킥·클랩·핑거 베이스·카림바) → 점프 전 드럼을 빼고 올라가는 스윕 → 착지에 크래시 → 「毛が多いけど」 직전 한 박자 멈춤 → 스틸드럼 「ジャン♪」으로 끝
