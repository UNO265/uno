# 업로드 (니마루): 足にしがみつく子猫が離れない

> 모후피타 `kitten_leg/`(足にしがみついて離れない子猫)와 같은 원본. 모후피타에는 올리지 않고 **니마루로 옮김**(2026-10-02 사용자 확인). 화면·목소리·BGM·말투는 니마루 기준으로 새로 제작.

- 업로드 제목: このまま歩いたら、どうなる？🐾 （이대로 걸으면, 어떻게 될까?）
- 영상 속 제목(상단 띠): 足にしがみつく（흰색） / 子猫が離れない（빨강） （발에 매달리는 / 아기 고양이가 안 떨어져）
- 썸네일 시점(이미지는 사용자가 직접): 추천 3.4초(앞발로 다리를 꼭 잡은 장면, 끌려가는 결말은 숨김) / 대안 10.0초(발에 붙은 채 끌려가는 장면)
- 화면: `layout: fit`(4:5), 위치는 모후피타 때와 같음(고양이가 아래쪽이라 니마루 띠는 다리·가구만 덮음)
- 목소리: 春歌ナナ (13/54), 1.1배(마지막 줄 1.25배) — 웃긴 영상이라 반말 태클
- BGM: 팝 밴드(뮤트 기타·핑거 베이스·가벼운 드럼·카림바) → 끌려갈 때 드럼을 빼고 베이스가 반음씩 「ずるずる」 내려가며 내려가는 슬라이드 휘슬 → 오치에 스틸드럼+카림바 「짠♪」. 원본 소리는 끔
- 오프닝 훅: 안 씀(끌려가는 장면 자체가 웃음 포인트) / 해설 그래픽: 첫머리 「この子」 화살표 / 속마음 자막 1번 「（離さないもん）」 3.6–4.5초 / `w` 1번(마지막) / 깜놀 자막 없음(놀라는 장면이 아님)
