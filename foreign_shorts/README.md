# 해외 영상 → 일본 타깃 쇼츠

KANENAZO 지침(`docs/guide/`)과 별개인 작업. 원본 영상·완성 MP4는 레포에 넣지 않는다(사용권 확인 전).

## 원칙 (사용자 결정)

- **목소리는 영상 분위기에 맞춰 매번 고른다.** 감동 → 冥鳴ひまり, 귀여움·태클 → ずんだもん 등. `script.json`의 `voice`에 기록하고 설명란에 `VOICEVOX:캐릭터명` 크레딧을 넣는다.
- 레이아웃은 도베르만 v3 확정안: 전체 화면 + 상단 제목 띠(12.5%) + 쇼츠 UI를 피한 자막(x 60–940, 하단 75% 위).
- 원본 영상의 음악은 저작권 위험이 있으면 빼고(`orig_audio: 0`) BGM은 CASE마다 직접 작곡.
- 장면 순서는 `source.segments`에 적은 순서대로 이어 붙인다(재배치·일부만 사용 가능).
- 설명란에 「元動画」 줄은 넣지 않는다(크레딧은 VOICEVOX 한 줄만).
- 원본에 박힌 외국어 문구는 흐림 처리하고 맞는 일본어로 바꿔 넣는다(`source.blur` + `captions`의 `style: overlay`).

## 가공 원칙 (2026-09-30 사용자 요청: "최대한 가공")

재사용 콘텐츠 심사는 **새로운 가치(해설·편집·연출)를 더했는지**를 사람이 보고 판단한다. 그래서 영상을 받으면 아래를 기본으로 모두 적용한다.

1. **이야기 재구성**: 여러 장면이 이어진 영상이면 첫 1초 후킹과 결말에 맞춰 순서를 바꾸고, 필요 없는 부분은 자른다(`source.segments`).
2. **연출 편집**: 웃음·반전 포인트에 펀치인 줌(`zooms`), 결정적 순간에 슬로모션(`speed`)·정지(`freeze_end`)를 넣는다.
3. **내레이션**: 장면을 설명만 하지 않고 태클·감정·해석을 더한다. 목소리는 분위기에 맞춰 매번 고른다.
4. **소리**: 원본 음악은 빼고 BGM은 CASE마다 직접 작곡, 필요한 곳에 효과음.
5. **자막·제목·썸네일**: 일본어로 새로 만든다. 외국어 문구는 **확대 트리밍으로 화면 밖으로 밀어내는 것을 먼저** 쓰고(흰 상자 문구는 흐리면 자국이 남음), 안 되면 흐림 처리 후 일본어로 교체한다. 문구가 이미 흐린 배경 띠 위에 있으면 흐림이 자국 없이 섞이므로 흐림이 낫다(확대하면 피사체가 잘릴 때).
6. **제목·자막 위치는 항상 고정**(사용자 결정): 제목은 위 12.5%, 자막은 아래 70%. 장면마다 옮기지 않는다. 수정이 필요하면 사용자가 렌더링 점검 때 알려 준다(`y`·`x`·`w`, `title_pos`는 그때만 사용).
9. **제목 스타일**(사용자 결정): 영상 속 제목(상단 띠)과 썸네일은 내용이 드러나는 제목(예: 小さな命を守る動物たち). **업로드 제목은 「부제목(궁금증 질문)｜영상 속 제목」 + 이모지 1개 + #Shorts** (예: この犬、何をくわえてる？｜小さな命を守る動物たち🐶 #Shorts). 모바일에서 앞 20~30자만 보이므로 질문을 앞에 둔다.
8. **끝의 정지 화면은 쓰지 않는다**(사용자 결정): 마지막 대사가 길면 마지막 구간을 살짝 느리게(`speed` 0.7~0.8) 해서 끝까지 움직이게 한다.
7. **모음 영상은 테마별로 나눈다**: 여러 사람의 클립을 모은 영상은 테마로 묶어 2~3편(각 15~25초)으로 나누고, 가장 강한 클립을 각 편의 마지막에 둔다.

좌우 반전이나 연출 목적이 없는 확대처럼 **검출만 피하려는 변형은 넣지 않는다.** 재사용 콘텐츠 심사에서 도움이 되지 않고, 저작권 문제도 해결하지 못한다.

## 주의

- 구간을 이어 붙이면 프레임 반올림으로 실제 전환이 계획보다 1~2프레임 빨라질 수 있다. 문구를 잘라내는 줌은 **전환 시각보다 0.05초 일찍** 바꾸고, 렌더 뒤 `edit.mp4`의 장면 전환 시각과 줌 경계를 비교한다.

## 만드는 법 (공통)

```bash
python3 common/narration.py CASE/script.json WORK/voice
python3 CASE/music.py WORK/music
python3 common/build.py CASE/script.json SRC.mp4 WORK OUT.mp4 ZenMaruGothic-Black.ttf
```

| CASE | 내용 | 목소리 |
|---|---|---|
| `doberman/` | 도베르만과 남자아이 (감동), 확정 v3 — 이 폴더는 자체 build.py 사용 | 冥鳴ひまり |
| `tortoise/` | 새끼 육지거북의 1일 (힐링·태클) | ずんだもん |
| `puppy/` | もふもふ子犬、ぜんぶ許せる (코믹, 장면 순서 재배치) | 春日部つむぎ |
| `kindness1/` | 優しい動物 ① 自分のごはんを分けてあげる (모음 영상 3분할, 확정: `script_title_fixed.json`) | 四国めたん |
| `kindness2/` | 優しい動物 ② 困っている友だちを放っておけない (기린 장면 슬로모션) | 青山龍星 |
| `kindness3/` | 優しい動物 ③ 小さな命を守る (개 장면 슬로모션, 새를 따라가는 줌) | 冥鳴ひまり |
