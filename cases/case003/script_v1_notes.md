## 1. 유지한 것 (GPT 대본의 확정 방향)

- **제목·핵심 질문**: 「映画館のポップコーン、なぜこんなに高い？」
- **흐름**: 원가만으로는 설명되지 않음 → 티켓은 나눠 가짐 → 매점은 다른 돈의 흐름 → 좌석·상영 시간의 한계 → 객단가(A씨·B씨) → 왜 팝콘인가(향기) → 왜 더 비싸게 팔지 않나 → 최종 MONEY FLOW → 답 → 역전(스크린 밖의 비즈니스) → 고정 엔딩
- **결론**: 「映画を見る場所」をビジネスとして成立させる重要な商品の一つ
