# GPT 썸네일 요청문 — 帰宅したら他人がいた

첨부: `heal_thumb_photo_for_gpt.png`(1080×1920, 2:17 장면, 글자·로고 없음) + 참고 사진 ①もう家族だと思ってた ②看守は気づけるか？(있으면)

```
너는 일본 시청자용 영화 쇼츠 채널 「シネトリ」의 썸네일 디자이너다.
첨부한 장면 사진(노교수가 혼자 아프리카 북 젬베를 치는 장면)에 제목을 얹어 세로 썸네일 1장을 만들어 줘.

[1] 크기: 1080×1920(9:16) PNG 한 장.

[2] 사진
- 첨부 사진을 그대로 쓴다. 인물의 얼굴·체형·나이·의상·안경, 북의 모양은 바꾸지 않는다. 새로 그리거나 다른 사람으로 만들지 않는다.
- 해도 되는 것: 선명도, 밝기·대비, 따뜻한 영화 같은 색감, 아래쪽을 살짝 어둡게.
- 화면 위쪽에 흐림·안개·그라데이션 띠를 넣지 않는다. 위쪽은 사진 그대로 둔다.
- 영상에 없는 소품·사람·글자·로고를 넣지 않는다.

[3] 제목 문구(이대로, 줄 나누기도 그대로)
- 1줄(흰색): 無気力な教授が
- 2줄(노란색): 始めたこと

[4] 제목 위치
- 제목 블록 전체가 화면 높이 61%~88% 사이(1920 기준 y 1180~1690). 아래 끝이 88%를 넘으면 안 된다(쇼츠 아래 UI에 가림).
- 좌우 여백 각 5% 이상(약 54px). 길면 위치를 내리지 말고 글자 크기를 줄인다.
- 2줄을 1줄보다 크게(1줄 글자 높이 ≈ 화면 높이의 9%, 2줄 ≈ 12.5%), 줄 간격 ≈ 1.5%.
- 가능하면 북을 치는 두 손이 글자에 완전히 가려지지 않게 한다.

[5] 글자 스타일
- 아주 굵은 일본어 고딕체(Noto Sans JP Black 등), 가로를 약간 좁힌 장체.
- 1줄: 순백 → 아래로 아주 연한 회색 그라데이션. 2줄: 밝은 노랑(#FFE600) → 진한 노랑(#FFC400) 그라데이션.
- 넓고 부드러운 검은 그림자 + 얇은 검은 테두리.
- 일본어 글자를 한 글자씩 정확하게(無気力な教授が / 始めたこと).

[6] 넣지 않는 것: 채널 로고, 화살표, 원, 이모지, 테두리, 추가 문구.

[7] 다 만든 뒤 확인하고 아니면 고쳐서 다시 만들어 줘
- 제목 위 끝 ≥ 61%, 아래 끝 ≤ 88%인가? 좌우 5% 여백이 있는가?
- 일본어 글자가 정확한가?
- 위쪽에 흐린 띠가 없고, 인물이 첨부 사진과 같은 사람인가?
```
