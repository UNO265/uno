# 커버(첫 화면) 제목 위치 기준

2026-10-02 사용자 지시로 추가. `00_GUIDE.md`(PDF 이식본)에는 없는 규칙이다.

## 왜

「看守は気づけるか？」 커버는 제목이 아래로 내려가 있었다. 그래서 실제 쇼츠 화면에서는 아래쪽 제목·채널명 UI에 가려 잘려 보였다. 「もう家族だと思ってた」 커버의 위치는 문제가 없어서, 이 위치를 기준으로 삼는다.

## 기준 (「もう家族だと思ってた」에서 잰 값)

| 항목 | 비율 | 1080×1920 기준 |
|---|---|---|
| 제목 블록 위 끝 | 높이의 61% | y ≈ 1180 |
| 제목 블록 아래 끝 | 높이의 **88% 이하** | y ≤ 1690 |
| 좌우 | 각 4.5% 이상 여백 | x 50–1030 |
| 줄 구성 | 2줄. 1줄 흰색, 2줄 노란색(핵심) | |
| 글꼴 | 굵은 고딕, 검은 그림자로 밝고 어두운 장면 모두 읽히게 | |

- 아래 끝 88%가 가장 중요하다. 이보다 내려가면 쇼츠 UI에 가린다.
- 글자가 길면 아래로 내리지 말고 글자 크기를 줄인다.
- 납품 전에 제목 블록의 위·아래·좌우 끝을 픽셀로 재서 위 범위 안인지 확인한다.

## 이미 만든 커버가 내려가 있을 때

글자가 이미지에 합쳐져 있으면 이미지 전체를 위로 올리고, 아래 빈 줄은 맨 아래 줄을 뒤집어 채운다. 대신 위쪽이 그만큼 잘리므로 인물 머리 등이 잘리지 않는지 확인한다. 「看守は気づけるか？」는 70px(높이 1672 기준) 올려서 맞췄다(`outputs/cover_看守は気づけるか_fixed.png`).
