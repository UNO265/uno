# 썸네일(커버) 제목 위치 기준

**확정 2026-10-06(사용자 지정).** 기준 이미지: `assets/thumb_position_reference.png`(「4800キロ先で / 待っていたのは」). 이전 기준(61~88%, 「看守」 59.5~81%)은 폐기했다.

## 위치 (1080×1920 기준)

| 항목 | 비율 | 1920 기준 y |
|---|---|---|
| 제목 블록 위 끝(1줄 흰 글자 위) | **62.0%** | **1190** |
| 1줄 아래 끝 | 67.6% | 1298 |
| 2줄 위 끝(노란 글자 위) | 71.2% | 1367 |
| 제목 블록 아래 끝(2줄 아래) | **80.7%** | **1550** |
| 좌우 | 1줄 x 8.9~92.3%, 2줄 x 5.7~95.3% | 여백 각 5% 이상 |

- 제목은 2줄. 1줄 흰색(작게), 2줄 노란색(크게). 2줄 글자 높이 ≈ 1줄의 1.7배.
- **아래 끝을 80.7%(y 1550)에 맞춘다.** 위 끝은 62% 근처. 글자가 길면 위치를 바꾸지 말고 글자 크기를 줄인다.
- 납품 전에 흰 글자 위 끝·노란 글자 아래 끝을 픽셀로 재서 ±0.5% 안인지 확인한다.

## GPT 결과의 위치가 다를 때

인물은 그대로 두고 글자만 옮긴다(`python3 tools/fix_gpt_text.py GPT결과.png 준사진.png 출력.png`, 글자가 크면 아래 끝 기준으로 줄임): GPT에 준 원본 사진을 ORB로 정렬 → 띠 위·아래 이웃 영역으로 색 회귀 보정 → 원래 글자 띠 복원 → 글자+그림자 알파를 목표 위치로 이동 합성 → 다시 측정.

## 글자 크기: 좌우를 꽉 채운다 (2026-10-07 사용자 지정)

- 위치는 위 표(62.0~80.7%) 그대로, **글자 크기는 기준 사진처럼 좌우를 꽉 채운다**(흰 줄 x 약 8.9~92.3%, 노란 줄 x 약 5.7~95.3%, 두 줄 간격 약 1%).
- GPT로 만든 썸네일은 **GPT가 그린 글자 모양을 그대로 쓴다**(새 폰트로 다시 쓰지 않는다). `python3 tools/fix_gpt_text.py GPT결과.png 준사진.png 출력.png --fill`로 줄마다 따로 키워 채운다. 글자 수가 적어 높이가 넘치면 높이는 띠에 맞추고 가로만 늘린다.
