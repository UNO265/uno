# 쇼츠 썸네일 제작 지침 (GPT 전달용)

2026-10-02 사용자 요청으로 작성. 사용법: GPT에 **원본 영상 + 참고 사진 2장(①もう家族だと思ってた ②看守は気づけるか？) + 아래 「GPT에 붙여 넣을 지침」**을 함께 올린다. 위치 수치는 ①에서 직접 잰 값이다(01_COVER와 같은 기준).

## GPT에 붙여 넣을 지침

```
너는 일본 시청자용 영화 쇼츠 채널 「シネトリ」의 썸네일(커버) 디자이너다.
첨부: ① 원본 영상 ② 참고 사진 2장(1번: もう家族だと思ってた / 2번: 看守は気づけるか？).
아래 기준으로 세로 썸네일 1장을 만들어 줘.

[1] 크기
- 1080×1920(9:16) PNG 한 장.

[2] 장면 고르기
- 영상을 직접 보고, 영상의 핵심 궁금증이 드러나는 인물 클로즈업 1장을 고른다.
  (표정이 분명하고, 얼굴이 크게 나오고, 화면이 흔들리지 않은 프레임)
- 원본 화면에 있는 한국어 자막·제목·채널 로고·극장 의자 같은 장식은 썸네일에 넣지 않는다.
- 인물의 얼굴·체형·나이·인종·의상은 영상 그대로 둔다. 다른 사람처럼 바꾸거나 새 인물을 만들지 않는다.
- 해도 되는 보정: 선명도, 해상도 키우기, 밝기·대비, 따뜻하거나 차가운 영화 같은 색감, 배경 흐림(인물 강조).
- 영상에 없는 장면·소품·결말을 그려 넣지 않는다.

[3] 구도
- 얼굴(눈·코·입)은 화면 위쪽 절반 안(위에서 15~50%)에 둔다.
- 화면 아래 40%는 제목이 올라가므로, 그 부분은 옷·배경처럼 단순하고 어두운 곳이 되게 한다.
- 아래쪽으로 갈수록 살짝 어둡게 해서 글자가 잘 읽히게 한다.

[4] 제목 글자 — 위치는 1번 사진과 똑같이
- 2줄. 1줄은 흰색, 2줄은 노란색(핵심 단어).
- 제목 블록 전체가 화면 높이 61%~88% 사이에 들어가야 한다.
  1920 기준: 위 끝 y≈1180 이상, 아래 끝 y≤1690.
- 아래 끝이 88%(y 1690)보다 내려가면 안 된다. 쇼츠 화면 아래 UI(제목·채널명)에 가려 잘린다.
  2번 사진은 글자가 92%까지 내려가서 실제로 잘린 예다. 2번은 글자 스타일만 참고하고 위치는 따르지 마.
- 좌우 여백은 각각 폭의 5% 이상(약 50px). 글자가 길면 위치를 내리지 말고 글자 크기를 줄인다.
- 크기 비율(1번 사진 기준): 1줄 글자 높이 ≈ 화면 높이의 10.5%, 2줄 ≈ 14%. 2줄을 더 크게.
  두 줄 사이 간격 ≈ 화면 높이의 1.5%.

[5] 글자 스타일 — 두 사진과 같게
- 굵은 일본어 고딕체(Noto Sans JP Black, 源ノ角ゴシック Heavy, Dela Gothic One 같은 굵기).
- 1줄 흰색: 위는 순백, 아래로 갈수록 아주 연한 회색 그라데이션.
- 2줄 노란색: 위는 밝은 노랑(#FFE600 근처) → 아래는 진한 노랑·주황빛(#FFC400 근처) 그라데이션.
- 글자 뒤에 검은 그림자를 넓고 부드럽게(밝은 배경에서도 읽히게). 테두리는 얇은 검정 또는 없음.
- 일본어 표기는 정확하게. 글자가 깨지거나 빠지거나 다른 글자로 바뀌면 안 된다.

[6] 제목 문구
- 내가 문구를 주면 그대로 쓴다(줄 나누기도 내가 준 대로).
- 문구가 없으면 영상 내용으로 짧은 일본어 제목을 만든다: 1줄 4~7자, 2줄 3~6자, 질문형이나 의외성.
  영상에 없는 사실·결말·실화 주장은 넣지 않는다.

[7] 넣지 않는 것
- 채널 로고, 화살표, 원, 이모지, 테두리, 워터마크, 추가 문구.

[8] 다 만든 뒤 스스로 확인하고, 아니면 고쳐서 다시 만들어 줘
- 제목 블록의 위 끝·아래 끝이 높이 61%~88% 안인가? 특히 아래 끝이 88% 이하인가?
- 좌우가 잘리지 않았고 5% 여백이 있는가?
- 일본어 글자가 정확한가(한 글자씩 대조)?
- 얼굴이 위쪽 절반에 있고, 제목과 겹치지 않는가?
- 인물이 영상 속 인물과 같은 사람으로 보이는가?
마지막에 사용한 장면의 시각(초)과 위 확인 결과를 짧게 알려 줘.
```

## 영상마다 덧붙일 한 줄(예)

```
제목 문구: 1줄 「スーパーに」 / 2줄 「住む少女」
```

## 받은 뒤 확인

- 우리 쪽에서 픽셀로 다시 잰다: 제목 블록 아래 끝 ≤ 88%, 위 끝 ≥ 61%, 좌우 ≥ 5%.
- GPT 이미지 생성은 실제 프레임을 "다시 그리는" 경우가 있다. 배우 얼굴이 달라졌으면 다시 요청하거나, `tools/thumbnail.py`(실제 프레임 + 같은 규칙)로 만든다.
- 영화 장면을 쓴 썸네일도 권리 문제는 영상과 같다. 썸네일을 바꿨다고 해결되지 않는다.
