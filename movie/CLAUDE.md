# 영화 숏츠 채널 (일본 타깃)

카네나조와 **별개의 채널**이다. 이 폴더(`movie/`)에서는 루트 `CLAUDE.md`와 `docs/guide/`(카네나조 00~06 지침)를 적용하지 않는다. VOICEVOX·4,000자·ANSWER CARD·실사 금지·단계별 확정 같은 카네나조 규칙을 여기로 가져오지 않는다. 반대로 이 채널 규칙도 카네나조에 적용하지 않는다.

## 지침

**[guide/00_GUIDE.md](guide/00_GUIDE.md)**(제작 기준 v1.1, 2026-10-02), [guide/01_COVER.md](guide/01_COVER.md)(커버 제목 위치, 사용자 추가 규칙), [guide/02_THUMBNAIL_GPT.md](guide/02_THUMBNAIL_GPT.md)(GPT에 썸네일을 맡길 때 붙여 넣을 지침). 원본은 `guide/japanese_shorts_claude_guide_v1.1.pdf`이고, 내용이 다르면 PDF가 기준이다. 사용자의 새 요청이 지침보다 우선한다.

## 꼭 기억할 것 (자세한 내용은 지침)

- **결과물**: 원본 영상 → 일본어 제목·해설 음성·자막 + 영화 원음 + BGM이 들어간 1080×1920 세로 MP4. 중간 선택을 묻지 않고 완성본까지 간다(카네나조처럼 단계마다 확정받지 않는다).
- **핵심**: 한국어 해설만 일본어 음성(기준 `ja-JP-KeitaNeural`)으로 읽는다. 배우 대사는 원음 그대로 두고 노란 자막(`#FFDC49`)만 단다. 해설 자막은 흰색, Noto Sans CJK JP Bold, 항상 한 줄.
- **분석은 실제로**: 프레임 추출·OCR·음성 인식으로 해설/대사/무대사를 구분한다. 대본만 보고 분석했다고 하지 않는다.
- **해설체**: 제3자 です・ます체. 인물 1인칭으로 바뀌지 않는다. 화면에 없는 사실·결말을 보태지 않는다.
- **동기화**: 문장 묶음 단위로 합성하고 단어 타이밍으로 배치. 축약 → 합성 속도 → 후처리 가속(대체로 1.0–1.25배) 순서로 맞춘다.
- **화면**: 상·하단 `#10131C`, 제목 Dela Gothic One(핵심 노란 강조). 한국어 자막·로고는 그 영역만 부드럽게 블러. 좌표·속도 같은 탈옥 영상 수치는 참고값일 뿐 그대로 쓰지 않는다.
- **커버 제목**: 2줄(흰/노랑), 높이 61~88% 안. 아래 끝이 88%를 넘으면 쇼츠 UI에 가린다(01_COVER).
- **채널 로고**(사용자 지정): 원본 채널 워터마크를 블러한 자리 위에 시네트리 배지(`assets/channel_badge.png`: 반투명 짙은 둥근 판 + シネトリ 노란 글자)를 같은 크기로 얹어 블러 자국을 가린다. 위치는 영상마다 `layout.logo_blur`에 맞춘다.
- **BGM**: 가사 없는 자작곡 또는 사용 조건 확인된 곡. 장르마다 바꾼다.
- **검수**: 납품 전 일본어 감수자 관점 검토 → 수정 → 재생성 → 재검사(7장 체크리스트). AI 감수와 원어민 청취 검수를 구분해 사실대로 보고한다.
- **권리**: 블러·번역·BGM으로 수익화·저작권 문제가 해결된다고 말하지 않는다. 게시·외부 전송은 별도 요청이 있을 때만.
- **안 되는 단계는 됐다고 하지 않는다.** 도구가 없으면 대본·자막·타임라인과 미완료 단계를 나눠 전달한다.

## 폴더

- `guide/` 지침
- `projects/<slug>/` 영상별 대본·타임라인(`script.json`)과 BGM 구성(`bgm.json`)
- `tools/` 제작 도구: `tts.py`(edge-tts, 프록시 CA), `narrate.py`(해설 생성·속도 맞춤), `bgm.py`(BGM 작곡), `build.py`(오디오 믹스·블러·자막·렌더), `thumbnail.py`(커버 1080×1920, 01_COVER 기준·`projects/<slug>/thumb.json`)
- `work/` 중간 파일(레포에 올리지 않음, `.gitignore`)
- `outputs/` 납품물(MP4·SRT·ASS·대본·검수 내역). 영상·음성 파일은 용량 때문에 커밋하지 않고 텍스트 산출물만 커밋한다.
- 원본 영상은 덮어쓰지 않는다.

## 제작 순서(한 영상)

1. 원본을 `work/<slug>/source.mp4`로 받고 프레임·자막 띠·음성 인식(한국어·영어)으로 분석 → `work/<slug>/events.json`(한국어 자막 이벤트)
2. `demucs --two-stems=vocals`로 해설 분리(한국어 해설 구간에만 쓴다)
3. `projects/<slug>/script.json` 작성(해설·대사·캡션·레이아웃) → `python3 tools/narrate.py <slug>` → `python3 tools/bgm.py <slug>` → `python3 tools/build.py <slug>`
4. 검수(지침 7장) 후 `outputs/<slug>/`에 MP4·SRT·ASS·대본/검수 내역
